Aufgabe 8.12.4: Die vereinfachte Hashfunktion verbessern? AFB II

Betrachte die vereinfachte Hashfunktion h(x) = (3 · x + 7) mod 12 aus dem Abschnitt oben.

  1. Berechne h(x) für x = 0, 1, …, 11 und gib alle Kollisionen an.
  2. Ersetze den Faktor 3 durch 5: h'(x) = (5 · x + 7) mod 12. Berechne erneut die Werte für x = 0 bis 11 und vergleiche.
  3. Zeige, dass man bei h' zu jedem Hashwert sofort ein passendes x berechnen kann. Bestimme so ein x mit h'(x) = 10.
  4. Beurteile, welche Eigenschaften einer kryptographischen Hashfunktion h' erfüllt und welche nicht.
Aufgabe 8.12.5: Downloads automatisch prüfen AFB II
  1. Schreibe eine Python-Funktion pruefe_datei(pfad, erwartet), die den SHA-256-Hashwert einer Datei berechnet und True zurückgibt, wenn er mit dem erwarteten Wert übereinstimmt. Die Datei soll in Blöcken von 4096 Byte gelesen werden, damit auch sehr große Dateien funktionieren. Groß- und Kleinschreibung des erwarteten Werts sollen keine Rolle spielen.
  2. Lege eine Datei test.txt an, die genau den Text Hallo enthält (ohne Zeilenumbruch), und teste (erwartete und tatsächliche Ausgabe):
    • mit dem Hashwert aus Beispiel 2 in Kleinbuchstaben → True
    • mit demselben Wert in Großbuchstaben (wie Get-FileHash ihn ausgibt) → True
    • nachdem du den Inhalt in hallo geändert hast → False
  3. Speichert ein Editor die Datei mit einem Zeilenumbruch am Ende, schlägt der erste Test fehl. Erkläre, warum.
