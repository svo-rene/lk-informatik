Aufgabe 8.9.8: Fehler finden – der Test war doch grün AFB III

Paul hat RSA programmiert und ist zufrieden, weil sein Test die richtige Zahl liefert:

from math import gcd

def schluessel(p, q, e):
    n = p * q
    phi = (p - 1) * (q - 1)
    if gcd(e, phi) != 1:
        raise ValueError("e unzulässig")
    d = pow(e, -1, n)
    return (e, n), (d, n)

oeff, priv = schluessel(5, 11, 3)
c = 9 ** 3 % 55
print(c, c ** priv[0] % 55)     # Ausgabe: 14 9  -> "funktioniert!"
  1. Finde den Fehler in der Schlüsselerzeugung und berechne Pauls falsches d sowie das richtige d.
  2. Teste Pauls Programm von Hand mit m = 2 und zeige, dass es versagt.
  3. Erkläre, warum der Test mit m = 9 trotzdem das richtige Ergebnis liefert. Was folgt daraus für das Testen?
  4. Verbessere das Programm und gib eine sinnvolle Menge von Testfällen an (Eingabe, erwartete Ausgabe).

Zu c): Es gilt me·d mod n. Überlege, welche Potenzen von 9 modulo 55 sich wiederholen.
