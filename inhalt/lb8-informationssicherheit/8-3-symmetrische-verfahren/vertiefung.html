Aufgabe 8.3.9: Fehler finden im Vigenère-Programm AFB III

Mia hat die Vigenère-Verschlüsselung für Großbuchstaben programmiert:

def vigenere(text, schluessel):
    ergebnis = ""
    for i in range(len(text)):
        z = text[i]
        if z.isalpha():
            k = ord(schluessel[i % len(schluessel)]) - ord("A")
            ergebnis += chr(ord(z) - ord("A") + k + ord("A"))
        else:
            ergebnis += z
    return ergebnis

print(vigenere("HALLO WELT", "KEY"))

Erwartet hat sie (wie im Vigenère-Beispiel von 8.2, Leerzeichen verbrauchen keinen Schlüsselbuchstaben) REJVS UOPR. Ausgegeben wird aber REdVS aId^.

  1. Das Programm enthält zwei Fehler. Finde sie und erkläre für jeden, an welcher Stelle der Ausgabe er sich zeigt.
  2. Berichtige das Programm.
  3. Weise die Korrektheit mit diesen Testfällen nach (Eingabe, erwartete Ausgabe, tatsächliche Ausgabe): ("HALLO WELT", "KEY") → REJVS UOPR; ("XYZ", "B") → YZA; ("INFORMATIK", "LK") → TXQYCWLDTU.

Rechne die ersten Zeichen von Hand nach: An welcher Position steht das Leerzeichen, und welcher Schlüsselbuchstabe wird danach verwendet?
