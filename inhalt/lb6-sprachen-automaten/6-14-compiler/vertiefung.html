Aufgabe 6.14.7: Fehler finden – ein Scanner, der hängt AFB III

Emil hat die Funktion scanne abgetippt. zeichenklasse und OPERATOREN stimmen mit Beispiel 3 überein. Seine Tests "x+1;" und "(a*b)" laufen fehlerfrei.

def scanne(text):
    tokens = []
    i = 0
    while i < len(text):
        klasse = zeichenklasse(text[i])
        if klasse == "leer":
            pass
        elif klasse == "operator":
            tokens.append((OPERATOREN[text[i]], text[i]))
            i = i + 1
        elif klasse == "ziffer":
            start = i
            while zeichenklasse(text[i]) == "ziffer":
                i = i + 1
            tokens.append(("ZAHL", text[start:i]))
        elif klasse == "buchstabe":
            start = i
            while i < len(text) and zeichenklasse(text[i]) in ("buchstabe", "ziffer"):
                i = i + 1
            tokens.append(("BEZEICHNER", text[start:i]))
        else:
            tokens.append(("FEHLER", text[i]))
            i = i + 1
    return tokens
