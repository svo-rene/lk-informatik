Lena hat das Einfügen in ihrer gekapselten Klasse Suchbaum rekursiv programmiert:

class Suchbaum:
    def __init__(self):
        self.__wurzel = None

    def einfuegen(self, leser, knoten=None):
        if self.__wurzel is None:
            self.__wurzel = Knoten(leser)
            return
        if knoten is None:
            knoten = self.__wurzel
        nummer = leser.get_nummer()
        vergleich = knoten.get_leser().get_nummer()
        if nummer == vergleich:
            return
        if nummer < vergleich:
            if knoten.get_links() is None:
                knoten.set_links(Knoten(leser))
            else:
                self.einfuegen(leser, knoten.get_links())
        else:
            if knoten.get_rechts() is None:
                knoten.set_rechts(Knoten(leser))
            else:
                self.einfuegen(leser, knoten.get_rechts())

Mit leser.csv (50 000 Datensätze) läuft alles. Mit leser_sortiert.csv (5 000 Datensätze) bricht das Programm nach knapp 1 000 Datensätzen ab:

RecursionError: maximum recursion depth exceeded in comparison
  1. Erkläre, warum der Fehler nur bei der kleineren, sortierten Datei auftritt. Gib an, wie viele Aufrufe von einfuegen beim Einfügen des 1 000. sortierten Datensatzes gleichzeitig offen sind.
  2. Mit der zufälligen Datei entsteht ein Baum der Höhe 35. Gib die größte Zahl gleichzeitig offener Aufrufe an und begründe, warum Python dabei keine Probleme hat.
  3. Lenas Freund schlägt vor, an den Programmanfang import sys und sys.setrecursionlimit(100000) zu schreiben. Beurteile diesen Vorschlag.
  4. Schreibe einfuegen iterativ. Weise mit Testfällen nach, dass der Baum danach alle 5 000 sortierten Datensätze enthält und Duplikate abgewiesen werden.
