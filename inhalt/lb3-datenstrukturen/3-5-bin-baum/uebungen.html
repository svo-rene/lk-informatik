PRIMM 3.5: Was macht raetsel? AFB I–II

Dateien: primm_3-5_raetsel.py und primm_3-5_fehler.py in 2_baeume/ speichern – erst nach Schritt 1 öffnen.

1 Vorhersagen (Papier, ohne Rechner): Was gibt das Programm aus? Zeichne dazu den Suchbaum und markiere, welche Knoten die Methode ansieht.

    def raetsel(self, grenze, knoten=None):
        if self.__wurzel is None:
            return 0
        if knoten is None:
            knoten = self.__wurzel
        anzahl = 0
        if knoten.links is not None:
            anzahl = anzahl + self.raetsel(grenze, knoten.links)
        if knoten.wert < grenze:
            anzahl = anzahl + 1
            if knoten.rechts is not None:
                anzahl = anzahl + self.raetsel(grenze, knoten.rechts)
        return anzahl

# Suchbaum aus Beispiel 1: 8, 3, 10, 1, 6, 14 eingefügt
print(b.raetsel(7))
Lösung zeigen

Ausgabe: 3. Die Methode zählt die Werte, die kleiner als die Grenze sind (1, 3, 6). Von der 8 aus geht es nur nach links, weil rechts davon nur Werte ≥ 8 stehen.

2 Ausführen: Öffne primm_3-5_raetsel.py in Thonny, starte mit F5 und vergleiche mit deiner Vorhersage.

3 Untersuchen mit dem Debugger (Strg + F5):

  1. Welche Knoten werden überhaupt besucht, welche nie?
  2. Wie viele Aufrufe von raetsel gibt es insgesamt? Gibt es einen Aufruf mit einem fehlenden Kind?
  3. Warum darf die Methode den rechten Teilbaum weglassen, wenn der Knoten nicht kleiner als die Grenze ist?
Lösung zeigen

1. Besucht werden 8, 3, 1 und 6, die 10 und die 14 nie. 2. Vier Aufrufe: 8 (von außen), 3, 1, 6. Mit einem fehlenden Kind wird nie aufgerufen, weil die Methode vorher is not None prüft – sonst würde sie wieder an der Wurzel beginnen. 3. Ist ein Knoten ≥ grenze, ist auch alles in seinem rechten Teilbaum ≥ grenze (Suchbaum-Eigenschaft) – dort kann nichts Kleineres liegen.

4 Abwandeln:

  1. Ändere die Methode so, dass sie zählt, wie viele Werte größer als grenze sind. Welcher Teilbaum darf jetzt wegfallen?
  2. Ändere sie so, dass Werte kleiner oder gleich der Grenze gezählt werden. Teste mit grenze = 6.

5 Fehler finden: Die rekursive Suche findet 14, aber nicht 6. Gehe die Suche nach 6 mit F7 Schritt für Schritt durch: Welchen Wert liefert der innerste Aufruf, und wo geht dieser Wert verloren? Korrigiere den Fehler.

    def suchen_rek(self, wert, knoten=None):
        if self.__wurzel is None:
            return False
        if knoten is None:
            knoten = self.__wurzel
        if wert == knoten.wert:
            return True
        if wert < knoten.wert:
            if knoten.links is None:
                return False
            self.suchen_rek(wert, knoten.links)
        else:
            if knoten.rechts is None:
                return False
            return self.suchen_rek(wert, knoten.rechts)

print(b.suchen_rek(14))    # True – richtig
print(b.suchen_rek(6))     # None statt True
