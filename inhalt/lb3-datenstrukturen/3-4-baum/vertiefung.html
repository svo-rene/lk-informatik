Ein Mitschüler hat die Klasse Tree aus baum4.py um eine eingerückte Ausgabe erweitert. Die Methode print_tree hat nur den Parameter node.

    def print_tree_structure(self, node=None, level=0):
        if node is None:
            node = self.root
            print("  " * level + node.data)
        for child in node.children:
            self.print_tree(child, level + 1)
  1. Beim Aufruf tree1.print_tree_structure() für den Baum Hans → (Brigitte → Petra), Dieter erscheint eine Fehlermeldung. Gib an, welche Meldung zu erwarten ist, und erkläre sie.
  2. Der Mitschüler ersetzt nur self.print_tree durch self.print_tree_structure. Gib die Ausgabe an und finde den zweiten Fehler.
  3. Gib die korrigierte Methode an und die erwartete Ausgabe für den Beispielbaum.
  4. Beurteile, was beim Aufruf für einen leeren Baum (root ist None) passiert, und schlage eine Verbesserung vor.
Aufgabe 3.4.6: Ist das noch ein Baum? AFB III

Eine Vereinssoftware speichert für jede Abteilung nur, zu welchem Bereich sie gehört (Elternverweis). Beim Import ist ein Fehler passiert:

eltern = {
    "Kasse": "Vorstand",
    "Jugend": "Vorstand",
    "Fußball": "Jugend",
    "Handball": "Jugend",
    "Turnen": "Breitensport",
    "Breitensport": "Turnen",
}
  1. Zeichne die Struktur und begründe mit der Definition eines Baums, welche Bedingungen verletzt sind.
  2. Schreibe eine Funktion ist_baum(eltern), die prüft, ob es genau eine Wurzel gibt und ob man von jedem Knoten aus über die Elternverweise zur Wurzel gelangt, ohne einen Knoten doppelt zu besuchen.
  3. Teste mit den Daten oben (erwartet: False) und mit der korrigierten Fassung, in der Breitensport zum Vorstand gehört (erwartet: True).
  4. Vergleiche die Darstellung mit Elternverweisen mit der Darstellung mit Kinderlisten aus Beispiel 2: Welche Frage lässt sich jeweils schnell beantworten?
