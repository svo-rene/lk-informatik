Verkettete Listen, Schlangen, Stapel und Bäume bestehen aus Knoten, die über Verweise verbunden sind. In der Werkstatt legst du solche Knoten an und hängst die Verweise mit der Maus oder dem Finger um, so wie es der Python-Code Zeile für Zeile tut. Die Werkstatt zeigt dir sofort, wenn ein Knoten von keiner Variablen mehr erreichbar ist. Im Modus Felder siehst du, was beim Anfügen an eine Python-Liste im Speicher passiert, wenn die Kapazität nicht mehr reicht.

Erreichbarkeit: Ein Knoten ist nur so lange nutzbar, wie eine Variable oder ein Verweis eines anderen erreichbaren Knotens auf ihn zeigt. Zeigt nichts mehr auf ihn, kommt man nie wieder an ihn heran, und Python räumt ihn weg.
Reihenfolge beim Umhängen: Erst den neuen Verweis setzen, der den Rest festhält, dann den alten Verweis umlegen.

So bedienst du die Werkstatt

  • Übung wählen: Oben links wählst du eine Übung zu einer Kursseite. Der Auftrag steht darunter. Mit Prüfen bekommst du eine Rückmeldung.
  • Verweis setzen: Ziehe vom blauen Punkt eines Feldes (zum Beispiel next) oder vom Punkt einer grünen Variablen auf einen Knoten. Ziehst du auf eine leere Fläche, wird der Verweis None.
  • Neuer Knoten: Ein neuer Knoten kommt immer in eine Variable, so wie neu = Node(5). Den Namen der Variablen kannst du ändern.
  • Rückgängig: In Python ist ein verlorener Knoten endgültig weg. Hier kannst du einen Fehler rückgängig machen und es noch einmal versuchen.
  • Verschieben: Knoten und Variablen kannst du an eine andere Stelle ziehen. „Als Liste anordnen“ und „Als Baum anordnen“ räumen die Zeichnung auf.

Ein Zugriff ist ein Lesen oder Schreiben eines Platzes. Kopieren eines Elements kostet also 2 Zugriffe.
