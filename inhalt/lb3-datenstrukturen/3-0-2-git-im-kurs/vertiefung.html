Aufgabe 3.0.2.6: Beurteile – „Ich habe es doch gelöscht“ AFB III

Ein Mitschüler hat für eine Übung zur Datenbankanbindung die Datei zugang.py mit seinem echten beste.schule-Passwort in sein Repository hochgeladen. Eine Stunde später hat er sie mit dem Mülleimer gelöscht. Er meint: „Jetzt ist es weg, und das Repository ist sowieso privat.“

Beurteile beide Teile der Aussage. Gehe darauf ein, wer das Passwort noch sehen kann und was er jetzt tun sollte.
