class Stack:
    def __init__(self):
        self._head = None
        self._anzahl = 0

    def is_empty(self):
        return self._head is None

    def push(self, data):
        neu = Node(data)
        neu.next = self._head
        self._head = neu
        self._anzahl += 1

    def pop(self):
        data = self._head.data
        self._head = self._head.next
        return data

    def __len__(self):
        return self._anzahl

Ein Rangierbahnhof hat zwei Abstellgleise, die beide Sackgleise sind: Der zuletzt hineingeschobene Wagen muss als Erster wieder heraus (Stapel). Trotzdem sollen die Wagen den Bahnhof in der Reihenfolge ihrer Ankunft verlassen (Schlange). Die Lösung der Rangierer: Ankommende Wagen kommen auf Gleis „ein“. Abfahren darf nur ein Wagen von Gleis „aus“. Ist Gleis „aus“ leer, werden alle Wagen von „ein“ nacheinander nach „aus“ umgesetzt.

  1. Lege eine Tabelle mit den Spalten Operation, Gleis „ein“ (oben rechts), Gleis „aus“ (oben rechts), Rückgabe an und fülle sie für diese Folge aus: enqueue(1), enqueue(2), enqueue(3), dequeue(), enqueue(4), dequeue(), dequeue(), dequeue(), dequeue().

Bei leerer Schlange lösen dequeue und peek IndexError("dequeue aus leerer Schlange") bzw. IndexError("peek auf leerer Schlange") aus.
  3. Ein Mitschüler schlägt vor, bei jedem dequeue umzusetzen, auch wenn „aus“ nicht leer ist. Zeige an der Folge aus Teil 1, dass dann eine falsche Reihenfolge entsteht.
  4. Beurteile die Laufzeit: Wie teuer ist ein einzelnes dequeue im schlechtesten Fall? Wie oft wird jeder Wagen insgesamt bewegt, wenn n Wagen ankommen und wieder abfahren? Vergleiche mit der Queue aus Seite 3.2.
