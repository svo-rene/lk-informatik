PRIMM 3.8: Was prüft raetsel? AFB I–II

Dateien: primm_3-8_raetsel.py und primm_3-8_fehler.py in 3_graphen/ speichern, dazu queue_knoten.py (siehe Beispiel 1) – erst nach Schritt 1 öffnen.

1 Vorhersagen (Papier, ohne Rechner): Was geben die beiden Aufrufe aus? Zeichne den Graphen und beschreibe in einem Satz, was die Methode prüft.

    def raetsel(self, start):
        visited = [False] * self.size
        queue = Queue()
        queue.enqueue(start)
        visited[start] = True
        anzahl = 0
        while not queue.is_empty():
            current = queue.dequeue()
            anzahl = anzahl + 1
            for n in self.graph[current]:
                if not visited[n]:
                    visited[n] = True
                    queue.enqueue(n)
        return anzahl == self.size


g = Graph(5)
g.add_edge(0, 1)
g.add_edge(1, 2)
g.add_edge(3, 4)
print(g.raetsel(0))
print(g.raetsel(3))
Lösung zeigen

Ausgabe: False und False. Die Methode zählt mit einer Breitensuche, wie viele Knoten vom Start aus erreichbar sind, und prüft, ob das alle sind – also ob der Graph zusammenhängend ist. Er besteht aus zwei Teilen (0–1–2 und 3–4), deshalb ist das Ergebnis von jedem Start aus False.

2 Ausführen: Öffne primm_3-8_raetsel.py in Thonny, starte mit F5 und vergleiche mit deiner Vorhersage.

3 Untersuchen mit dem Debugger (Strg + F5):

  1. In welcher Reihenfolge werden die Knoten bei raetsel(0) aus der Schlange genommen?
  2. Welchen Wert hat anzahl am Ende von raetsel(0), welchen am Ende von raetsel(3)?
  3. Welche Kante müsste man ergänzen, damit beide Aufrufe True liefern?
Lösung zeigen

1. 0, 1, 2. 2. 3 bzw. 2. 3. Irgendeine Kante zwischen den beiden Teilen, z. B. g.add_edge(2, 3).

4 Abwandeln:

  1. Schreibe unerreichbar(start), die alle Knoten liefert, die vom Start aus nicht erreichbar sind (für start = 0: [3, 4]).
  2. Schreibe komponenten(), die zählt, aus wie vielen Teilen der Graph besteht. Tipp: Starte so lange neue Breitensuchen, bis jeder Knoten besucht ist.

5 Fehler finden: Diese Breitensuche liefert [0, 1, 2, 2, 3, 3] statt [0, 1, 2, 3]. Beobachte im Debugger, welche Knoten nach dem Entnehmen der 1 mit enqueue angestellt werden: Warum wird die 2 ein zweites Mal angestellt? Korrigiere den Fehler und vergleiche mit bfs aus Beispiel 1.

    def bfs(self, start):
        visited = [False] * self.size
        queue = Queue()
        queue.enqueue(start)
        reihenfolge = []
        while not queue.is_empty():
            current = queue.dequeue()
            visited[current] = True
            reihenfolge.append(current)
            for n in self.graph[current]:
                if not visited[n]:
                    queue.enqueue(n)
        return reihenfolge
