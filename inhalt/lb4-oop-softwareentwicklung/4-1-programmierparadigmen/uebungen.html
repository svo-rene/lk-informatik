Aufgabe 4.1.3: Klausurauswertung – imperativ und funktional AFB II

Eine Kurslehrerin wertet eine Klausur aus. Die Ergebnisse liegen in Notenpunkten (0 bis 15) vor, bestanden ist eine Klausur ab 5 Punkten. Ihr bisheriges Programm ist imperativ:

punkte = [12, 4, 9, 15, 3, 7]
summe = 0
bestanden = 0
for p in punkte:
    summe = summe + p
    if p >= 5:
        bestanden = bestanden + 1
print(round(summe / len(punkte), 1), bestanden)
  1. Gib die Ausgabe des Programms an.
  2. Schreibe eine Funktion auswertung(punkte) im funktionalen Stil, die das Tupel (durchschnitt, anzahl_bestanden) zurückgibt. Es darf keine Variable schrittweise verändert werden (keine Schleife mit Zuweisungen). Der Durchschnitt wird auf eine Nachkommastelle gerundet; für eine leere Liste soll er None sein.
  3. Teste deine Funktion mit print(auswertung(…)):
    Eingabe punkteerwartete Ausgabetatsächliche Ausgabe
    [12, 4, 9, 15, 3, 7](8.3, 4)
    [5, 5](5.0, 2)
    [0, 4, 3](2.3, 0)
    [15](15.0, 1)
    [](None, 0)
  4. Erkläre, was das imperative Programm bei einer leeren Liste macht, und begründe, warum dieser Fehler in beiden Paradigmen bedacht werden muss.

Tipp: sum, len und eine Listenabstraktion [p for p in punkte if …] reichen aus. Für den Sonderfall hilft ein bedingter Ausdruck wert1 if bedingung else wert2.

Aufgabe 4.1.4: Stammbaum – logisch und imperativ AFB II

Eine Stammbaum-App speichert, wer Elternteil von wem ist. In Prolog sieht der Ausschnitt so aus:

elternteil(erna, ines).
elternteil(erna, tom).
elternteil(ines, lea).
elternteil(ines, max).
elternteil(tom, ida).

grosselternteil(X, Z) :- elternteil(X, Y), elternteil(Y, Z).
geschwister(X, Y)     :- elternteil(E, X), elternteil(E, Y), X \= Y.
  1. Gib an, wie SWI-Prolog auf die Anfrage ?- grosselternteil(erna, E). antwortet, wenn du nach jeder Antwort ; eingibst. Gib außerdem die Antwort auf ?- setof(G, geschwister(lea, G), L). an und erkläre, warum lea nicht ihr eigenes Geschwister ist.
  2. Ergänze eine Regel cousin(X, Y): X und Y sind Cousins bzw. Cousinen, wenn ihre Elternteile Geschwister sind. Gib die Antwort auf ?- setof(C, cousin(ida, C), L). an.
  3. Dieselben Daten liegen in Python als Liste von Paaren vor: 
    beziehungen = [("erna", "ines"), ("erna", "tom"), ("ines", "lea"),
               ("ines", "max"), ("tom", "ida")]
    Schreibe imperativ eine Funktion enkel(person, beziehungen), die die Liste aller Enkel von person zurückgibt (in der Reihenfolge, in der sie gefunden werden). Teste sie:
    Aufruferwartete Ausgabetatsächliche Ausgabe
    print(enkel("erna", beziehungen))['lea', 'max', 'ida']
    print(enkel("ines", beziehungen))[]
    print(enkel("ines", beziehungen + [("lea", "paul")]))['paul']
    print(enkel("otto", beziehungen))[]
  4. Vergleiche beide Lösungen: Was musst du in Python selbst programmieren, was erledigt Prolog von allein?
