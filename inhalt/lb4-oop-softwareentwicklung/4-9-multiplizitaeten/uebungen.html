Aufgabe 4.9.5: Multiplizitäten aus Code ablesen – Linienbus AFB II 
class Fahrer:
    def __init__(self, name: str):
        self.name: str = name

class Haltestelle:
    def __init__(self, name: str):
        self.name: str = name

class Reifen:
    def __init__(self, position: int):
        self.position: int = position

class Bus:
    def __init__(self, kennzeichen: str, fahrer: Fahrer):
        self.kennzeichen: str = kennzeichen
        self.fahrer: Fahrer = fahrer                                 # (a)
        self.ersatzfahrer: Fahrer | None = None                      # (b)
        self.haltestellen: list[Haltestelle] = []                    # (c)
        self.reifen: list[Reifen] = [Reifen(i) for i in range(6)]    # (d)
  1. Gib für (a) bis (d) die Multiplizität an, die aus dem Code folgt, und die Beziehungsart. Achte bei (a) und (b) darauf, dass zweimal dieselbe Klasse beteiligt ist.
  2. Welche Multiplizitäten lassen sich aus diesem Code nicht ablesen? Woher bekommt man sie?
  3. Zeichne das Klassendiagramm.
  4. Der Verkehrsbetrieb legt fest: „Jeder Bus fährt mindestens 2 Haltestellen an.“ Ändere die Klasse Bus so, dass 2..* durchgesetzt wird, und gib zwei Testfälle an.
