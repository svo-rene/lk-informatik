Aufgabe 4.0.5: Ein Fahrkartenpreis – vier Denkweisen AFB II

Der Verkehrsverbund berechnet Fahrkartenpreise nach dem Alter: Kinder unter 6 Jahren fahren kostenlos, 6- bis 14-Jährige zahlen 150 Cent, alle ab 15 Jahren 300 Cent. Vier Teams haben das Problem in verschiedenen Paradigmen gelöst:

# Variante A
alter_gruppe = [4, 9, 15, 40]
gesamt = 0
for alter in alter_gruppe:
    if alter < 6:
        gesamt = gesamt + 0
    elif alter <= 14:
        gesamt = gesamt + 150
    else:
        gesamt = gesamt + 300
print(gesamt)
# Variante B
class Fahrgast:
    def __init__(self, alter):
        self.alter = alter

    def preis(self):
        if self.alter < 6:
            return 0
        elif self.alter <= 14:
            return 150
        return 300

gruppe = [Fahrgast(4), Fahrgast(9), Fahrgast(15), Fahrgast(40)]
gesamt = 0
for f in gruppe:
    gesamt = gesamt + f.preis()
print(gesamt)
# Variante C
def preis(alter):
    return 0 if alter < 6 else (150 if alter <= 14 else 300)

print(sum(map(preis, [4, 9, 15, 40])))
% Variante D (Prolog)
preis(Alter, 0)   :- Alter < 6.
preis(Alter, 150) :- Alter >= 6, Alter =< 14.
preis(Alter, 300) :- Alter >= 15.

?- preis(40, P).
?- preis(9, P).
  1. Ordne jede Variante in die Paradigmen-Hierarchie ein (oberste Ebene und Paradigma darunter). Nenne jeweils ein Merkmal im Code, an dem du das erkennst.
  2. Gib die Ausgaben von A, B und C an. Ermittle außerdem, was A, B und C ausgeben, wenn die Gruppe aus Personen mit dem Alter 6, 14 und 5 besteht.
  3. Gib an, wie SWI-Prolog auf die beiden Anfragen in Variante D antwortet. Erkläre, warum bei der zweiten Anfrage nach dem Eingeben von ; noch eine Antwort folgt.
  4. Der Verbund führt einen Seniorentarif ein: ab 65 Jahren 200 Cent. Beurteile, in welcher Variante die Änderung am wenigsten Stellen im Code betrifft.

Tipp: Prolog probiert die Regeln von oben nach unten aus. Nach einer Antwort merkt es sich, welche Regeln es noch nicht versucht hat.
