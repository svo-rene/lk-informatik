Aufgabe 4.3.5: Fehler finden – das Schließfach AFB III

Für die Schließfächer im Schulhaus hat Mira eine Klasse geschrieben. Nach dem Öffnen soll Fach 17 (Ida): offen erscheinen.

class Schliessfach:
    def __init__(nummer, besitzer):
        self.nummer = nummer
        self.besitzer = besitzer
        self.offen = False

    def oeffnen(self):
        offen = True

    def status(self):
        if self.offen:
            return f"Fach {self.nummer} ({besitzer}): offen"
        return f"Fach {self.nummer} ({besitzer}): zu"

fach = Schliessfach(17, "Ida")
fach.oeffnen
print(fach.status())

  2. Mira behebt die Fehler nacheinander in der Reihenfolge, in der Python sie meldet. Gib an, was das Programm nach jeder einzelnen Korrektur ausgibt.
