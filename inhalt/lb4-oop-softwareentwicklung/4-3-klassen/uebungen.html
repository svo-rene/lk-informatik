Kurz geprüft 3: Die Lampe übersetzen AFB I–II

Ein Klassendiagramm Lampe hat die Attribute ort: string und an: bool sowie die Methoden Lampe(ort: string) und schalten(): void. Gib die Kopfzeilen der Klasse und der beiden Methoden in Python an. Was muss in __init__ mit dem Attribut an geschehen?

Lösung zeigen

class Lampe:, def __init__(self, ort): und def schalten(self):. schalten braucht kein return (void). Da an kein Parameter des Konstruktors ist, bekommt es in __init__ einen festen Startwert, z. B. self.an = False.

Aufgabe 4.3.4: Zwischen UML und Code übersetzen AFB II

a) Code → UML: Die Mensa verwaltet ihre Gerichte mit dieser Klasse (Preise in Cent):

class Gericht:
    def __init__(self, name, preis, vegetarisch):
        self.name = name
        self.preis = preis
        self.vegetarisch = vegetarisch
        self.portionen = 0

    def verkaufen(self, anzahl):
        self.portionen += anzahl

    def umsatz(self):
        return self.portionen * self.preis

g1 = Gericht("Linsencurry", 350, True)
g2 = Gericht("Schnitzel", 420, False)
g1.verkaufen(12)
g2.verkaufen(8)
g1.verkaufen(3)
print(g1.umsatz(), g2.umsatz())
