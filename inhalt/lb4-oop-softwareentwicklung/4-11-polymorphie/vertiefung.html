Aufgabe 4.11.7: Fehler finden – die vergessene Unterklasse AFB III

Ein Fahrradverleih berechnet seine Preise so (Fahrrad 10 €, E-Bike 15 €, Lastenrad 18 € pro Tag):

class Fahrrad:
    def __init__(self, tage):
        self.tage = tage

class EBike(Fahrrad):
    pass

class Lastenrad:
    def __init__(self, tage):
        self.tage = tage

def preis(f):
    if type(f) == Fahrrad:
        return 10 * f.tage
    elif type(f) == Lastenrad:
        return 18 * f.tage
    else:
        return 0

leihen = [Fahrrad(2), EBike(3), Lastenrad(1)]
print(sum(preis(f) for f in leihen))
  1. Sage die Ausgabe vorher und vergleiche sie mit dem richtigen Gesamtpreis. Erkläre den Fehler.
  2. Ein Mitschüler schlägt vor, type(f) == Fahrrad durch isinstance(f, Fahrrad) zu ersetzen. Beurteile den Vorschlag.
  3. Baue das Programm so um, dass es ohne if-Kette auskommt (Polymorphie), und teste es mit der Liste oben.
  4. Vergleiche: Was muss in beiden Fassungen geändert werden, wenn ein Tandem für 12 € pro Tag dazukommt?
