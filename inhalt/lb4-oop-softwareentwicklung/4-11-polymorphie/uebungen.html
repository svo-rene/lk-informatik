Aufgabe 4.11.5: Ergebnis vorhersagen – wer bellt hier? AFB II 
class Tier:
    def __init__(self, name):
        self.name = name

    def laut(self):
        return "..."

    def vorstellen(self):
        return f"{self.name} sagt {self.laut()}"

class Hund(Tier):
    def laut(self):
        return "Wuff"

class Welpe(Hund):
    def laut(self):
        return super().laut().lower() + "!"

class Fisch(Tier):
    pass

for t in [Hund("Rex"), Welpe("Bobo"), Fisch("Flossi")]:
    print(t.vorstellen())
  1. Sage die drei Ausgabezeilen vorher, ohne das Programm auszuführen.
  2. Die Methode vorstellen() steht nur in Tier. Erkläre, warum sie trotzdem Hund.laut() bzw. Welpe.laut() aufruft.
  3. Gib für Welpe("Bobo").vorstellen() die Reihenfolge aller ausgeführten Methoden an (Klasse.Methode).
Aufgabe 4.11.6: Zahlungsarten am Schulkiosk AFB II

Der Schulkiosk bekommt ein Kassensystem. Je nach Zahlungsart kommen Gebühren hinzu. Alle Beträge werden in Cent (ganze Zahlen) gerechnet:

  • Barzahlung: keine Gebühr
  • Kartenzahlung: 1 % des Betrags (ganzzahlig abgerundet), mindestens aber 10 Cent
  • Onlinezahlung: 35 Cent plus 2,5 % des Betrags (ganzzahlig abgerundet)
  1. Schreibe eine Oberklasse Zahlungsart mit den Methoden bezeichnung() und gebuehr(betrag_cent: int) -> int sowie die drei Unterklassen.
  2. Schreibe eine Funktion abrechnen(betrag_cent, zahlungsart) -> str, die z. B. "Karte: 20.20 €" zurückgibt. Die Funktion darf keine if-Abfrage auf die Zahlungsart enthalten.
  3. Ergänze danach eine Klasse Gutschein (10 % Rabatt, ganzzahlig abgerundet), ohne abrechnen zu verändern.
Aufruferwartete Ausgabetatsächliche Ausgabe
abrechnen(2000, Barzahlung())Bar: 20.00 €
abrechnen(2000, Kartenzahlung())Karte: 20.20 €
abrechnen(2000, Onlinezahlung())Online: 20.85 €
abrechnen(500, Kartenzahlung())Karte: 5.10 € (Mindestgebühr)
abrechnen(500, Onlinezahlung())Online: 5.47 €

Ganzzahlig abrunden geht mit //, z. B. betrag_cent * 25 // 1000 für 2,5 %.

Aufgabe 4.11.8: Botschaften verfolgen – Fußgängerampel AFB II–III 
class Ampel:
    def __init__(self, name):
        self.name = name
        self.farbe = "rot"

    def schalte(self, farbe):
        self.farbe = farbe
        print(f"{self.name}: {farbe}")

class Steuerung:
    def __init__(self, auto_ampel, fuss_ampel):
        self.auto = auto_ampel
        self.fuss = fuss_ampel

    def anforderung(self):
        self.auto.schalte("gelb")
        self.auto.schalte("rot")
        self.fuss.schalte("grün")

class Taster:
    def __init__(self, steuerung):
        self.steuerung = steuerung

    def gedrueckt(self):
        print("Taster gedrückt")
        self.steuerung.anforderung()

auto = Ampel("Autoampel")
auto.schalte("grün")
fuss = Ampel("Fußgängerampel")
taster = Taster(Steuerung(auto, fuss))
taster.gedrueckt()
  1. Gib die vollständige Ausgabe an.
  2. Benenne das Ereignis und liste alle Botschaften, die es auslöst, in der richtigen Reihenfolge als „Sender → Empfänger: methode(argumente)“ auf.
  3. Nachts soll die Autoampel bei „gelb“ statt „Autoampel: gelb“ die Zeile „Autoampel: gelb blinkt“ ausgeben. Löse das mit einer Unterklasse BlinkAmpel, ohne Steuerung oder Taster zu ändern. Gib die neue Ausgabe an und begründe, warum keine weitere Klasse angepasst werden muss.
