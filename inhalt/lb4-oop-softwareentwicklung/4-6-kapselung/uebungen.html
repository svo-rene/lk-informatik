Aufgabe 4.6.3: Schließfach im Schwimmbad – UML in Code übersetzen AFB II

Ein Schwimmbad ersetzt die Münzschlösser seiner Schließfächer durch Zahlenschlösser. Die Software dafür ist schon modelliert:

Schliessfach
+ nummer: int
− __pin: str
− __offen: bool
− __fehlversuche: int
+ oeffnen(pin: str): bool

+ ist_offen(): bool
+ ist_gesperrt(): bool

Regeln: Ein neues Fach ist geschlossen und hat 0 Fehlversuche. Mit der richtigen PIN öffnet es sich, und die Fehlversuche werden auf 0 gesetzt. Jede falsche PIN zählt als Fehlversuch. Ab 3 Fehlversuchen ist das Fach gesperrt und öffnet sich auch mit der richtigen PIN nicht mehr.

  1. Implementiere die Klasse in Python genau nach dem Diagramm (Konstruktor __init__(nummer, pin)).
  2. Teste sie mit den folgenden Aufrufen, die nacheinander auf demselben Objekt f = Schliessfach(17, "4711") ausgeführt werden:

f.schliessen(), dann dreimal f.oeffnen("0000"), dann print(f.ist_gesperrt())True
print(f.oeffnen("4711"))False

Überlege bei oeffnen() zuerst, in welcher Reihenfolge die Fälle „gesperrt“, „richtige PIN“ und „falsche PIN“ geprüft werden müssen.
