Aufgabe 4.6.4: Fehler finden – der löchrige Bibliotheksausweis AFB III

Laut Benutzungsordnung der Schulbibliothek darf man höchstens 5 Medien gleichzeitig ausleihen. Wer offene Gebühren hat, darf nichts Neues ausleihen. Gebühren entstehen nur durch die Bibliothek und werden durch Bezahlen kleiner. Ein Mitschüler hat dazu programmiert:

class Bibliotheksausweis:
    MAX_AUSLEIHEN = 5

    def __init__(self, name):
        self.name = name
        self.__ausleihen = []
        self.gebuehren = 0.0

    def get_ausleihen(self):
        return self.__ausleihen

    def ausleihen(self, titel):
        if len(self.__ausleihen) < Bibliotheksausweis.MAX_AUSLEIHEN:
            self.__ausleihen.append(titel)

    def set_gebuehren(self, betrag):
        self.gebuehren = betrag


ausweis = Bibliotheksausweis("Mia")
liste = ausweis.get_ausleihen()
for i in range(7):
    liste.append(f"Buch {i}")
print(len(ausweis.get_ausleihen()))
ausweis.gebuehren = -10.0
print(ausweis.gebuehren)
  1. Sage die beiden Ausgaben vorher. Erkläre, warum trotz der privaten Liste 7 Bücher „ausgeliehen“ sind.
  2. Finde mindestens drei Stellen, an denen die Kapselung verletzt ist oder eine Regel der Benutzungsordnung nicht durchgesetzt wird.
  3. Korrigiere die Klasse. Ersetze dabei den allgemeinen Setter durch fachlich sinnvolle Methoden.
  4. Weise mit Testfällen (Aufruf, erwartete Ausgabe, tatsächliche Ausgabe) nach, dass jede gefundene Lücke geschlossen ist.
Aufgabe 4.6.6: Getter und Setter = Kapselung? AFB III

Für eine Verkehrssimulation hat jemand diese Klasse geschrieben:

class Ampel:
    def __init__(self):
        self.__zustand = "rot"

    def get_zustand(self):
        return self.__zustand

    def set_zustand(self, zustand):
        self.__zustand = zustand

Er meint: „Das Attribut ist privat und hat Getter und Setter – also ist die Klasse sauber gekapselt.“

  1. Beurteile diese Aussage. Zeige mit zwei Aufrufen, dass trotzdem unzulässige Zustände oder Übergänge entstehen können. Eine Ampel schaltet immer rot → rotgelb → grün → gelb → rot.
  2. Entwirf eine bessere öffentliche Schnittstelle (Klassendiagramm) und begründe, warum sie keinen Setter enthält.
  3. Implementiere deinen Entwurf und teste ihn: Nach viermaligem Weiterschalten muss die Ampel wieder rot zeigen.
