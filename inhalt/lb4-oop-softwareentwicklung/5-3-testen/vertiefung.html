Aufgabe 5.3.5: Fehler finden – „Bei mir sind alle Tests grün“ AFB III

Im Kopierraum kostet eine Seite 5 Cent, ab 100 Seiten kostet jede Seite nur 4 Cent. Weniger als eine Seite gibt es nicht (ValueError). Zu diesem Modul

# kopien.py
def kopierkosten_cent(seiten: int) -> int:
    if seiten > 100:
        return seiten * 4
    return seiten * 5

gehört diese Testdatei. Sie gibt „Test bestanden“ aus:

# test_kopien.py
from kopien import kopierkosten_cent

def test_kosten():
    assert(kopierkosten_cent(10) == 50, "10 Seiten falsch")
    ergebnis = kopierkosten_cent(150)
    assert ergebnis == kopierkosten_cent(150)
    assert kopierkosten_cent(50) == 250
    print("Test bestanden")

test_kosten()
  1. Finde mindestens vier Schwächen der Testdatei und erkläre bei jeder, warum sie einen Fehler verbergen kann.
  2. Schreibe eine bessere Testdatei nach den Regeln dieser Seite. Gib ihre Ausgabe für das Modul oben an.
  3. Korrigiere das Modul.
Aufgabe 5.3.7: Testfälle bei zwei Bedingungen – der Kletterwald AFB III

Ein Kletterwald berechnet Gruppenpreise: Kinder von 6 bis 11 Jahren zahlen 12 €, alle ab 12 Jahren 18 €. Kinder unter 6 dürfen nicht klettern. Ab 8 Personen gibt es 15 % Rabatt auf den Gesamtpreis, abgerundet auf ganze Cent. Eine leere Gruppe ist ungültig. Die Funktion heißt gruppenpreis_cent(alter: list[int]) -> int.

  1. Bestimme die Äquivalenzklassen und Grenzwerte für das Alter und für die Gruppengröße.
  2. Jemand sagt: „Ich teste jede Bedingung einzeln mit einer Person bzw. einer Gruppe aus Erwachsenen. Das reicht.“ Beurteile das. Finde mindestens einen Fehler, den solche Tests übersehen würden.
  3. Stelle eine möglichst kleine Menge von Testfällen auf, die alle Grenzen abdeckt, mit erwarteten Ergebnissen in Cent. Begründe die Auswahl.
  4. Programmiere die Funktion und deine Tests in zwei Dateien und lass sie laufen.
