Aufgabe 5.3.3: Eine Klasse testen – die Stempelkarte AFB II–III

Das Schülercafé gibt Stempelkarten aus: Für jedes Getränk gibt es einen Stempel, höchstens 10. Eine volle Karte (genau 10 Stempel) kann gegen ein Gratisgetränk eingelöst werden; danach hat sie wieder 0 Stempel. Auf eine volle Karte kommt kein weiterer Stempel.

# stempelkarte.py
class Stempelkarte:
    MAX_STEMPEL = 10

    def __init__(self):
        self.__stempel = 0

    def get_stempel(self) -> int:
        return self.__stempel

    def stempeln(self) -> bool:
        if self.__stempel <= Stempelkarte.MAX_STEMPEL:
            self.__stempel += 1
            return True
        return False

    def ist_voll(self) -> bool:
        return self.__stempel == Stempelkarte.MAX_STEMPEL

    def einloesen(self) -> bool:
        if self.ist_voll():
            self.__stempel = 0
            return True
        return False

  3. Führe die Tests aus, finde den Fehler und korrigiere ihn.

Aufgabe 5.3.4: Ergebnis prüfen – Schaltjahre AFB II

Ein Jahr ist ein Schaltjahr, wenn es durch 4 teilbar ist – außer es ist durch 100 teilbar. Durch 400 teilbare Jahre sind aber wieder Schaltjahre (2000 ja, 1900 nein).

# kalender.py
def ist_schaltjahr(jahr: int) -> bool:
    return jahr % 4 == 0 and jahr % 100 != 0
# test_kalender.py

def test_normales_jahr():
    assert ist_schaltjahr(2023) == False, "2023: erwartet False, tatsächlich True"

def test_vielfaches_von_4():

    assert ergebnis == True, f"2024: erwartet True, tatsächlich {ergebnis}"

def test_jahrhundert():
    ergebnis = ist_schaltjahr(1900)
    assert ergebnis == False, f"1900: erwartet False, tatsächlich {ergebnis}"

def test_vierhundert():
    ergebnis = ist_schaltjahr(2000)
    assert ergebnis == True, f"2000: erwartet True, tatsächlich {ergebnis}"

if __name__ == "__main__":

            fehler += 1

Aufgabe 5.3.6: Von Akzeptanzkriterien zu Tests – das AG-Brett AFB II

In Beispiel 1 auf Seite 5.2 stehen drei Akzeptanzkriterien für das digitale AG-Brett. Das Team hat dazu zwei Model-Klassen geschrieben:

# ag.py  (Model)
class AG:
    MAX_PLAETZE = 20

    def __init__(self, name: str, tag: str, uhrzeit: str, raum: str):
        self.name = name
        self.tag = tag
        self.uhrzeit = uhrzeit          # "HH:MM"
        self.raum = raum
        self.__belegt = 0

    def anmelden(self) -> bool:
        if self.__belegt < AG.MAX_PLAETZE:
            self.__belegt += 1
            return True
        return False

    def ist_voll(self) -> bool:
        return self.__belegt == AG.MAX_PLAETZE
# ag_brett.py  (Model)
from ag import AG

def uhrzeit_von(ag: AG) -> str:
    return ag.uhrzeit

class AGBrett:
    def __init__(self):
        self.__ags: list[AG] = []

    def hinzufuegen(self, ag: AG) -> None:
        self.__ags.append(ag)

    def ags_am(self, tag: str) -> list[AG]:
        treffer = []
        for ag in self.__ags:
            if ag.tag == tag:
                treffer.append(ag)
        return sorted(treffer, key=uhrzeit_von)
