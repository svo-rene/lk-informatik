Aufgabe 5.1.6: Fehler finden – der Lauftreff startet nicht AFB III

Der Lauftreff der Schule möchte zu jedem Lauf die Zeit und das Tempo in Minuten pro Kilometer sehen. Drei Module:

# lauf.py  (Model)
from anzeige import als_minuten

class Lauf:
    def __init__(self, strecke_m: int, zeit_s: int):
        self.__strecke_m = strecke_m
        self.__zeit_s = zeit_s

    def get_zeit(self) -> int:
        return self.__zeit_s

    def tempo(self) -> str:
        sekunden_pro_km = self.__zeit_s * 1000 // self.__strecke_m
        return als_minuten(sekunden_pro_km) + " min/km"
# anzeige.py  (View)
from lauf import Lauf

def als_minuten(sekunden: int) -> str:
    return f"{sekunden // 60}:{sekunden % 60:02d}"

def zeige(lauf: Lauf) -> None:
    print("Zeit:", als_minuten(lauf.get_zeit()), " Tempo:", lauf.tempo())
# main.py  (Controller)
from lauf import Lauf
from anzeige import zeige

zeige(Lauf(5000, 1530))

Beim Start von main.py erscheint am Ende:

ImportError: cannot import name 'Lauf' from partially initialized module 'lauf' (most likely due to a circular import)
  1. Erkläre Schritt für Schritt, was Python beim Start von main.py lädt und warum Lauf beim Import in anzeige.py noch nicht existiert.
  2. Benenne, gegen welche Regel von MVC der Entwurf verstößt.
  3. Korrigiere die Module so, dass das Model nichts aus der View importiert. Das Tempo soll das Model als ganze Zahl (Sekunden pro Kilometer) liefern. Ergänze in main.py einen kontrollierten Programmeinstieg.
  4. Prüfe: Lauf(5000, 1530) ergibt „Zeit: 25:30  Tempo: 5:06 min/km“, Lauf(10000, 3005) ergibt „Zeit: 50:05  Tempo: 5:00 min/km“.
Aufgabe 5.1.7: Beurteile – „Eine Datei reicht doch“ AFB III

Eine Dreiergruppe soll ein Programm für die Abstimmung über das Ziel der Kursfahrt schreiben: Vorschläge sammeln, jede Person der Kursliste darf genau einmal abstimmen, das Ergebnis erscheint als Tabelle und als Balken. Ole schlägt vor: „Wir schreiben alles in eine Datei kursfahrt.py. Dann gibt es keine Importfehler, und jeder sieht immer den ganzen Code.“

  1. Beurteile Oles Vorschlag. Gehe auf Übersicht, Testbarkeit, Austauschbarkeit und auf die Arbeit zu dritt an einem gemeinsamen Repository ein.
  2. Entwirf eine Aufteilung in Module nach MVC. Gib für jedes Modul an, was es enthält, welche Module es importiert und welche Person es bearbeitet.
  3. Nenne eine Situation, in der eine einzige Datei tatsächlich die bessere Wahl ist.
