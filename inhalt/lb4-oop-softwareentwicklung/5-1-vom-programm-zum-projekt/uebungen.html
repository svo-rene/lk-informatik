Aufgabe 5.1.3: Ein Programm in Module zerlegen – Weitsprung beim Sportfest AFB II–III

Beim Sportfest werden die Weitsprung-Ergebnisse bisher mit diesem Programm ausgewertet. Jede Person hat drei Versuche. Weiten unter 0 m oder über 10 m sind Tippfehler und zählen nicht.

# weitsprung.py – alles in einer Datei
class Springer:
    def __init__(self, name: str):
        self.name = name
        self.versuche = []

    def versuch(self, weite: float) -> None:
        if weite < 0 or weite > 10:
            print("ungültige Weite")
        else:
            self.versuche.append(weite)

    def bester(self) -> float:
        return max(self.versuche)

teilnehmer = []
anzahl = int(input("Wie viele Springer? "))
for i in range(anzahl):
    s = Springer(input("Name: "))
    for nr in range(3):
        s.versuch(float(input(f"Versuch {nr + 1} in m: ")))
    teilnehmer.append(s)
for s in teilnehmer:
    print(s.name, s.bester())

  3. Die View gibt eine Rangliste aus: Platz, Name und beste Weite mit zwei Nachkommastellen, die Weiteste zuerst. Personen ohne gültigen Versuch stehen am Ende ohne Platz.
  4. Teste mit den Eingaben 3, Pia (5.12, −3, 4.98), Tom (12, 13, 11), Lou (4.30, 5.05, 4.2):
