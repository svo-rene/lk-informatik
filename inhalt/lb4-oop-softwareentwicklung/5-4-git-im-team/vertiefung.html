Aufgabe 5.4.6: Beurteile – „Kein Konflikt, also alles gut“ AFB III

Ben benennt in Branch 16-getter in runde.py die Methode punkte() in get_punkte() um und passt alle Aufrufe in main.py an. Gleichzeitig schreibt Mia in Branch 17-zwischenstand in ansicht.py eine neue Funktion:

def zeige_stand(runde: Runde) -> None:
    print(f"Punkte: {runde.punkte()}")

Beide PRs zeigen keinen Konflikt, beide Reviews sind positiv, beide werden gemergt. Danach bricht das Programm ab mit

AttributeError: 'Runde' object has no attribute 'punkte'
  1. Erkläre, warum Git keinen Konflikt gemeldet hat, obwohl die beiden Änderungen nicht zusammenpassen.
  2. Beurteile die Aussage „Kein Konflikt, also alles gut“.
  3. Entwickle mindestens drei Maßnahmen für eure Gruppe, die so einen Fehler vor dem Merge sichtbar machen. Gehe auch darauf ein, was ein Reviewer vor dem Zustimmen tun sollte, wenn sich main seit der Abzweigung geändert hat.
