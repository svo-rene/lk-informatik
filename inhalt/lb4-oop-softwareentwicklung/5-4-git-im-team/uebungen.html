 1  # runde.py
 2  class Runde:
 3      def __init__(self, aufgaben):
 4          self.aufgaben = aufgaben
 5          self.richtig = 0
 6
 7      def antworten(self, nr, antwort):
 8          if self.aufgaben[nr].loesung() == antwort:
 9              self.richtig += 1
10              print("Richtig!")
11
12      def prozent(self):
13          return self.richtig / len(self.aufgaben) * 100

Mit drei Aufgaben (3·4, 6·7, 8·8) und den Aufrufen antworten(0, 12), antworten(0, 12), antworten(1, 40) liefert prozent() den Wert 66.66666666666666.

Aufgabe 5.4.5: Konflikt oder nicht? AFB II

In main steht in aufgabe.py:

1  class Aufgabe:
2      def __init__(self, a: int, b: int):
3          self.__a = a
4          self.__b = b
5
6      def text(self) -> str:
7          return f"{self.__a} · {self.__b} = ?"
8
9      def loesung(self) -> int:
10         return self.__a * self.__b

Von diesem Stand aus ändern zwei Branches:

  • Branch 14-text: Zeile 7 wird zu return f"Was ist {self.__a} mal {self.__b}?"; außerdem eine neue Datei test_aufgabe.py.
  • Branch 15-hinweis: Zeile 7 wird zu return f"{self.__a} · {self.__b} = ? (ohne Rechner)"; Zeile 10 bleibt; am Dateiende kommt eine Methode ist_leicht(self) -> bool dazu.

14-text wird zuerst gemergt.

  1. Gib für jede der drei Änderungen von 15-hinweis an, ob sie beim Merge einen Konflikt auslöst. Begründe.
  2. Gib den Ausschnitt von aufgabe.py mit Konfliktmarkierungen an, so wie Git ihn erzeugen würde.
  3. Löse den Konflikt sinnvoll und gib die Zeile 7 an.
