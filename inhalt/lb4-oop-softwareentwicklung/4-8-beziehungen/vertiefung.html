Aufgabe 4.8.6: Fehler finden – zwei Häuser, ein Raum AFB III

Im Modell einer Schulverwaltung steht: „Ein Schulgebäude besteht aus Räumen“ (Komposition, gefüllte Raute). Umgesetzt wurde das so:

class Raum:
    def __init__(self, nummer: str):
        self.nummer: str = nummer

class Schulgebaeude:
    def __init__(self, name: str, raeume: list[Raum]):
        self.name: str = name
        self.raeume: list[Raum] = raeume

r = [Raum("A101"), Raum("A102")]
haus_a = Schulgebaeude("Haus A", r)
haus_b = Schulgebaeude("Haus B", r)
haus_b.raeume.append(Raum("B001"))
print(len(haus_a.raeume))
  1. Sage die Ausgabe vorher und erkläre sie mit einem Speicherbild (Variablen, Listenobjekt, Raumobjekte, Pfeile für Verweise).
  2. Begründe, warum der Code dem Modell „Komposition“ widerspricht.
  3. Korrigiere die Klasse Schulgebaeude so, dass sie das Modell erfüllt. Nutze dazu auch Kapselung (4.6). Ein Raum soll nur über eine Methode raum_anbauen(nummer) hinzukommen.
  4. Teste: Beide Häuser werden mit der Nummernliste ["A101", "A102"] erzeugt, haus_b baut „B001“ an. Danach muss haus_a 2 Räume und haus_b 3 Räume haben.
