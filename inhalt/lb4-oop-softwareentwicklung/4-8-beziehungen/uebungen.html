Aufgabe 4.8.4: Modelliere aus einem Sachtext – Stadtbibliothek AFB II
„Die Stadtbibliothek stellt ihre Verwaltung auf eine neue Software um. Jede Leserin und jeder Leser hat einen Namen und erhält bei der Anmeldung genau einen Leserausweis mit Ausweisnummer und Ablaufdatum. Der Ausweis ist nicht übertragbar und wird bei der Abmeldung vernichtet. Die Bibliothek besitzt Medien mit Titel und Signatur. Für Themenwochen stellt das Team Themenregale zusammen (z. B. „Klimawandel“), in die vorhandene Medien gestellt werden. Nach der Themenwoche wird das Regal aufgelöst, die Medien bleiben im Bestand. Leserinnen und Leser können Medien ausleihen und zurückgeben und wissen jederzeit, welche Medien sie gerade ausgeliehen haben.“
  1. Bestimme die Klassen mit ihren Attributen und Methoden. Unterstreiche dazu im Text Substantive (Kandidaten für Klassen und Attribute) und Verben (Kandidaten für Methoden).
  2. Bestimme für jede Beziehung, ob es eine Assoziation, Aggregation oder Komposition ist. Begründe jeweils mit einer Textstelle und zeichne das Klassendiagramm.
  3. Implementiere die Klassen so, dass man die Beziehungsart am Code erkennt (Wo wird das Teil erzeugt? Wird ein Verweis übergeben?).

Aufgabe 4.8.5: Code in UML übersetzen – Smartphone AFB II 
class Akku:
    def __init__(self, kapazitaet_mah: int):
        self.kapazitaet_mah: int = kapazitaet_mah

class Ladegeraet:
    def __init__(self, watt: int):
        self.watt: int = watt

class Kontakt:
    def __init__(self, name: str, nummer: str):
        self.name: str = name
        self.nummer: str = nummer

class Smartphone:
    def __init__(self, modell: str, kapazitaet_mah: int):
        self.modell: str = modell
        self.akku: Akku = Akku(kapazitaet_mah)
        self.ladegeraet: Ladegeraet | None = None
        self.kontakte: list[Kontakt] = []

    def anschliessen(self, geraet: Ladegeraet) -> None:
        self.ladegeraet = geraet

    def trennen(self) -> None:
        self.ladegeraet = None

    def kontakt_speichern(self, kontakt: Kontakt) -> None:
        self.kontakte.append(kontakt)
