Aufgabe 4.5.5: Fehler finden – das Leihrad mit Akku AFB III

Der Verleih von E-Bikes prüft vor jeder Ausleihe, ob ein Rad genug Akku hat. Pro Kilometer verbraucht ein Rad 2 % Akku, fahrbereit ist es ab 20 %. Das Programm soll für ein Rad mit 80 % Akku nach 34 km Rad 4 muss an die Ladestation ausgeben.

class Leihrad:
    def __init__(self, nummer, akku):
        self.nummer = nummer
        self.akku = akku          # Ladestand in Prozent

    def fahren(km):
        self.akku = self.akku - 2 * km

    def reichweite(self):
        print(self.akku // 2)

    def ist_fahrbereit(self):
        return self.akku >= 20

rad = Leihrad(4, 80)
rad.fahren(34)
rest = rad.reichweite()
if rest > 5 and rad.ist_fahrbereit:
    print("Rad", rad.nummer, "kann ausgeliehen werden")
else:
    print("Rad", rad.nummer, "muss an die Ladestation")
