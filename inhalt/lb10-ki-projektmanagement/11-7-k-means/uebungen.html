Aufgabe 11.7.8: Eine k-Means-Iteration programmieren AFB II

Schreibe in Python (ohne Bibliotheken außer math) zwei Funktionen für die beiden Schritte einer Iteration:

  • zuordnen(punkte, zentren) gibt eine Liste zurück, die für jeden Punkt den Index des nächstgelegenen Zentrums enthält.
  • neue_zentren(punkte, zuordnung, k) gibt die Liste der neuen Zentren (Mittelwerte) zurück.

Teste mit den Punkten aus Beispiel 2: punkte = [(1, 1), (2, 1), (1, 3), (5, 4), (6, 5), (6, 3)]

Eingabeerwartete Ausgabetatsächliche Ausgabe
zuordnen(punkte, [(1, 1), (2, 1)])[0, 1, 0, 1, 1, 1]
neue_zentren(punkte, [0, 1, 0, 1, 1, 1], 2)[(1.0, 2.0), (4.75, 3.25)]
zuordnen(punkte, [(1.0, 2.0), (4.75, 3.25)])[0, 0, 0, 1, 1, 1]
