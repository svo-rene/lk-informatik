1. Was ist lineare Regression?

Der Spam-Filter aus Seite 11.3 sagt eine Kategorie voraus: „Spam“ oder „kein Spam“. Man nennt das Klassifikation. Auch viele Verfahren, die du in den nächsten Kapiteln kennenlernst (Entscheidungsbäume, k-Nächste-Nachbarn), sind Klassifikationsverfahren. Die lineare Regression ist anders: Sie sagt keine Kategorie, sondern eine Zahl voraus, die theoretisch beliebig viele Werte annehmen kann. Man spricht deshalb von Regression.

Beispiele für Vorhersagen einer Zahl:

  • Wie viele Punkte wird ein Schüler in der Klausur erreichen, wenn er eine bestimmte Anzahl Stunden gelernt hat?
  • Wie hoch wird der Verkaufspreis einer Immobilie mit einer bestimmten Wohnfläche sein?
  • Wie hoch wird die Temperatur morgen Mittag sein?

In diesem Kapitel begleitet uns ein durchgehendes Beispiel: Wir wollen aus der Lernzeit (in Stunden) die zu erwartende Klausurpunktzahl vorhersagen.

2. Die Gerade: y = m·x + b

Die lineare Regression geht davon aus, dass zwischen einer Eingabe x (z. B. Lernstunden) und einer Ausgabe y (z. B. Klausurpunkte) ein linearer, also geradliniger Zusammenhang besteht. Dieser Zusammenhang lässt sich durch eine Geradengleichung beschreiben:

y = m · x + b

  • m ist die Steigung: Um wie viel steigt (oder sinkt) y, wenn x um 1 zunimmt? Bei unserem Beispiel: Um wie viele Punkte verbessert sich die Klausur pro zusätzlicher Lernstunde?
  • b ist der Achsenabschnitt (y-Achsenabschnitt): der Wert von y, wenn x = 0 ist. Bei unserem Beispiel: Wie viele Punkte werden ganz ohne Lernen im Schnitt erreicht?
Einfaches Beispiel: Wäre m = 3 und b = 40, würde die Gerade lauten: y = 3·x + 40. Ein Schüler, der 5 Stunden lernt, würde dann eine Punktzahl von 3 · 5 + 40 = 55 vorhergesagt bekommen.

3. Wie findet der Algorithmus die beste Gerade?

Durch eine Punktwolke aus echten Messwerten lassen sich unendlich viele Geraden legen. Der Algorithmus muss also entscheiden, welche Gerade „am besten passt“. Dazu wird für jeden Datenpunkt der Fehler (auch Residuum genannt) berechnet: der senkrechte Abstand zwischen dem tatsächlichen y-Wert und dem von der Gerade vorhergesagten y-Wert.

Damit sich positive und negative Abweichungen nicht gegenseitig aufheben, werden die Fehler quadriert und anschließend aufsummiert. Man erhält so die Fehlerquadratsumme (Sum of Squared Errors, SSE). Die Gerade mit der kleinsten Fehlerquadratsumme wird gewählt – daher der Name Methode der kleinsten Quadrate.

SSE = Σ (y_tatsächlich − y_vorhergesagt)²

3.1 Beispielrechnung

Gegeben seien vier Datenpunkte (Lernstunden x, tatsächlich erreichte Punktzahl y):

x (Stunden)y (Punkte)
13
25
36
48

Wir testen zunächst die Gerade y = 1,5·x + 2:

  • x = 1: vorhergesagt 1,5·1 + 2 = 3,5 → tatsächlich 3 → Fehler = −0,5 → Quadrat = 0,25
  • x = 2: vorhergesagt 1,5·2 + 2 = 5 → tatsächlich 5 → Fehler = 0 → Quadrat = 0
  • x = 3: vorhergesagt 1,5·3 + 2 = 6,5 → tatsächlich 6 → Fehler = −0,5 → Quadrat = 0,25
  • x = 4: vorhergesagt 1,5·4 + 2 = 8 → tatsächlich 8 → Fehler = 0 → Quadrat = 0

SSE = 0,25 + 0 + 0,25 + 0 = 0,5

Zum Vergleich testen wir die Gerade y = 1·x + 3:

  • x = 1: vorhergesagt 4 → tatsächlich 3 → Fehler = −1 → Quadrat = 1
  • x = 2: vorhergesagt 5 → tatsächlich 5 → Fehler = 0 → Quadrat = 0
  • x = 3: vorhergesagt 6 → tatsächlich 6 → Fehler = 0 → Quadrat = 0
  • x = 4: vorhergesagt 7 → tatsächlich 8 → Fehler = 1 → Quadrat = 1

SSE = 1 + 0 + 0 + 1 = 2

Da 0,5 kleiner ist als 2, passt die erste Gerade (y = 1,5·x + 2) besser zu den Datenpunkten.

3.2 Die optimale Gerade direkt berechnen

Der Algorithmus probiert allerdings nicht einzelne Geraden aus, sondern berechnet die Gerade mit der kleinsten Fehlerquadratsumme direkt mit zwei Formeln. Dabei sind x̄ und ȳ die Mittelwerte der x- bzw. y-Werte:

m = Σ (x − x̄)·(y − ȳ) / Σ (x − x̄)²  und  b = ȳ − m · x̄

Beispiel 1 einfach

Ausgangssituation: Gesucht ist die optimale Gerade für die vier Punkte aus 3.1: (1|3), (2|5), (3|6), (4|8).

  1. Mittelwerte berechnen: x̄ = (1 + 2 + 3 + 4) / 4 = 2,5 und ȳ = (3 + 5 + 6 + 8) / 4 = 5,5 – warum: Beide Formeln arbeiten mit den Abweichungen vom Mittelwert.
  2. Zähler bilden: Σ (x − x̄)·(y − ȳ) = (−1,5)·(−2,5) + (−0,5)·(−0,5) + 0,5·0,5 + 1,5·2,5 = 3,75 + 0,25 + 0,25 + 3,75 = 8 – warum: Der Zähler misst, wie stark x und y gemeinsam steigen oder fallen.
  3. Nenner bilden: Σ (x − x̄)² = 2,25 + 0,25 + 0,25 + 2,25 = 5 – warum: Der Nenner misst die Streuung der x-Werte.
  4. Steigung und Achsenabschnitt: m = 8 / 5 = 1,6 und b = 5,5 − 1,6 · 2,5 = 1,5 – warum: Die Formel für b sorgt dafür, dass die Gerade durch den Schwerpunkt (x̄|ȳ) verläuft.
  5. Fehlermaß berechnen: Vorhersagen: 3,1; 4,7; 6,3; 7,9 → Fehler −0,1; 0,3; −0,3; 0,1 → SSE = 0,01 + 0,09 + 0,09 + 0,01 = 0,2 – warum: Erst die SSE zeigt, wie gut die Gerade wirklich passt.

Ergebnis: Die optimale Gerade lautet also y = 1,6·x + 1,5 mit SSE = 0,2.

Kontrolle: Die SSE ist kleiner als bei beiden getesteten Geraden aus 3.1 (0,5 und 2) – und keine andere Gerade erreicht einen kleineren Wert. Außerdem liegt der Schwerpunkt auf der Geraden: 1,6 · 2,5 + 1,5 = 5,5 = ȳ.

Beispiel 2 komplex

Ausgangssituation: Der Schulkiosk will vorhersagen, wie viele Eis er an einem Tag verkauft. Die Schülerfirma hat an fünf Tagen notiert:

Höchsttemperatur x (°C)1418222630
verkaufte Eis y2028344450
  1. Mittelwerte: x̄ = 110 / 5 = 22 und ȳ = 176 / 5 = 35,2 – warum: Grundlage beider Formeln.
  2. Abweichungen tabellieren: x − x̄ = −8; −4; 0; 4; 8 und y − ȳ = −15,2; −7,2; −1,2; 8,8; 14,8 – warum: Eine Tabelle verhindert Vorzeichenfehler, die Hauptfehlerquelle bei dieser Rechnung.
  3. Summen: Σ (x − x̄)·(y − ȳ) = 121,6 + 28,8 + 0 + 35,2 + 118,4 = 304 und Σ (x − x̄)² = 64 + 16 + 0 + 16 + 64 = 160 – warum: Zähler und Nenner der Steigungsformel.
  4. Gerade bestimmen: m = 304 / 160 = 1,9 und b = 35,2 − 1,9 · 22 = −6,6, also y = 1,9·x − 6,6 – warum: Methode der kleinsten Quadrate.
  5. Deuten: Pro Grad mehr verkauft der Kiosk im Mittel 1,9 Eis mehr – warum: Die Steigung ist die eigentlich interessante Aussage des Modells.
  6. Fehlermaß: Vorhersagen 20; 27,6; 35,2; 42,8; 50,4 → Fehler 0; 0,4; −1,2; 1,2; −0,4 → SSE = 0 + 0,16 + 1,44 + 1,44 + 0,16 = 3,2 – warum: Die Fehler sind klein, die Gerade passt gut.
  7. Vorhersage: Für 25 °C: 1,9 · 25 − 6,6 = 40,9, also etwa 41 Eis – warum: 25 °C liegt innerhalb des Datenbereichs (14–30 °C), die Vorhersage ist daher vertrauenswürdig.
  8. Falle 1 – Extrapolation: Für 0 °C ergäbe sich 1,9 · 0 − 6,6 = −6,6 Eis. Negative Verkaufszahlen sind unmöglich – warum: Außerhalb des Datenbereichs gilt der lineare Zusammenhang nicht mehr; b hat hier keine sinnvolle Bedeutung.
  9. Falle 2 – Ausreißer: Nimmt man einen sechsten Tag hinzu (28 °C, nur 12 Eis, weil Wandertag war), liefert dieselbe Rechnung m ≈ 0,99 und b ≈ 8,58. Für 25 °C sagt das Modell dann nur noch etwa 33 Eis voraus – warum: Durch das Quadrieren hat der große Fehler des Ausreißers enormes Gewicht und zieht die Gerade flach (vgl. Abschnitt 6).

Ergebnis: y = 1,9·x − 6,6; Vorhersage für 25 °C: etwa 41 Eis. Untypische Tage (Wandertag, Ferien) sollte man vor dem Training aus den Daten entfernen oder gesondert erfassen, und Vorhersagen nur im Datenbereich treffen.

Kontrolle: Schwerpunkt: 1,9 · 22 − 6,6 = 35,2 = ȳ ✓; die Fehler summieren sich zu 0 + 0,4 − 1,2 + 1,2 − 0,4 = 0 ✓ (das gilt für die Regressionsgerade immer).

Hinweis: Warum quadrieren und nicht einfach den Betrag nehmen?

Durch das Quadrieren werden große Fehler überproportional stark bestraft – ein Ausreißer mit Fehler 4 zählt (16) viel schwerer als vier kleine Fehler von je 1 (zusammen 4). Außerdem lässt sich die Fehlerquadratsumme mathematisch besonders einfach minimieren; daraus ergeben sich die beiden Formeln oben.

4. Gütemaß R² (Bestimmtheitsmaß)

Um zu beurteilen, wie gut eine Regressionsgerade insgesamt zu den Daten passt, verwendet man häufig das Bestimmtheitsmaß R². Es liegt (normalerweise) zwischen 0 und 1:

  • R² = 0: Das Modell erklärt die Daten überhaupt nicht – die Gerade sagt nicht besser vorher als einfach immer der Durchschnittswert.
  • R² = 1: perfekte Vorhersage – alle Datenpunkte liegen exakt auf der Geraden.
  • Werte dazwischen, z. B. R² = 0,8, bedeuten, dass das Modell 80 % der Streuung in den Daten erklären kann.

Eine genaue Herleitung der Formel ist an dieser Stelle nicht nötig – wichtig ist nur, den Wert richtig zu interpretieren: Je näher R² an 1 liegt, desto besser passt die Gerade zu den Daten.

5. Bezug zu Overfitting und Underfitting

Auch bei der linearen Regression gibt es die aus Seite 11.3 „KI-Systeme: Training und Optimierung“ bekannten Probleme Overfitting und Underfitting:

  • Underfitting: Eine einfache Gerade kann komplizierte, geschwungene Zusammenhänge nicht abbilden. Sie erfasst die Muster in den Daten nur unzureichend.
  • Overfitting: Ersetzt man die Gerade durch ein Polynom hoher Ordnung (z. B. Grad 8 statt Grad 1), schlängelt sich die Kurve durch jeden einzelnen Trainingspunkt. Das sieht auf den Trainingsdaten perfekt aus, versagt aber bei neuen, unbekannten Daten, weil das Modell sich jede Kleinigkeit der Trainingsdaten „gemerkt“ hat, statt das grundlegende Muster zu lernen. Dasselbe Phänomen begegnet dir später bei zu tiefen Entscheidungsbäumen (11.5).

6. Vor- und Nachteile der linearen Regression

Vorteile

  • einfach zu verstehen, zu berechnen und zu interpretieren (Steigung und Achsenabschnitt haben eine klare Bedeutung)
  • wenig Rechenaufwand, funktioniert auch mit wenigen Datenpunkten
  • gut geeignet als erster Ansatz, um einen Zusammenhang grob abzuschätzen

Nachteile

  • funktioniert nur gut, wenn der tatsächliche Zusammenhang (annähernd) linear ist
  • Bei stark gekrümmten Zusammenhängen liefert eine Gerade schlechte Vorhersagen (Underfitting).
  • empfindlich gegenüber Ausreißern, da diese die Fehlerquadratsumme stark beeinflussen

7. Anwendungsbeispiele

  • Immobilienpreis-Schätzung: Vorhersage des Verkaufspreises anhand von Wohnfläche, Lage oder Baujahr
  • Umsatzprognose: Vorhersage des Umsatzes eines Unternehmens anhand von Werbeausgaben oder Kundenzahl
  • Temperaturvorhersage: Schätzung der Temperatur anhand vergangener Messwerte oder der Jahreszeit
  • Klausurpunktzahl: Vorhersage der Punktzahl anhand der investierten Lernzeit (unser Beispiel)
Praxisbezug: Prognosen im Beruf

Alltag: Die geschätzte Ankunftszeit deiner Navigations-App oder der Reichweitenrechner eines E-Autos beruhen auf Regressionsmodellen.

Beruf: Data Scientists in Energieversorgern sagen z. B. den Strombedarf des nächsten Tages aus Temperatur und Wochentag voraus; im Handel wird der Absatz von Produkten prognostiziert, um die Lagerhaltung zu planen. Die lineare Regression ist dabei oft das erste Referenzmodell, an dem sich komplexere Verfahren messen lassen müssen.

Das Wichtigste

Klassifikation: sagt eine Kategorie voraus, z. B. „bestanden“ oder „nicht bestanden“.

Regression: sagt eine Zahl voraus, z. B. „87 Punkte“. Die lineare Regression ist das einfachste Regressionsverfahren.

Methode der kleinsten Quadrate: Gewählt wird die Gerade, bei der die Summe der quadrierten senkrechten Abstände zwischen Datenpunkten und Gerade am kleinsten ist.

Muster statt Rauschen: Ein Modell soll das zugrunde liegende Muster erfassen, nicht das Rauschen der Trainingsdaten auswendig lernen. Ein höherer Polynomgrad ist nicht automatisch besser.
