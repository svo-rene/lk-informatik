Aufgabe 11.6.5: Fehler finden – ein fehlerhaftes k-NN-Programm AFB III

Jonas hat k-NN in Python programmiert. Beim Test mit den Daten aus Beispiel 1 stürzt sein Programm ab.

import math

def abstand(p, q):
    return math.sqrt((p[0] - q[0]) + (p[1] - q[1]))

def knn(trainingsdaten, punkt, k):
    liste = []
    for (x, y, klasse) in trainingsdaten:
        liste.append((abstand((x, y), punkt), klasse))
    liste.sort(reverse=True)
    stimmen = {}
    for i in range(k):
        klasse = liste[i][1]
        stimmen[klasse] = stimmen.get(klasse, 0) + 1
    beste = None
    for klasse in stimmen:
        if beste is None or stimmen[klasse] > stimmen[beste]:
            beste = klasse
    return beste

daten = [(1, 1, "Rot"), (2, 4, "Rot"), (3, 6, "Rot"), (6, 5, "Blau"),
         (7, 3, "Blau"), (8, 8, "Blau"), (4, 1, "Rot")]
print(knn(daten, (5, 5), 3))
  1. Finde die beiden Fehler. Erkläre jeweils, welche Auswirkung der Fehler hat, und korrigiere ihn.
  2. Teste das korrigierte Programm mit folgenden Fällen und trage die tatsächliche Ausgabe ein:
    Eingabeerwartete Ausgabetatsächliche Ausgabe
    knn(daten, (5, 5), 1)Blau
    knn(daten, (5, 5), 3)Blau
    knn(daten, (5, 5), 5)Rot
  3. Bei k = 4 steht es 2 : 2. Welche Klasse gibt das korrigierte Programm aus? Begründe am Code, welche Gleichstandsregel aus Abschnitt 3.4 es dadurch (zufällig) umsetzt.
Aufgabe 11.6.6: Das richtige k wählen AFB III

k13715501
Accuracy Trainingsdaten100 %94 %89 %84 %62 %
Accuracy Validierungsdaten78 %86 %88 %83 %60 %
  1. Erkläre, warum die Trainings-Accuracy bei k = 1 zwangsläufig 100 % beträgt.
  2. Deute die Werte bei k = 501. Was sagt das Modell hier vermutlich für jedes Bild vorher?
