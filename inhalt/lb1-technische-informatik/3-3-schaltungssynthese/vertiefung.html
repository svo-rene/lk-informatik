Aufgabe 3.3.5: Fehler beim Ausklammern – der Rollladen AFB III

Ein Smart-Home-Rollladen soll abends automatisch herunterfahren. Eingänge (1 = trifft zu): A = Automatik eingeschaltet, B = es ist dunkel, C = Terrassentür geschlossen, D = Person auf der Terrasse erkannt. Anforderung: Der Rollladen fährt herunter, wenn die Automatik an ist und es dunkel ist – aber nicht, wenn dabei die Terrassentür offen steht und jemand auf der Terrasse ist (sonst wäre die Person ausgesperrt).

Paul hat so gearbeitet:

  1. Aus der Wahrheitstabelle: f = (A ∧ B ∧ C) ∨ (A ∧ B ∧ ¬D)
  2. Ausklammern: f = A ∧ B ∧ C ∨ ¬D
  3. Schaltung: UND(A, B, C) und NICHT(D) gehen in ein ODER-Gatter – nur 3 Gatter.
  4. Test in LogicSim mit A = B = C = 1, D = 0 und mit A = B = 1, C = 0, D = 1: beide Male richtig.
  1. Prüfe, ob Pauls Ausdruck aus Schritt 1 die Anforderung richtig wiedergibt.
  2. Finde den Fehler in Schritt 2 und gib alle Belegungen an, bei denen Pauls Schaltung falsch reagiert. Beschreibe, was der Rollladen dann tut.
  3. Gib die korrekte vereinfachte Funktion und Schaltung an. Wie viele Gatter braucht sie?
  4. Beurteile Pauls Testvorgehen in Schritt 4 und schlage ein besseres vor.
