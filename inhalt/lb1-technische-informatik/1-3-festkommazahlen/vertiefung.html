Aufgabe 1.3.6: Fehler finden in einer Umrechnung AFB III

Max soll 6,3 in eine binäre Festkommazahl mit 8 Bit Bruchteil umwandeln. Seine Lösung:

Ganzzahlteil:  6 = 110

Bruchteil:     0,3 · 2 = 0,6  →  0
               0,6 · 2 = 1,2  →  1
               0,2 · 2 = 0,4  →  0
               0,4 · 2 = 0,8  →  0
               0,8 · 2 = 1,6  →  1
               0,6 · 2 = 1,2  →  1
               0,2 · 2 = 0,4  →  0
               0,4 · 2 = 0,8  →  0

Wie beim Ganzzahlteil von unten nach oben gelesen: 00110010
Ergebnis: 6,3 = 110,00110010

Bemerkung: Der gespeicherte Wert ist etwas größer als 6,3, weil gerundet
wurde. Mit 12 Bit Bruchteil wäre 6,3 exakt darstellbar.
  1. Finde alle Fehler in der Lösung und erkläre jeweils, warum es ein Fehler ist.
  2. Gib die richtige Darstellung an und berechne den tatsächlich gespeicherten Dezimalwert und die Abweichung von 6,3.
  3. Berechne, welchen Wert Max' falsches Bitmuster darstellt. Beschreibe, wie Max seinen Fehler mit einer Probe selbst hätte entdecken können.
Aufgabe 1.3.7: 16 Bit für eine Küchenwaage AFB III

Eine digitale Küchenwaage soll Gewichte von 0 bis 5 kg auf 1 g genau anzeigen. Für den Messwert steht ein vorzeichenloses 16-Bit-Register zur Verfügung. Drei Vorschläge liegen vor:

VorschlagEinheitGanzzahlteilBruchteil
AKilogramm8 Bit8 Bit
BKilogramm3 Bit13 Bit
CGramm16 Bit0 Bit (ganze Zahl)
  1. Bestimme für jeden Vorschlag den größten darstellbaren Wert und die Auflösung (kleinster Abstand) in Gramm.
  2. Beurteile die drei Vorschläge anhand der Anforderungen und gib eine begründete Empfehlung ab.
