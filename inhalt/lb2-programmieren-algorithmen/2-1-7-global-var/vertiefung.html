Aufgabe 2.1.7.5: Fehler finden – Namen, die sich in die Quere kommen AFB III

Programm A soll das Maximum einer Liste bestimmen und danach noch zwei Zahlen vergleichen:

werte = [4, 9, 2]
max = 0
for w in werte:
    if w > max:
        max = w
print("Maximum:", max)
print("Größere Zahl:", max(3, 7))

Programm B zählt gerade Zahlen. Ein Mitschüler testet zweimal hintereinander:

anzahl = 0

def zaehle_gerade(liste):
    global anzahl
    for x in liste:
        if x % 2 == 0:
            anzahl = anzahl + 1
    return anzahl

print(zaehle_gerade([2, 4, 5]))   # erwartet: 2
print(zaehle_gerade([6, 7]))      # erwartet: 1
  1. Gib für beide Programme die tatsächliche Ausgabe an und erkläre die Ursache mit dem Begriff Gültigkeitsbereich.
  2. Bei Programm B ist der erste Test grün, der zweite rot. Vertauscht man die Reihenfolge der beiden Tests, ändern sich die Ergebnisse. Begründe, warum das ein deutliches Warnsignal ist.
  3. Korrigiere beide Programme und lege für zaehle_gerade eine Testtabelle (Eingabe | erwartete Ausgabe | tatsächliche Ausgabe) mit [2, 4, 5], [6, 7], [], [-2, -3] und [0] an.
