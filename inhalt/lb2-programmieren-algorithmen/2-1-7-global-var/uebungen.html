Aufgabe 2.1.7.4: Ergebnis vorhersagen AFB II

Bestimme die vier Ausgabezeilen, ohne das Programm auszuführen. Gib bei jedem Aufruf an, ob x in der Funktion lokal oder global ist.

x = 10

def a():
    x = 20
    return x

def b():
    return x + 1

def c():
    global x
    x = x * 2
    return x

print(a(), x)
print(b(), x)
print(c(), x)
print(b(), a())

In einer print-Zeile werden die Argumente von links nach rechts ausgewertet.

Aufgabe 2.1.7.6: Kiosk-Kasse ohne global AFB II 
kasse = 0.0
verkauft = []

def verkaufe(artikel, preis):
    global kasse
    kasse = kasse + preis
    verkauft.append(artikel)

verkaufe("Brezel", 1.20)
verkaufe("Saft", 1.50)
print(kasse, verkauft)
  1. Gib die Ausgabe an. Erkläre, warum kasse mit global gekennzeichnet werden muss, verkauft aber nicht.
  2. Schreibe verkaufe so um, dass keine globale Variable mehr benutzt wird: Kassenstand und Liste werden als Parameter übergeben, der neue Kassenstand wird zurückgegeben.
  3. Teste mit einer Tabelle: zwei Verkäufe (wie oben), kein Verkauf, ein Verkauf mit Preis 0 und ein Verkauf mit dem Preis "1,20".

Kommazahlen werden intern binär gespeichert. 1.2 + 1.5 ergibt in Python 2.7, andere Summen zeigen aber Rundungsreste. Geldbeträge rechnet man deshalb oft in Cent.
