Aufgabe 2.2.7.3: Ergebnis vorhersagen mit Aufrufstapel AFB II

Bestimme die Ausgaben, ohne die Programme auszuführen.

# Programm A
def a(n):
    if n == 0:
        print("Boden")
        return 1
    print("ab", n)
    ergebnis = 2 * a(n - 1)
    print("auf", n)
    return ergebnis

print(a(3))

# Programm B
def b(text):
    if len(text) <= 1:
        return text
    return b(text[1:]) + text[0]

print(b("Abi"))
  1. Notiere alle Ausgabezeilen von Programm A in der richtigen Reihenfolge.
  2. Zeichne für Programm A den Aufrufstapel zu dem Zeitpunkt, an dem „Boden“ ausgegeben wird. Gib die Rekursionstiefe an.
  3. Bestimme die Ausgabe von Programm B. Beschreibe, was b allgemein leistet, und gib b("") und b("x") an.

text[1:] ist der Text ab dem zweiten Zeichen, text[0] das erste Zeichen.

Aufgabe 2.2.7.6: Rekursiv und iterativ im Vergleich AFB II
  1. Schreibe eine rekursive Funktion quersumme(n). Es gilt: Die Quersumme von n ist n % 10 plus die Quersumme von n // 10. Für negative n wird die Quersumme des Betrags berechnet, bei einem anderen Typ als int wird None zurückgegeben.
  2. Schreibe eine rekursive Funktion ist_palindrom(text), die Groß- und Kleinschreibung ignoriert: Ein Text ist ein Palindrom, wenn erstes und letztes Zeichen übereinstimmen und der Rest dazwischen ein Palindrom ist.
  3. Teste beide:
    Eingabeerwartete Ausgabetatsächliche Ausgabe

    quersumme(7)
    quersumme(-1234)
    quersumme("12")
    ist_palindrom("Anna")
    ist_palindrom("Abi")
    ist_palindrom("")
  4. Gib für beide Funktionen die Rekursionstiefe in Abhängigkeit von der Eingabe an und schreibe quersumme zusätzlich iterativ.
