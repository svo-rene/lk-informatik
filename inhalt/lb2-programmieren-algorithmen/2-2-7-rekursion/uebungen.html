Kurz geprüft 3: Basisfall und Rekursionsschritt AFB I

Schreibe die Kette der Aufrufe für sum_recursion(4) auf. Was ist das Ergebnis? Welcher Aufruf ruft sich nicht mehr selbst auf?

Lösung zeigen

sum_recursion(4) = 4 + sum_recursion(3) = 4 + 3 + sum_recursion(2) = … = 4 + 3 + 2 + 1 + sum_recursion(0) = 10. sum_recursion(0) ist der Basisfall und gibt direkt 0 zurück.

Kurz geprüft 4: Wie hoch wird der Stapel? AFB I

Wie viele Aufrufe liegen bei sum_recursion(5) höchstens gleichzeitig auf dem Aufrufstapel? Welcher Aufruf wird als erster fertig, welcher als letzter?

Lösung zeigen

6 Aufrufe (n = 5, 4, 3, 2, 1, 0). Als erster wird sum_recursion(0) fertig, als letzter sum_recursion(5) – er wurde zuerst aufgerufen und wartet am längsten.

Kurz geprüft 5: Endet das? AFB II 
def schritte(n):
    if n == 0:
        return 0
    return 1 + schritte(n - 2)

Für welche Werte von n liefert schritte(n) ein Ergebnis, für welche gibt es einen RecursionError? Wie lässt sich die Funktion absichern?

Lösung zeigen

Nur für gerade n ≥ 0 wird 0 genau getroffen (z. B. 6, 4, 2, 0 → Ergebnis 3). Bei ungeraden oder negativen n springt n an 0 vorbei (z. B. 3, 1, −1, −3, …) – RecursionError. Absichern mit if n <= 0: als Basisfall.

Aufgabe 2.2.7.3: Ergebnis vorhersagen mit Aufrufstapel AFB II

Bestimme die Ausgaben, ohne die Programme auszuführen.

# Programm A
def a(n):
    if n == 0:
        print("Boden")
        return 1
    print("ab", n)
    ergebnis = 2 * a(n - 1)
    print("auf", n)
    return ergebnis

print(a(3))

# Programm B
def b(text):
    if len(text) <= 1:
        return text
    return b(text[1:]) + text[0]

print(b("Abi"))
  1. Notiere alle Ausgabezeilen von Programm A in der richtigen Reihenfolge.
  2. Zeichne für Programm A den Aufrufstapel zu dem Zeitpunkt, an dem „Boden“ ausgegeben wird. Gib die Rekursionstiefe an.
  3. Bestimme die Ausgabe von Programm B. Beschreibe, was b allgemein leistet, und gib b("") und b("x") an.

text[1:] ist der Text ab dem zweiten Zeichen, text[0] das erste Zeichen.
