Aufgabe 2.2.5.7: Fehler finden und Ergebnis prüfen AFB III

Programm A ist ein Insertionsort, der Elemente verschiebt statt zu tauschen:

def insertion_sort_a(liste):
    for i in range(1, len(liste)):
        wert = liste[i]
        j = i - 1
        while j > 0 and liste[j] > wert:
            liste[j + 1] = liste[j]
            j = j - 1
        liste[j + 1] = wert
    return liste

Programm B soll ein Selectionsort sein:

def selection_sort_b(liste):
    n = len(liste)
    for i in range(n - 1):
        for j in range(i + 1, n):
            if liste[j] < liste[i]:
                temp = liste[i]
                liste[i] = liste[j]
                liste[j] = temp
    return liste
