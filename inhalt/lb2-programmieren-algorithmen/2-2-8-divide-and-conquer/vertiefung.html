Aufgabe 2.2.8.6: Fehler finden – zwei Fehler in der binären Suche AFB III 
def binaere_suche(liste, gesucht):
    links = 0
    rechts = len(liste) - 1
    while links < rechts:
        mitte = (links + rechts) // 2
        if liste[mitte] == gesucht:
            return mitte
        elif gesucht < liste[mitte]:
            rechts = mitte - 1
        else:
            links = mitte
    return -1

Aufgabe 2.2.8.7: Lohnt sich das Sortieren? AFB III

Das Schulverwaltungsprogramm einer Schule mit 1200 Schülerinnen und Schülern sucht Datensätze nach Namen. Bisher wird linear gesucht. Ein Entwickler schlägt vor, die Liste einmal zu sortieren (etwa n · log2 n Vergleiche) und danach binär zu suchen.

  1. Berechne für den schlechtesten Fall, ab wie vielen Suchen pro Tag sich der Vorschlag lohnt, wenn jeden Morgen neu sortiert werden muss.
  2. Im Laufe des Tages kommen neue Schüler hinzu. Beurteile, wie man die Liste sortiert hält, ohne jedes Mal komplett neu zu sortieren, und welchen Aufwand das Einfügen hat.
  3. Eine Mitschülerin meint: „Die binäre Suche ist gar kein richtiges Divide and Conquer, denn es wird nichts kombiniert.“ Nimm Stellung.
