Aufgabe 2.1.4.4: Ergebnis vorhersagen AFB II

Notiere den Zustand der Liste nach jeder Zeile und die drei Ausgaben, ohne das Programm auszuführen. Prüfe danach am Rechner.

werte = [4, 7, 1, 7, 3]
werte.append(werte[1] + werte[-1])
werte.insert(0, werte.pop())
werte.remove(7)
print(werte)
print(len(werte), werte[2], werte[-2])
summe = 0
i = 0
while i < len(werte):
    if werte[i] % 2 == 1:
        summe = summe + werte[i]
    i = i + 2
print(summe)

In Zeile 3 wird zuerst das Argument werte.pop() ausgewertet, danach erst eingefügt.
