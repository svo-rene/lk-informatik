Wiederholung: Ein Algorithmus ist eine präzise Handlungsvorschrift zur Lösung eines Problems. Er besteht aus einer endlichen Folge eindeutig beschriebener Schritte, die in einer festgelegten Reihenfolge ausgeführt werden. Ein Kochrezept oder die Anleitung für einen Pizzateig sind alltägliche Beispiele – allerdings sind sie selten wirklich eindeutig („eine Prise Salz“).

Neu: In der Oberstufe wird der Algorithmusbegriff präzisiert. Zu den bekannten Eigenschaften Endlichkeit, Eindeutigkeit und Ausführbarkeit kommen weitere, genauer gefasste Voraussetzungen hinzu.

Hinweis: Nicht jedes Programm erfüllt alle Eigenschaften

Ein Betriebssystem oder ein Webserver soll absichtlich nicht terminieren. Ein Programm, das mit random würfelt, ist nicht determiniert. Solche Verfahren sind trotzdem nützlich; man spricht dann von einem erweiterten Algorithmusbegriff, bei dem einzelne Eigenschaften bewusst gelockert werden.

Beispiel 1 einfach

Ausgangssituation: Der Algorithmus „Addiere die Zahlen von 1 bis n“ soll auf alle sechs Eigenschaften geprüft werden.

def summe_bis(n):
    s = 0
    for i in range(1, n + 1):
        s = s + i
    return s

print(summe_bis(4))     # 10
  1. Finitheit: Die Beschreibung besteht aus wenigen Zeilen. Sie ist also endlich lang.
  2. Dynamische Finitheit: Während der Ausführung gibt es nur die drei Variablen n, s und i. Es kommt kein Speicher hinzu, egal wie lange die Schleife läuft.
  3. Ausführbarkeit: Jeder Schritt ist eine Addition oder Zuweisung. Das kann der Rechner immer ausführen.
  4. Terminierung: Die for-Schleife läuft genau n-mal. Danach endet die Funktion mit return.
  5. Determiniertheit: Es gibt keinen Zufall. Gleiches n liefert immer dieselbe Summe.
  6. Determinismus: Nach jeder Anweisung steht fest, welche als Nächstes kommt.

Ergebnis: Für natürliche Zahlen n erfüllt der Algorithmus alle sechs Eigenschaften.

Kontrolle: Für n = 4 ergibt sich 1 + 2 + 3 + 4 = 10. Die Formel von Gauß liefert ebenfalls 4 · 5 / 2 = 10.

Beispiel 2 komplex

Ausgangssituation: Die Anweisung „Solange x ≠ 1: Ist x gerade, halbiere x, sonst setze x = 3x + 1“ erzeugt die Collatz-Folge. Gezählt werden soll, nach wie vielen Schritten x den Wert 1 erreicht.

def collatz_schritte(x):
    if not isinstance(x, int) or x < 1:   # Vorbedingung: ganze Zahl ab 1
        return None
    schritte = 0
    while x != 1:
        if x % 2 == 0:
            x = x // 2
        else:
            x = 3 * x + 1
        schritte = schritte + 1
    return schritte

print(collatz_schritte(6))   # 8
  1. Ablauf für x = 6 verfolgen: 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1. Das sind 8 Schritte. Warum: Erst eine Handrechnung zeigt, ob das Programm überhaupt das Richtige zählt.
  2. Determinismus und Determiniertheit prüfen: In jedem Schritt entscheidet allein „x gerade?“, was passiert. Gleicher Startwert ergibt also immer dieselbe Folge. Warum: Diese beiden Eigenschaften folgen direkt aus der Verzweigung ohne Zufall.
  3. Falle bei unzulässigen Eingaben: Für x = 0 gilt 0 // 2 = 0, die Schleife läuft endlos. Für x = −1 entsteht der Kreislauf −1 → −2 → −1. Warum: Die Terminierung hängt von der Eingabe ab. Deshalb prüft die erste Zeile die Vorbedingung x ≥ 1 und gibt sonst None zurück.
  4. Falscher Typ: isinstance(x, int) prüft, ob x eine ganze Zahl ist. Ein Text wie "6" oder eine Kommazahl wie 6.0 wird abgewiesen. Warum: Ohne die Prüfung bricht "6" < 1 mit einem TypeError ab.
  5. Terminierung allgemein: Ob die Schleife für jede Startzahl x ≥ 1 endet, ist bis heute unbewiesen (Collatz-Vermutung). Per Computer wurden riesige Mengen von Startzahlen nachgeprüft, aber ein Beweis fehlt. Warum wichtig: Terminierung ist keine Selbstverständlichkeit, selbst bei einer sehr kurzen Schleife.

Ergebnis: collatz_schritte(6) liefert 8. Für zulässige Eingaben ist der Algorithmus deterministisch und determiniert. Seine Terminierung ist für alle getesteten Werte erfüllt, aber nicht bewiesen.

Kontrollstrukturen

Kontrollstrukturen, auch algorithmische Grundstrukturen genannt, sind die elementaren Bausteine, aus denen komplexe Algorithmen aufgebaut werden.

Beispiel: alle vier Grundstrukturen in einem kurzen Programm 
def bewertung(punkte):            # Unterprogramm
    if punkte >= 50:              # Verzweigung
        return "bestanden"
    else:
        return "nicht bestanden"

ergebnisse = [72, 38, 55]         # Sequenz
for p in ergebnisse:              # Schleife
    print(p, bewertung(p))
Praxisbezug: Algorithmen im Alltag und im Beruf

Alltag: Eine Ampelsteuerung ist ein Algorithmus aus Sequenzen (Rot → Rot-Gelb → Grün), Verzweigungen (Fußgänger hat gedrückt?) und einer Schleife, die nie endet – ein Beispiel für den erweiterten Algorithmusbegriff.

Beruf: Softwaretesterinnen und -tester prüfen systematisch, ob jede Verzweigung und jede Schleife eines Programms mit passenden Testfällen durchlaufen wird („Zweigüberdeckung“). In sicherheitskritischen Bereichen wie der Bahn- oder Medizintechnik ist das vorgeschrieben.

Das Wichtigste

Eigenschaften eines Algorithmus:

  • Finitheit (statisch): Die Beschreibung des Algorithmus ist endlich lang.
  • Dynamische Finitheit: Während der Ausführung wird zu jedem Zeitpunkt nur endlich viel Speicher benötigt.
  • Ausführbarkeit: Jeder Schritt ist tatsächlich ausführbar (z. B. keine Division durch 0, keine unmöglichen Aktionen).
  • Terminierung: Der Algorithmus endet für jede zulässige Eingabe nach endlich vielen Schritten.
  • Determiniertheit: Bei gleicher Eingabe liefert der Algorithmus immer dasselbe Ergebnis.
  • Determinismus: Zu jedem Zeitpunkt ist der nächste Schritt eindeutig festgelegt.
  • Sequenz: Anweisungen werden nacheinander in der angegebenen Reihenfolge ausgeführt.
  • Verzweigung (Auswahl): Abhängig von einer Bedingung wird der eine oder der andere Programmteil ausgeführt (if/elif/else).
  • Schleife (Wiederholung): Eine Gruppe von Anweisungen wird wiederholt, solange eine Bedingung erfüllt ist (while) oder für jedes Element einer Folge (for).
  • Unterprogramm: Ein Teil des Algorithmus wird als eigene, benannte Einheit ausgelagert und bei Bedarf aufgerufen. Das fördert Wiederverwendbarkeit und Übersicht.

Aufgabe 2.1.2.2: Wiederholung Kontrollstrukturen AFB I–II

Die folgenden Aufgaben decken grundlegende Konzepte der Programmierung in Python ab.

a) EVA, Variablen, einfache Mathematik

  1. Schulnoten: Erstelle ein Programm, das den Durchschnitt deiner letzten drei Leistungskontrollen berechnet. Das Programm soll nach den drei Noten fragen und dann den Durchschnitt ausgeben.
  2. Pizzaparty-Planer: Schreibe ein Programm, das berechnet, wie viele Pizzen du für deine Geburtstagsparty bestellen musst. Frage nach der Anzahl der Gäste und berechne, wie viele Pizzen du brauchst, wenn jeder Gast 2,5 Stücke isst und eine Pizza 8 Stücke hat.

b) Verzweigungen

  1. Schulnoten-Übersetzer: Schreibe ein Programm, das eine Punktzahl (0–100) in eine Schulnote (1–6) umwandelt. Verwende if-Anweisungen, um die richtige Note auszugeben.
  2. Wetter-Aktivitäten-Planer: Entwickle ein Programm, das abhängig von Temperatur und Wetter Aktivitäten vorschlägt. Frage nach der Temperatur (in °C) und ob es regnet (ja/nein). Gib dann passende Vorschläge aus (z. B. „Perfekt für ein Picknick!“ bei über 20 °C und keinem Regen).

c) Schleifen

  1. Spardosen-Simulator: Der Benutzer gibt an, wie viel Geld er täglich sparen möchte und für wie viele Tage. Das Programm soll in einer Schleife den Sparverlauf simulieren und am Ende die Gesamtersparnis ausgeben.
  2. Zahlenraten-Spiel: Der Computer wählt eine zufällige Zahl zwischen 1 und 100. Der Spieler hat 7 Versuche, die Zahl zu erraten. Nach jedem Versuch gibt das Programm einen Hinweis, ob die gesuchte Zahl größer oder kleiner ist.

d) Funktionen

  1. Begrüßungs-Generator: Schreibe eine Funktion, die einen Namen als Parameter erhält und eine persönliche Begrüßung zurückgibt. Rufe die Funktion mit verschiedenen Namen auf.
  2. Geometrie-Helfer: Erstelle drei Funktionen zur Berechnung des Flächeninhalts eines Rechtecks, eines Dreiecks und eines Kreises. Lass den Benutzer auswählen, welche Berechnung er durchführen möchte.
