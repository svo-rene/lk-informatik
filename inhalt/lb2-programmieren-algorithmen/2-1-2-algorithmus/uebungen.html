Aufgabe 2.1.2.4: Ergebnis vorhersagen AFB II

Bestimme die Ausgaben der beiden Programme ohne sie auszuführen. Lege dazu eine Tabelle mit der Belegung aller Variablen nach jedem Schleifendurchlauf an. Prüfe erst danach am Rechner.

# Programm A
summe = 0
for i in range(1, 6):
    if i % 2 == 0:
        summe = summe + i
    elif i == 5:
        summe = summe * 2
    else:
        summe = summe - 1
print(summe)

# Programm B
x = 10
zaehler = 0
while x > 1:
    if x % 3 == 0:
        x = x // 3
    else:
        x = x - 1
    zaehler = zaehler + 1
print(x, zaehler)

Bei Programm A lohnt ein genauer Blick auf die Reihenfolge von if und elif: Welcher Zweig ist für i = 5 zuständig?

Aufgabe 2.1.2.6: Wechselgeld am Schulkiosk AFB II

Die Kasse am Schulkiosk soll das Wechselgeld mit möglichst wenigen Münzen auszahlen. Verfügbar sind Münzen zu 200, 100, 50, 20, 10, 5, 2 und 1 Cent. Das Verfahren: Nimm immer die größte Münze, die noch in den Restbetrag passt.

  1. Schreibe eine Funktion wechselgeld(betrag), die den Betrag in Cent erhält und die Liste der Münzen zurückgibt. Ist der Betrag keine ganze Zahl oder negativ, gibt sie None zurück.
  2. Teste mit der Tabelle und ergänze zwei eigene Testfälle.
    Eingabeerwartete Ausgabetatsächliche Ausgabe
    wechselgeld(388)[200, 100, 50, 20, 10, 5, 2, 1]
    wechselgeld(4)[2, 2]
    wechselgeld(1000)[200, 200, 200, 200, 200]
    wechselgeld(0)[]
    wechselgeld(-5)None
    wechselgeld("50")None
  3. Begründe, dass dein Algorithmus für jede zulässige Eingabe terminiert.
