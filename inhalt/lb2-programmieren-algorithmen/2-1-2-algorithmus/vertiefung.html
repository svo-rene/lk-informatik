Aufgabe 2.1.2.5: Fehler finden – Schaltjahr AFB III

Ein Jahr ist ein Schaltjahr, wenn es durch 4 teilbar ist – außer es ist durch 100 teilbar. Ist es durch 400 teilbar, ist es doch ein Schaltjahr. Ein Mitschüler hat programmiert:

def ist_schaltjahr(jahr):
    if jahr % 4 == 0:
        return True
    elif jahr % 100 == 0:
        return False
    elif jahr % 400 == 0:
        return True
    else:
        return False

Er hat mit 2024 und 2023 getestet und ist zufrieden.

  1. Übernimm die Tabelle und fülle die Spalte „erwartete Ausgabe“ nach der Regel aus. Trage danach die tatsächliche Ausgabe ein.
    Eingabeerwartete Ausgabetatsächliche Ausgabe
    ist_schaltjahr(2024)
    ist_schaltjahr(2023)
    ist_schaltjahr(1900)
    ist_schaltjahr(2000)
    ist_schaltjahr(2100)
    ist_schaltjahr("2024")
  2. Nenne die Testfälle, die den Fehler entlarven. Begründe, warum die beiden elif-Zweige nie erreicht werden.
  3. Korrigiere die Funktion. Ungültige Eingaben (kein int) sollen None liefern.
  4. Begründe, warum das Jahr 2000 als Testfall für diesen Fehler nicht ausreicht.
Aufgabe 2.1.2.7: ggT durch Subtraktion AFB III

Ein sehr alter Algorithmus berechnet den größten gemeinsamen Teiler zweier Zahlen a und b:

solange a ≠ b:
    wenn a > b: a ← a − b
    sonst:      b ← b − a
gib a aus
  1. Führe den Algorithmus für a = 84 und b = 36 von Hand aus (Tabelle mit a und b nach jedem Schritt).
  2. Untersuche, was für a = 0, b = 5 und für a = −4, b = 6 passiert. Welche Eigenschaft eines Algorithmus ist verletzt?
  3. Begründe, dass der Algorithmus für alle positiven ganzen Zahlen a und b terminiert.
  4. Implementiere ggt(a, b) in Python. Sind a oder b keine positiven ganzen Zahlen, wird None zurückgegeben. Teste mit (84, 36), (7, 7), (17, 5), (1, 100), (0, 5) und (−4, 6) in einer Tabelle Eingabe | erwartete Ausgabe | tatsächliche Ausgabe.
  5. Beurteile den Aufwand für ggt(1, 100) im Vergleich zu ggt(84, 36).
