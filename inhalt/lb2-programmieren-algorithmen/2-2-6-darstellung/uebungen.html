Aufgabe 2.2.6.4: Ergebnis vorhersagen aus einem Struktogramm AFB II 
┌────────────────────────────────────────┐
│ Eingabe: n                             │
├────────────────────────────────────────┤
│ z ← 0                                  │
├────────────────────────────────────────┤
│ solange n > 0                          │
│   ┌────────────────────────────────────┤
│   │ n mod 2 = 1 ?                      │
│   ├──────────────────┬─────────────────┤
│   │ ja               │ nein            │
│   │ z ← z + 1        │ ∅               │
│   ├──────────────────┴─────────────────┤
│   │ n ← n div 2                        │
├───┴────────────────────────────────────┤
│ Ausgabe: z                             │
└────────────────────────────────────────┘

„div“ ist die ganzzahlige Division, „mod“ der Rest.

  1. Führe das Struktogramm für n = 13 von Hand aus. Notiere n und z nach jedem Schleifendurchlauf in einer Tabelle.
  2. Bestimme ebenso die Ausgaben für n = 16, n = 7 und n = 0. Beschreibe, was der Algorithmus berechnet.
  3. Übersetze das Struktogramm in eine Python-Funktion f(n) und überprüfe deine Vorhersagen mit einer Tabelle Eingabe | erwartete Ausgabe | tatsächliche Ausgabe. Ergänze den Fall n = −5 und erkläre das Ergebnis.

Schreibe 13 als Summe von Zweierpotenzen.

Aufgabe 2.2.6.5: Fahrkartenautomat modellieren AFB II

Ein Fahrkartenautomat berechnet den Preis in Cent: Kinder unter 6 Jahren fahren kostenlos; 6- bis 17-Jährige zahlen 200; mit Schülerausweis zahlen auch 18- bis 20-Jährige 200; ab 65 Jahren kostet die Fahrt 300; alle anderen zahlen 450. Danach werden Münzen eingeworfen, bis der Preis erreicht ist, und das Wechselgeld wird berechnet.

  1. Zeichne ein Struktogramm für ticketpreis(alter, ausweis) mit verschachtelten Verzweigungen. Bei ungültigem Alter (keine ganze Zahl oder negativ) wird None geliefert.
  2. Zeichne einen PAP für bezahle(preis, muenzen). Die Liste muenzen enthält die eingeworfenen Münzen in Cent. Es werden nur so viele Münzen genommen, bis der Preis erreicht ist. Reichen die Münzen nicht, wird None zurückgegeben, sonst das Wechselgeld.
  3. Implementiere beide Funktionen und teste sie:
    Eingabeerwartete Ausgabetatsächliche Ausgabe
    ticketpreis(5, False)
    ticketpreis(17, False)
    ticketpreis(18, False)
    ticketpreis(19, True)
    ticketpreis(65, False)
    ticketpreis(-1, False)
    bezahle(450, [200, 200, 100])
    bezahle(200, [50, 200, 100])
    bezahle(0, [])
    bezahle(300, [100])
  4. Entscheide, ob die Bezahlschleife kopf- oder fußgesteuert sein sollte. Denke an kostenlose Fahrten.
