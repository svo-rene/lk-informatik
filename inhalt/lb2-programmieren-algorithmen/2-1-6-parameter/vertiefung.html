Aufgabe 2.1.6.6: Fehler finden – die Kopie, die keine ist AFB III

Die Funktion soll eine absteigend sortierte Kopie liefern und die Originalliste nicht verändern:

def sortiert_absteigend(liste):
    kopie = liste
    kopie.sort(reverse=True)
    return kopie

noten = [2, 1, 3]
s = sortiert_absteigend(noten)
print(s, noten)
  1. Gib erwartete und tatsächliche Ausgabe an und erkläre den Fehler mit einem Speicherbild.
  2. Korrigiere die Funktion auf zwei verschiedene Arten und teste mit [2, 1, 3], [], [5] und [-1, -3, 2].
  3. Eine Lehrkraft speichert Noten als Liste von Listen: tabelle = [[1, 2], [3, 4]]. Sie erstellt k = tabelle.copy() und führt k[0].append(9) aus. Sage den Inhalt von tabelle voraus und begründe mit einem Speicherbild, warum copy() hier nicht ausreicht.
Aufgabe 2.1.6.7: Entwurfsentscheidung – verändern oder neu erzeugen? AFB III

Für die Notenverwaltung soll eine Funktion allen Schülerinnen und Schülern Bonuspunkte gutschreiben. Zwei Entwürfe stehen zur Wahl:

def bonus_a(punkte, bonus):          # Entwurf A
    for i in range(len(punkte)):
        punkte[i] = min(15, punkte[i] + bonus)

def bonus_b(punkte, bonus):          # Entwurf B
    neu = []
    for p in punkte:
        neu.append(min(15, p + bonus))
    return neu
  1. Gib für p = [10, 14, 3] und bonus = 2 an, was nach bonus_a(p, 2) bzw. nach q = bonus_b(p, 2) in p und q steht.
  2. Beurteile beide Entwürfe für diese Situationen: (a) Die Lehrkraft möchte vorher und nachher vergleichen. (b) Die Liste enthält die Werte von einer Million Sensoren, der Speicher ist knapp. (c) Ein Teammitglied ruft die Funktion auf, ohne ihren Code zu kennen.
  3. Formuliere eine Regel für die Benennung solcher Funktionen, die Missverständnisse vermeidet.
