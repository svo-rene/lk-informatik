Aufgabe 2.1.6.4: Ergebnis vorhersagen mit Speicherbild AFB II

Bestimme die Ausgaben, ohne die Programme auszuführen. Zeichne für Programm A ein Speicherbild unmittelbar vor dem Ende von f.

# Programm A
def f(zahl, text, liste):
    zahl += 1
    text += "!"
    liste += [zahl]
    liste = [0]
    liste.append(99)

a = 1
s = "Hi"
l = [7]
f(a, s, l)
print(a, s, l)

# Programm B
def leeren(liste):
    liste.clear()

def leeren2(liste):
    liste = []

x = [1, 2]
y = x
leeren2(x)
print(x, y)
leeren(y)

Aufgabe 2.1.6.5: Messwerte normieren – mit und ohne Nebenwirkung AFB II

Ein Physikkurs vergleicht Messreihen, indem alle Werte durch den größten Betrag der Reihe geteilt werden. Danach liegen alle Werte zwischen −1 und 1.

  1. Schreibe eine Funktion normiert(werte), die eine neue Liste zurückgibt und die übergebene Liste nicht verändert. Ist die Liste leer oder sind alle Werte 0, gibt sie eine Kopie der Liste zurück.
  2. Schreibe eine Prozedur normiere(werte), die die übergebene Liste selbst verändert und nichts zurückgibt.
  3. Teste beide. Prüfe dabei auch, ob die Originalliste nach dem Aufruf noch unverändert ist.
    Eingabeerwartete Ausgabetatsächliche Ausgabe
    d = [2, 4, 8]; print(normiert(d), d)[0.25, 0.5, 1.0] [2, 4, 8]
    d = [2, 4, 8]; print(normiere(d), d)
    normiert([-8, 4])
    normiert([])
    normiert([0, 0])
    normiert(["2", 4])
