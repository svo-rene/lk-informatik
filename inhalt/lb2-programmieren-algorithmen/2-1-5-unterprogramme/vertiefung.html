Aufgabe 2.1.5.6: Fehler finden – drei Fehler in zwei Unterprogrammen AFB III 
def mittelwert(liste):
    summe = 0
    for x in liste:
        summe = summe + x
        return summe / len(liste)

def bewerte(liste):
    m = mittelwert(liste)
    if m >= 5:
        print("bestanden")
    else:
        print("nicht bestanden")

ergebnis = bewerte([3, 9, 6])
print("Ergebnis:", ergebnis)
  1. Gib die tatsächliche Ausgabe des Programms an und vergleiche sie mit der beabsichtigten.
  2. Fülle eine Testtabelle (Eingabe | erwartete Ausgabe | tatsächliche Ausgabe) für mittelwert mit [3, 9, 6], [6], [-2, 2] und [].
  3. Erkläre, warum der Test mit [6] den Hauptfehler nicht aufdeckt.
  4. Beschreibe alle drei Fehler und korrigiere das Programm so, dass ergebnis den Text „bestanden“ bzw. „nicht bestanden“ enthält und eine leere Liste nicht zum Absturz führt.
Aufgabe 2.1.5.7: Eigenes Modul für CSV-Dateien AFB III

In vielen Programmen dieses Kurses werden CSV-Dateien gelesen (siehe Seite 2.1.4). Statt den Lesecode jedes Mal neu zu schreiben, soll ein Modul csv_werkzeug.py entstehen.

  1. Entwirf die Funktion lade_spalte(dateiname, spalte). Sie liefert die Werte der Spalte mit dem Index spalte als Liste von Texten, ohne Kopfzeile und ohne Leerzeilen. Ist die Spaltennummer in einer Zeile zu groß, wird diese Zeile übersprungen. Fehlt die Datei, gibt die Funktion None zurück.
  2. Entwirf die Prozedur speichere_tabelle(dateiname, kopf, zeilen). Dabei ist kopf eine Liste von Spaltennamen und zeilen eine Liste von Listen.
  3. Importiere beide Unterprogramme in einem Hauptprogramm. Lies die Punkte aus punkte.csv (Beispiel 3 auf Seite 2.1.4) und speichere eine Tabelle mit Name und Punkten.
  4. Lege eine Testtabelle mit mindestens vier Fällen an, darunter eine fehlende Datei und eine zu große Spaltennummer.
  5. Beurteile, ob lade_spalte bei einer fehlenden Datei besser None oder eine leere Liste zurückgeben sollte.

Eine fehlende Datei fängst du so ab: try: … except FileNotFoundError: return None.
