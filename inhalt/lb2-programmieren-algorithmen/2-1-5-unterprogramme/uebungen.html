Hinweis: Jupyter-Notebook zu dieser Seite

Als Ergänzung zu dieser Seite gibt es ein Jupyter-Notebook mit eigenen Beispielen und Übungen zum Thema, die du direkt ausführen und bearbeiten kannst. Es verwendet teilweise andere Beispiele und Namen als diese Seite: 2-1-5_unterprogramme.ipynb herunterladen. Das Notebook ersetzt diese Seite nicht, sondern bietet dir eine interaktive Umgebung.

So arbeitest du damit – ganz ohne Installation:

  1. Notebook über den Link oben herunterladen.
  2. Im Browser das JupyterLite der Schule jupyterlite.inf7.eu öffnen (alternativ jupyter.org/try-jupyter/lab). JupyterLab startet dort vollständig im Browser.
  3. Die heruntergeladene Datei links in den Dateibereich ziehen oder über den Hochladen-Pfeil auswählen.
  4. Mit einem Doppelklick öffnen und die Zellen mit Umschalt + Enter nacheinander ausführen.
  5. Am Ende herunterladen: Rechtsklick auf die Datei im Dateibereich → Download, dann in deinen eigenen Dokumenten speichern.

Aufgabe 2.1.5.4: Ergebnis vorhersagen – return oder print? AFB II

Notiere alle Ausgabezeilen in der richtigen Reihenfolge, ohne das Programm auszuführen. Kennzeichne bei jeder Zeile, welche Anweisung sie erzeugt.

def doppelt(x):
    return 2 * x

def zeige(x):
    print("Wert:", x)

def pruefe(x):
    if x > 10:
        return "groß"
    print("klein")

ergebnis = doppelt(doppelt(3))
print(ergebnis)
r = zeige(ergebnis)
print(r)
print(pruefe(ergebnis))
print(pruefe(5))
Aufgabe 2.1.5.5: Passwortprüfung in Teilfunktionen AFB II

Die Schulcloud verlangt sichere Passwörter: mindestens 10 Zeichen, mindestens ein Großbuchstabe, mindestens ein Kleinbuchstabe und mindestens eine Ziffer.

  1. Schreibe die Funktionen hat_ziffer(pw), hat_grossbuchstabe(pw) und hat_kleinbuchstabe(pw), die jeweils True oder False zurückgeben.
  2. Schreibe eine Funktion ist_sicher(pw), die nur diese Funktionen und len verwendet. Ist pw kein Text, gibt sie False zurück.
  3. Teste mit der Tabelle und ergänze die erwarteten Ausgaben vorher:
    Eingabeerwartete Ausgabetatsächliche Ausgabe
    ist_sicher("Abcdefghi1")
    ist_sicher("abcdefghi1")
    ist_sicher("ABCDEFGHI1")
    ist_sicher("Abcdefghij")
    ist_sicher("Abc1")
    ist_sicher("")
    ist_sicher(1234567890)
  4. Begründe, warum jede Zeile der Tabelle einen anderen Teil des Programms prüft.

Für ein einzelnes Zeichen z gibt es z.isdigit(), z.isupper() und z.islower().
