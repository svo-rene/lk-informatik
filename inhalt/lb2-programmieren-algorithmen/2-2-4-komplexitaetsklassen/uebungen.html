Aufgabe 2.2.4.3: Wachstum ordnen AFB II
  1. Ordne die Funktionen nach ihrem Wachstum für große n, beginnend mit der langsamsten. Fasse Funktionen derselben Komplexitätsklasse zusammen: 3n, n log2 n, 100, n², 2n, log2 n, n!, n³/1000, √n, 10 n log2 n.
  2. Gib an, welche dieser Funktionen polynomial beschränkt sind.
  3. Für n = 1 gilt 2n > n³. Bestimme das kleinste n, ab dem 2n > n³ dauerhaft gilt. Begründe mit einer Wertetabelle.
Aufgabe 2.2.4.4: Was schafft der Server in einer Sekunde? AFB II

Ein Server führt 109 Schritte pro Sekunde aus. Eine Anfrage darf höchstens eine Sekunde dauern.

  1. Bestimme für die Schrittzahlen n, n log2 n, n², 2n und n! jeweils das größte n, das in einer Sekunde verarbeitet werden kann. Für n log2 n genügt eine Abschätzung durch Probieren.
  2. Stelle die Ergebnisse in einer Tabelle dar und beschreibe den Unterschied zwischen polynomialen und exponentiellen Klassen in einem Satz.
