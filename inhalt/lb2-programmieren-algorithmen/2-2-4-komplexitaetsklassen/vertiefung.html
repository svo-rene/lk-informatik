Aufgabe 2.2.4.6: Schrittzahlen per Programm vergleichen AFB III
  1. Schreibe eine Funktion schritte(klasse, n), die für die Klassen "1", "log n", "n", "n log n", "n^2", "2^n" und "n!" die Schrittzahl liefert (Logarithmus zur Basis 2). Bei unbekannter Klasse oder negativem n gibt sie None zurück.
  2. Teste mit einer Tabelle Eingabe | erwartete Ausgabe | tatsächliche Ausgabe: ("n^2", 10), ("2^n", 10), ("n log n", 8), ("n!", 0), ("log n", 1), ("n^3", 5), ("n", -1).
  3. Gib für n = 10, 20, 40, 80 eine Tabelle aus, die für jede Klasse den Faktor zeigt, um den die Schrittzahl bei Verdopplung von n wächst.
  4. Begründe allgemein, welcher Faktor sich bei Verdopplung von n für jede Klasse ergibt, und vergleiche mit deiner Tabelle.

math.log2(n) und math.factorial(n) stehen im Modul math.
