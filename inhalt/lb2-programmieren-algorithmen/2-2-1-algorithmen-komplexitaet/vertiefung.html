Aufgabe 2.2.1.4: Fehler finden – ein Durchgang reicht doch? AFB III

Lina hat ein Sortierverfahren entwickelt: „Gehe einmal von links nach rechts durch und tausche jedes Nachbarpaar, das falsch herum liegt.“

def sortiere_einmal(liste):
    for i in range(len(liste) - 1):
        if liste[i] > liste[i + 1]:
            temp = liste[i]
            liste[i] = liste[i + 1]
            liste[i + 1] = temp
    return liste
