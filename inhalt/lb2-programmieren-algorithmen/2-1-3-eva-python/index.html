Ob Taschenrechner-App oder Fahrkartenautomat: Fast jedes Programm arbeitet nach demselben Muster. Es nimmt Daten entgegen, verarbeitet sie und gibt ein Ergebnis aus.

Eingabe von Daten

Mit der Funktion input() lässt du den Benutzer Daten eingeben.

name = input("Gib deinen Namen ein: ")
stufe = input("Gib deine Klassenstufe ein: ")

Verarbeitung von Daten

Die eingegebenen Daten kannst du umwandeln und damit rechnen. Das Schuljahr beginnt in Sachsen im August. Wer im Schuljahr 2026/27 in Klasse 11 ist, wurde 2016 eingeschult: 2026 − (11 − 1) = 2016.

from datetime import date

stufe = int(stufe)                 # Klassenstufe (Text) in eine Ganzzahl umwandeln
heute = date.today()
if heute.month >= 8:               # ab August läuft das neue Schuljahr
    schuljahr_beginn = heute.year
else:
    schuljahr_beginn = heute.year - 1
einschulung = schuljahr_beginn - (stufe - 1)

Ausgabe von Daten

Ergebnisse gibst du mit der Funktion print() aus.

print("Dein Einschulungsjahr ist:", einschulung)

Mehrere Teile trennst du mit Kommas. print setzt zwischen die Teile automatisch ein Leerzeichen:

print(name, "du wurdest im Jahr", einschulung, "eingeschult.")
# Ausgabe z. B.: Lena du wurdest im Jahr 2015 eingeschult.
Beispiel 1 einfach

Ausgangssituation: print(int("7") + 3) gibt 10 aus, print("7" + "3") dagegen 73 – bei Texten bedeutet + „aneinanderhängen“. Das folgende Programm zeigt den Unterschied mit echten Eingaben.

a = input("Erste Zahl: ")      # E: Eingabe ist immer ein Text (str)
b = input("Zweite Zahl: ")
print(a + b)                   # A: Texte werden aneinandergehängt
print(int(a) + int(b))         # V + A: erst umwandeln, dann rechnen
  1. Eingabe: Bei den Eingaben 7 und 3 gilt a = "7" und b = "3". Warum: input() liefert immer einen str.
  2. Erste Ausgabe: "7" + "3" ergibt den Text "73". Warum: Für Texte bedeutet + Verketten.
  3. Verarbeitung: int("7") ergibt die Zahl 7, int("3") die Zahl 3. Die Summe ist 10. Warum: Erst nach der Umwandlung rechnet Python mit Zahlen.

Ergebnis: Ausgabe 73 und darunter 10.

Eingabe (a, b)erwartete AusgabeBemerkung

-2, 5-25 und 3negative Zahl: der Text „-25“ sieht aus wie eine Zahl, ist aber keine Rechnung

Beispiel 2 komplex

Ausgangssituation: Eine Fahrzeit in Minuten soll in Stunden und Minuten umgerechnet werden. Zusätzlich soll die Ankunftszeit berechnet werden, auch wenn die Fahrt über Mitternacht geht.

minuten = int(input("Fahrzeit in Minuten: "))   # E
stunden = minuten // 60                         # V: ganzzahlige Division
rest = minuten % 60                             # V: Rest (Modulo)
print(stunden, "h", rest, "min")                # A
# Eingabe 135 -> Ausgabe: 2 h 15 min

abfahrt = input("Abfahrt (hh:mm): ")             # E, z. B. "22:50"
teile = abfahrt.split(":")                       # V: ["22", "50"]
ankunft = int(teile[0]) * 60 + int(teile[1]) + minuten   # Minuten seit 0:00 Uhr
tage = ankunft // 1440                           # 1 Tag = 1440 Minuten
ankunft = ankunft % 1440                         # Uhrzeit innerhalb des Tages
zusatz = ""
if tage > 0:
    zusatz = "(+" + str(tage) + " Tag)"         # Text mit + zusammensetzen
stunde = ankunft // 60
minute = ankunft % 60
if minute < 10:                                # 5 Minuten als "05" schreiben
    uhrzeit = str(stunde) + ":0" + str(minute)
else:
    uhrzeit = str(stunde) + ":" + str(minute)
print("Ankunft:", uhrzeit, zusatz)              # A
  1. Fahrzeit zerlegen: 135 // 60 = 2 und 135 % 60 = 15, also „2 h 15 min“. Warum: // zählt die vollen Stunden, % liefert die übrigen Minuten.
  2. Abfahrt umrechnen: "22:50".split(":") ergibt ["22", "50"]. Daraus folgt 22 · 60 + 50 = 1370 Minuten seit Mitternacht. Warum: In einer einzigen Einheit lässt sich einfach addieren.
  3. Addieren: 1370 + 135 = 1505 Minuten.
  4. Über Mitternacht: 1505 // 1440 = 1 voller Tag, 1505 % 1440 = 65 Minuten. Warum: Ohne diesen Schritt würde „25:05 Uhr“ ausgegeben.
  5. Ausgabe: 65 // 60 = 1 und 65 % 60 = 5, die Minuten sind kleiner als 10, also wird eine 0 davorgesetzt: „1:05“. Warum str(): Zahlen und Texte lassen sich mit + nicht verbinden, die Zahl muss erst Text werden.

Ergebnis: 2 h 15 min und Ankunft: 1:05 (+1 Tag).

Falle bei negativen Eingaben: Python rundet bei // immer ab. Für −30 Minuten ergibt sich −30 // 60 = −1 und −30 % 60 = 30, also „-1 h 30 min“. Das Programm stürzt nicht ab, liefert aber Unsinn. Eingaben müssen deshalb geprüft werden.

Praxisbezug: Eingaben prüfen

Alltag: Ein Fahrkartenautomat der Dresdner Verkehrsbetriebe arbeitet nach dem EVA-Prinzip: Du wählst Tarifzone und Fahrkarte (E), der Automat berechnet Preis und Wechselgeld (V) und druckt die Fahrkarte (A).

Beruf: Anwendungsentwicklerinnen und -entwickler verbringen viel Zeit damit, Eingaben abzusichern: Was passiert, wenn jemand „elf“ statt „11“ eintippt? Ungeprüfte Eingaben sind eine der häufigsten Ursachen für Programmabstürze und Sicherheitslücken.

Das Wichtigste

EVA-Prinzip: Eingabe → Verarbeitung → Ausgabe.

Eingabe in Python: input() liest eine Eingabe immer als Text (str) ein. Zum Rechnen muss der Text mit int() oder float() in eine Zahl umgewandelt werden.

Ausgabe in Python: print() gibt Ergebnisse aus.
