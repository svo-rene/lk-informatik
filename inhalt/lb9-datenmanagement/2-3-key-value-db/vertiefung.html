Aufgabe 2.3.6: Fehler finden – die Lagerverwaltung AFB III

Für den Schulkiosk hat Paul eine kleine Lagerverwaltung geschrieben. Eingebucht werden gelieferte Artikel, ausgebucht verkaufte. Gewünscht ist die Ausgabe {'Stift': 50, 'Heft': 25, 'Lineal': 5}, False, False.

lager = {"Stift": 40, "Heft": 25}

def einbuchen(artikel, menge):
    lager[artikel] = menge

def ausbuchen(artikel, menge):
    if lager[artikel] >= menge:
        lager[artikel] -= menge
        return True
    return False

einbuchen("Stift", 10)
einbuchen("Lineal", 5)
print(lager)
print(ausbuchen("Heft", 30))
print(ausbuchen("Zirkel", 1))
  1. Bestimme ohne Computer die tatsächliche Ausgabe des Programms.
  2. Benenne die beiden Fehler und erkläre, warum der eine „still“ (ohne Fehlermeldung) und der andere „laut“ auftritt.
  3. Korrigiere die beiden Funktionen und gib zwei weitere Testfälle an, die die Korrektur absichern.
Aufgabe 2.3.7: Schlüssel für einen Vokabeltrainer entwerfen AFB III

Eine Vokabeltrainer-App soll ihre Daten in Redis speichern. Die App muss folgende Fragen beantworten:

  1. Was heißt das englische Wort „library“ auf Deutsch?
  2. Welche Vokabeln gehören zu Lektion 4?
  3. Wie oft hat Nutzerin 12 die Vokabel „library“ schon richtig beantwortet?
  4. Welche Vokabeln hat Nutzerin 12 noch nie richtig beantwortet?

Entwirf ein Schlüsselschema (Muster und je ein Beispiel-Paar), sodass möglichst viele Fragen mit einem einzigen GET beantwortet werden können. Beurteile, welche der Fragen sich mit einem reinen Key-Value-Store nur umständlich beantworten lässt, und begründe, ob für diese App ein anderes Datenmodell besser geeignet wäre.
