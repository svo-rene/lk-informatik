In vielen Programmiersprachen lassen sich Datentypen ineinander verschachteln, um komplexe Strukturen abzubilden. Besonders in Python sind geschachtelte Listen und Dictionaries sehr mächtig und weit verbreitet.

1. Listen in Listen

Eine Liste kann andere Listen enthalten. Dies erlaubt z. B. die Darstellung von Tabellen oder Matrizen. 

matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

print(matrix[1])      # [4, 5, 6]  – die zweite Zeile (Zählung ab 0)
print(matrix[1][2])   # 6          – darin das dritte Element

Der erste Index wählt die innere Liste, der zweite das Element darin – wie Zeile und Spalte einer Tabelle.

2. Listen in Dictionaries

Ein Dictionary kann Listen als Werte enthalten. Dies ist praktisch, wenn mehreren Kategorien mehrere Elemente zugeordnet werden sollen. 

noten = {"Anna": [2, 1, 3], "Ben": [3, 2, 2]}

print(noten["Anna"])      # [2, 1, 3]
print(noten["Anna"][0])   # 2 – Annas erste Note

3. Dictionaries in Dictionaries

Auch Dictionaries können verschachtelt werden, z. B. zur Modellierung komplexer Objekte. 

personen = {
    "anna": {"alter": 16, "klasse": "10A"},
    "ben": {"alter": 15, "klasse": "9B"}
}

4. Alles gemixt

Die Kombination aller Strukturen erlaubt es, realitätsnahe Datenmodelle zu erstellen. 

schule = {
    "10A": [{"name": "Anna", "noten": [2, 1, 3]},
            {"name": "Carla", "noten": [1, 1, 2]}],
    "9B":  [{"name": "Ben", "noten": [3, 2, 2]}]
}

# Zugriff Schritt für Schritt: Klasse -> Liste -> Person -> Notenliste -> Note
print(schule["10A"][1]["name"])       # Carla
print(schule["10A"][1]["noten"][2])   # 2

# Komplexeres Beispiel: Durchschnitt jeder Person in allen Klassen
for klasse, personen in schule.items():
    for person in personen:
        schnitt = sum(person["noten"]) / len(person["noten"])
        print(klasse, person["name"], round(schnitt, 2))
# Ausgabe:
# 10A Anna 2.0
# 10A Carla 1.33
# 9B Ben 2.33

Lies einen verschachtelten Zugriff immer von links nach rechts: Jede eckige Klammer geht eine Ebene tiefer. Bei einer Liste steht darin eine Position ([1]), bei einem Dictionary ein Schlüssel (["name"]).

Praxisbezug: Bestellungen im Onlineshop

Eine Bestellung in einem Onlineshop ist genau so eine verschachtelte Struktur: ein Dictionary mit Kundendaten, darin eine Liste von Artikeln, und jeder Artikel ist wieder ein Dictionary mit Name, Preis und Menge. Backend-Entwickler*innen und Data Analysts arbeiten täglich mit solchen Daten, wenn sie Bestellungen aus einer API abrufen und etwa den Warenwert je Bestellung berechnen. Weil in solchen Strukturen oft Namen und Adressen stecken, gilt die DSGVO: Für eine Umsatzauswertung werden die personenbezogenen Teile vorher entfernt.

Warum ist das wichtig?

In der realen Softwareentwicklung werden Daten oft in komplexer Form gespeichert, z. B. als JSON. Das Verständnis von geschachtelten Datentypen ist essenziell für:

  • Datenanalyse
  • Webentwicklung (z. B. REST APIs)
  • Arbeit mit Datenbanken
  • Machine Learning
Beispiel 1 einfach Zugriff Ebene für Ebene – der Stundenplan

Ausgangssituation: Ein Stundenplan ist ein Dictionary: Schlüssel ist der Wochentag, Wert die Liste der Fächer.

stundenplan = {
    "Mo": ["Mathe", "Deutsch", "Informatik"],
    "Di": ["Englisch", "Sport"]
}
print(stundenplan["Mo"])
print(stundenplan["Mo"][2])
print(len(stundenplan["Di"]))
stundenplan["Di"].append("Physik")
print(stundenplan["Di"])
print(stundenplan["Mo"][2][0])
  1. stundenplan["Mo"] – Das äußere Objekt ist ein Dictionary, also steht in der Klammer ein Schlüssel. Ergebnis ist die ganze Liste ['Mathe', 'Deutsch', 'Informatik'].
  2. stundenplan["Mo"][2] – Die zweite Klammer wirkt auf diese Liste, also steht darin eine Position. Position 2 ist das dritte Element: Informatik.
  3. len(stundenplan["Di"]) – len zählt die Elemente der inneren Liste: 2.
  4. append auf der inneren Liste – Die Liste im Dictionary wird direkt verändert; eine neue Zuweisung ist nicht nötig.
  5. stundenplan["Mo"][2][0] – Auch ein String hat Positionen. Die dritte Klammer liefert den ersten Buchstaben von „Informatik“.

Ergebnis:

['Mathe', 'Deutsch', 'Informatik']
Informatik
2
['Englisch', 'Sport', 'Physik']
I

Kontrolle: Schreibe bei jedem Zugriff unter jede Klammer, welchen Typ das Zwischenergebnis hat: dict → list → str. Passt der Klammerinhalt nicht zum Typ (z. B. stundenplan[0]), gibt es einen Fehler.

Beispiel 2 komplex Warenwert einer Bestellung – mit fehlendem Feld

Ausgangssituation: Ein Onlineshop liefert eine Bestellung als verschachtelte Struktur (vgl. Praxisbezug). Bei einem Artikel fehlt das Feld menge; laut Shop-Regel gilt dann die Menge 1. Gesucht sind die Zahl der Positionen und der Warenwert.

bestellung = {
    "nr": 5003,
    "kunde": {"name": "Lea Kraus", "ort": "Pirna"},
    "artikel": [
        {"name": "USB-Stick", "preis": 8.49, "menge": 2},
        {"name": "Maus", "preis": 24.95, "menge": 1},
        {"name": "Collegeblock", "preis": 2.49}
    ]
}

summe = 0
for posten in bestellung["artikel"]:
    menge = posten.get("menge", 1)        # fehlt die Menge, gilt 1
    summe += posten["preis"] * menge
print(bestellung["kunde"]["name"], "-", len(bestellung["artikel"]), "Positionen")
print(f"Warenwert: {summe:.2f} €")
  1. Struktur analysieren – bestellung ist ein dict; "kunde" enthält wieder ein dict, "artikel" eine Liste von dicts. Für die Summe muss man also über die Liste laufen.
  2. Schleife über bestellung["artikel"] – posten ist in jedem Durchlauf ein Artikel-Dictionary.
  3. Durchlauf 1: 8.49 · 2 = 16.98, Summe 16.98.
  4. Durchlauf 2: 24.95 · 1 = 24.95, Summe 41.93.
  5. Durchlauf 3 – die Falle: Beim Collegeblock fehlt menge. Mit posten["menge"] bräche das Programm mit KeyError: 'menge' ab. posten.get("menge", 1) liefert stattdessen 1. Summe 44.42.
  6. Ausgabe formatieren – Kommazahlen sind intern nicht immer exakt; :.2f zeigt genau zwei Nachkommastellen.

Ergebnis:

Lea Kraus - 3 Positionen
Warenwert: 44.42 €
TestfallEingabeerwartete Ausgabe
Bestellung wie oben3 Artikel, einer ohne MengeWarenwert: 44.42 €
leere Bestellung"artikel": []Warenwert: 0.00 €
nur ein Artikel ohne Menge[{"name": "Maus", "preis": 24.95}]Warenwert: 24.95 €

Kontrolle: Überschlag 2 · 8,50 + 25 + 2,50 = 44,50 – das berechnete Ergebnis 44,42 liegt passend knapp darunter. Für eine reine Umsatzauswertung würde man den Teil "kunde" gar nicht erst mitverarbeiten (Datenminimierung).

Das Wichtigste

Geschachtelte (verschachtelte) Datentypen sind Listen oder Dictionaries, deren Elemente selbst wieder Listen oder Dictionaries sind. Auf ein inneres Element greifst du mit mehreren Klammern hintereinander zu, z. B. schule["10A"][0]["noten"][1]. Geschachtelte Strukturen helfen dabei, komplexe Daten realitätsnah abzubilden, und sind die Grundlage für die Arbeit mit JSON und APIs (Seiten 3.10 und 3.11).
