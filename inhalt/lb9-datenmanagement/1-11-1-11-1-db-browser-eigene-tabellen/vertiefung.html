Aufgabe 1.11.1.5: Fehler finden – das Skript der Schulbibliothek AFB III

Paul möchte für die Schulbibliothek Leser, Bücher und Ausleihen anlegen. Sein Skript bricht mehrfach ab oder speichert nicht das, was es soll:

CREATE TABLE Leser (
    LeserID INTEGER PRIMARY KEY,
    Name TEXT NOT NULL
);
CREATE TABLE Buch (
    BuchID INTEGER PRIMARY KEY,
    Titel TEXT NOT NULL
);
CREATE TABLE Ausleihe (
    BuchID INTEGER PRIMARY KEY,
    LeserID INTEGER PRIMARY KEY,
    Datum TEXT,
    FOREIGN KEY (LeserID) REFERENCES Leser (LeserID)
);
INSERT INTO Ausleihe VALUES (1, 1, '2026-09-01');
INSERT INTO Leser (LeserID, Name) VALUES (1, 'Ole');
INSERT INTO Buch (Titel) VALUES ('Momo', 'Krabat');

Finde mindestens vier Fehler – Syntaxfehler, Verstöße gegen Schlüsselregeln und Modellierungsfehler. Gib zu jedem die Fehlermeldung bzw. die Folge an und schreibe ein korrigiertes Skript. Beurteile außerdem, ob (BuchID, LeserID) als Primärschlüssel für eine Bibliothek ausreicht.

Aufgabe 1.11.1.6: Schneller Import – gute Idee? AFB III

  1. Beschreibe, welche Eigenschaften die neue Tabelle hat und welche ihr im Vergleich zu Mitglieder fehlen.
  2. Beurteile an zwei konkreten Situationen aus dem Vereinsalltag, welche Probleme daraus entstehen können.
  3. Entwirf ein Vorgehen in Schritten, mit dem die 300 Datensätze sicher in die Tabelle Mitglieder gelangen.
