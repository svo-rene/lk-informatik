2. Daten mit Python einlesen

import csv

daten = []
with open('umfrage.csv', newline='', encoding='utf-8') as file:
    reader = csv.reader(file, delimiter=';')
    next(reader)  # Kopfzeile überspringen
    for zeile in reader:
        daten.append(zeile)

for eintrag in daten:
    print(eintrag)

3. Daten bereinigen

def ist_zahl(text):
    """True, wenn text eine ganze Zahl oder Dezimalzahl ist (z. B. '3', '7.5', '7,5')."""
    try:
        float(text.replace(',', '.'))
        return True
    except ValueError:
        return False

bereinigt = []

for zeile in daten:
    if len(zeile) == 3:
        nr = zeile[0].strip()
        wort = zeile[1].strip()
        zahl = zeile[2].strip().replace(',', '.')   # Dezimalkomma in Punkt umwandeln

        if wort and not ist_zahl(wort) and ist_zahl(zahl):
            bereinigt.append([nr, wort, zahl])

Warum nicht einfach zahl.isdigit()? isdigit() prüft, ob alle Zeichen Ziffern sind. Bei '7.5' ist der Punkt keine Ziffer, also würde eine gültige Dezimalzahl aussortiert, ebenso '-3'. Der Versuch, den Text mit float() umzuwandeln, erkennt dagegen alle Zahlen: Klappt es, ist es eine Zahl; sonst meldet Python einen ValueError, den try/except abfängt.

4. Daten analysieren

zaehler = {}
for z in bereinigt:
    antwort = z[1]
    if antwort in zaehler:
        zaehler[antwort] += 1
    else:
        zaehler[antwort] = 1

zahlen = [float(z[2]) for z in bereinigt]
durchschnitt = sum(zahlen) / len(zahlen)

print("Antworten (Wort):", zaehler)
print("Durchschnitt (Zahl):", round(durchschnitt, 1))

5. Neue CSV-Datei speichern

with open('umfrage_bereinigt.csv', 'w', newline='', encoding='utf-8') as file:
    writer = csv.writer(file, delimiter=';')
    writer.writerow(['Nr', 'Antwort_Wort', 'Antwort_Zahl'])
    writer.writerows(bereinigt)

7. Archivieren und Löschen (Phasen 4 und 5)

Hinweis: Was archiviert, was gelöscht wird

Sichere deine bereinigten Daten und dein Programm (z. B. zusammen als ZIP-Datei) und lösche die Rohdaten, sobald du sie nicht mehr brauchst – vor allem, wenn sie sensible Angaben enthalten.

Das Wichtigste

CSV (Comma-Separated Values): Textformat für tabellarische Daten. Jede Zeile ist ein Datensatz, die Spalten sind durch ein Trennzeichen getrennt (in Deutschland meist Semikolon, international Komma).

Vorteile von CSV: leicht lesbar, plattformunabhängig und sowohl mit Tabellenkalkulationen als auch mit Python einfach zu verarbeiten.

Personenbezogene Daten: Namen, E-Mail-Adressen und andere Angaben, mit denen man eine Person erkennen kann. Für eine Auswertung braucht man sie fast nie.

Datenminimierung: nur erheben, was man für die Fragestellung wirklich braucht.

Anonymisierung: Namen weglassen bzw. durch Nummern ersetzen, damit keine Rückschlüsse auf einzelne Personen möglich sind.

Grundaufgaben

Aufgabe 3.9.1: Denk dir zwei Umfragefragen aus AFB I

Überlege dir zwei Fragen:

  • Frage 1: mit einer Antwort als Wort (z. B. Musikrichtung, Lieblingstier, Lieblingsspiel, Lieblingsverein, Lieblingsfarbe)
  • Frage 2: mit einer Antwort als Zahl, auch Dezimalzahlen sind erlaubt (z. B. Schuhgröße, Anzahl Haustiere, Schlafdauer in Stunden wie 7.5)

Erstelle in LibreOffice Calc eine Tabelle mit mindestens 10 Datensätzen und den Spalten Nr, Antwort_Wort, Antwort_Zahl. Trage statt Namen nur eine laufende Nummer ein – so bleibt die Umfrage anonym (siehe Merkkasten unten).

Baue absichtlich 2–3 Fehler ein, z. B.:

  • eine leere Zelle
  • Antworten vertauscht (Zahl bei Wort, Wort bei Zahl)
  • Buchstaben in der Zahlenspalte

Speichere deine Datei als umfrage.csv (Zeichensatz UTF-8, Semikolon als Feldtrenner, Dezimalzahlen mit Punkt).
