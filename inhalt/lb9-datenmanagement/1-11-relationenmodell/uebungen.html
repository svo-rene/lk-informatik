Aufgabe 1.11.5: Rückweg aus einer SQL-Datei – der Fahrradverleih AFB II

Von einem Fahrradverleih ist nur diese SQL-Datei erhalten. Notiere zuerst das Relationenmodell in der Schreibweise dieser Seite und erstelle dann das ER-Modell. Begründe jede Kardinalität mit einer Stelle im SQL-Code.

CREATE TABLE Station (
    StationNr INTEGER PRIMARY KEY,
    Ort       TEXT NOT NULL
);
CREATE TABLE Fahrrad (
    RadNr     INTEGER PRIMARY KEY,
    Typ       TEXT,
    StationNr INTEGER NOT NULL,
    FOREIGN KEY (StationNr) REFERENCES Station(StationNr)
);
CREATE TABLE Kunde (
    KundenNr INTEGER PRIMARY KEY,
    Name     TEXT NOT NULL,
    Email    TEXT UNIQUE
);
CREATE TABLE Ausleihe (
    KundenNr INTEGER,
    RadNr    INTEGER,
    Start    TEXT,
    Ende     TEXT,
    PRIMARY KEY (KundenNr, RadNr, Start),
    FOREIGN KEY (KundenNr) REFERENCES Kunde(KundenNr),
    FOREIGN KEY (RadNr)    REFERENCES Fahrrad(RadNr)
);

Erkläre außerdem, warum Start zum Primärschlüssel von Ausleihe gehört und was das für das ER-Modell bedeutet.
