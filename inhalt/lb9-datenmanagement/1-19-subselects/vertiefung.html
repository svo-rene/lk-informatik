Aufgabe 1.19.9: Fehler finden – NOT IN und die leere Ergebnismenge AFB III

Zum Halbjahr wird eine neue Klasse angelegt und eine neue Schülerin aufgenommen, deren Klasse noch nicht feststeht:

INSERT INTO klasse (name) VALUES ('11A');
INSERT INTO schueler (name, klasse_id) VALUES ('Mia Neu', NULL);

Die Sekretärin möchte wissen, welche Klassen noch keine Schüler*innen haben, und schreibt:

SELECT name
FROM klasse
WHERE id NOT IN (SELECT klasse_id FROM schueler);
  1. Welches Ergebnis erwartest du, welches liefert SQLite tatsächlich?
  2. Erkläre den Unterschied, indem du die Bedingung für die Klasse 11A Schritt für Schritt auswertest.
  3. Korrigiere die Abfrage und beurteile, warum dieser Fehler im Alltag besonders gefährlich ist.
Aufgabe 1.19.10: JOIN oder Subselect? AFB III

Gesucht sind die Namen aller Schüler*innen mit mindestens einer Note besser als 2.0. Drei Vorschläge liegen vor:

-- Vorschlag A
SELECT s.name FROM schueler s JOIN note n ON n.schueler_id = s.id WHERE n.wert < 2.0;

-- Vorschlag B
SELECT DISTINCT s.name FROM schueler s JOIN note n ON n.schueler_id = s.id WHERE n.wert < 2.0;

-- Vorschlag C
SELECT name FROM schueler WHERE id IN (SELECT schueler_id FROM note WHERE wert < 2.0);

Bestimme jeweils das Ergebnis, beurteile, welcher Vorschlag die Frage korrekt beantwortet, und begründe mit der Faustregel aus dem Hinweis „Wann lieber JOINs?“.
