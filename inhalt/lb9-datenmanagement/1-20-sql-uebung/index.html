Praxisbezug: Datenanalyse im Freizeitpark

Große Freizeitparks werten Ticketverkäufe, Buchungen und Besucherzahlen täglich aus, um Personal, Öffnungszeiten und Preise zu planen. Diese Arbeit übernehmen Data Analysts, die genau solche Abfragen schreiben wie du auf dieser Seite, und Datenbankadministratorinnen und -administratoren, die dafür sorgen, dass die Datenbank vollständig und widerspruchsfrei bleibt (NOT-NULL-Bedingungen, Fremdschlüssel). Weil Name und Alter personenbezogene Daten sind, gilt außerdem die DSGVO: Für Auswertungen reichen meist anonymisierte oder zusammengefasste Werte.

7. Joins über drei Tabellen mit Filter**

Hinweis: SQL-Befehlsübersicht

Diese Übersicht enthält die wichtigsten SQL-Befehle und Konzepte, die du für die Freizeitpark-Übungen brauchst. Alle Beispiele laufen mit freizeitpark.sql.

1. SELECT – Daten abfragen

SELECT [Spalten] FROM [Tabelle]; – wählt bestimmte Spalten oder alle (*) aus einer Tabelle aus.

SELECT * FROM visitors;

SELECT DISTINCT [Spalte] FROM [Tabelle]; – gibt nur verschiedene Werte zurück.

SELECT DISTINCT ticket_type FROM tickets;

SELECT [Spalten] FROM [Tabelle] WHERE [Bedingung]; – filtert Ergebnisse nach einer Bedingung.

SELECT * FROM attractions WHERE suitable_for_children = 1;

2. INSERT – Daten einfügen

INSERT INTO [Tabelle] ([Spalten]) VALUES ([Werte]); – fügt neue Daten in eine Tabelle ein.

INSERT INTO visitors (name, age, year_of_birth) VALUES ('Max Mustermann', 20, 2003);

3. UPDATE – Daten aktualisieren

UPDATE [Tabelle] SET [Spalte] = [neuer Wert] WHERE [Bedingung]; – ändert Daten, die die Bedingung erfüllen.

UPDATE tickets SET price = 30 WHERE ticket_type = 'Standard';

4. DELETE – Daten löschen

DELETE FROM [Tabelle] WHERE [Bedingung]; – löscht Zeilen, die der Bedingung entsprechen. Zeilen, auf die noch ein Fremdschlüssel verweist (z. B. ein Besucher mit Buchungen), lassen sich bei aktiven Fremdschlüsseln nicht löschen.

DELETE FROM bookings WHERE booking_id = 10;

5. JOIN – Tabellen verbinden

INNER JOIN – gibt nur Zeilen zurück, zu denen es in beiden Tabellen einen passenden Partner gibt.

SELECT visitors.name, tickets.ticket_type FROM visitors INNER JOIN tickets ON visitors.visitor_id = tickets.visitor_id;

LEFT JOIN – gibt alle Zeilen der linken Tabelle zurück und ergänzt passende Zeilen der rechten Tabelle (sonst NULL).

SELECT visitors.name, bookings.booking_date FROM visitors LEFT JOIN bookings ON visitors.visitor_id = bookings.visitor_id;

6. Aggregatfunktionen – Berechnungen über Gruppen von Daten

COUNT() – zählt die Zeilen, die die Bedingung erfüllen.

SELECT COUNT(*) FROM tickets WHERE ticket_type = 'VIP';

SUM() – berechnet die Summe einer Zahlenspalte.

SELECT SUM(price) FROM tickets WHERE ticket_type = 'Standard';

AVG() – berechnet den Durchschnitt einer Zahlenspalte.

SELECT AVG(annual_visitors) FROM attractions;

MAX() und MIN() – geben den größten bzw. kleinsten Wert zurück.

SELECT MAX(price) FROM tickets;
SELECT MIN(age) FROM visitors;

7. GROUP BY – Daten gruppieren

GROUP BY – fasst Zeilen mit gleichen Werten zu Gruppen zusammen, meist zusammen mit Aggregatfunktionen.

SELECT ticket_type, COUNT(*) FROM tickets GROUP BY ticket_type;

HAVING – filtert Gruppen nach einer Bedingung (nach GROUP BY).

SELECT ticket_type, COUNT(*) FROM tickets GROUP BY ticket_type HAVING COUNT(*) > 2;

8. ORDER BY – Ergebnisse sortieren

ORDER BY [Spalte] [ASC|DESC]; – sortiert aufsteigend (ASC) oder absteigend (DESC).

SELECT * FROM shows ORDER BY show_time DESC;

9. BETWEEN – Bereichsabfragen

WHERE [Spalte] BETWEEN [Wert1] AND [Wert2]; – filtert Werte in einem Bereich (Grenzen eingeschlossen).

SELECT * FROM visitors WHERE age BETWEEN 18 AND 30;

10. LIKE – Musterabgleich

WHERE [Spalte] LIKE '[Muster]'; – sucht nach einem Muster in einem Text. % steht für beliebig viele Zeichen.

SELECT * FROM attractions WHERE attraction_name LIKE 'A%';

11. IN – Werteliste abgleichen

WHERE [Spalte] IN ([Wert1], [Wert2], …); – prüft, ob ein Wert in einer Liste vorkommt.

SELECT * FROM tickets WHERE ticket_type IN ('VIP', 'Standard');

Das Wichtigste

SELECT DISTINCT spalte FROM tabelle; gibt jeden Wert nur einmal aus, auch wenn er in mehreren Zeilen vorkommt. Das brauchst du, wenn z. B. ein Besucher mehrfach gebucht hat und sonst mehrfach im Ergebnis auftauchen würde.
