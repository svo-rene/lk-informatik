In der Informatik ist es häufig notwendig, Daten zu bereinigen, bevor sie weiterverarbeitet oder analysiert werden können, weil zum Beispiel Sensoren fehlerhafte Werte liefern oder Daten unvollständig sind.

Verfälschungen vermeiden:

Beim Bereinigen von Daten darfst du keine persönlichen Annahmen oder Wertungen einbringen. Verwende nur nachvollziehbare, objektive Methoden wie den Mittelwert oder benachbarte Messwerte. Die ursprüngliche Bedeutung der Daten soll erhalten bleiben – sonst kann die Analyse verfälscht werden.

1. CSV-Datei einlesen

Mit dem csv-Modul kannst du eine Tabelle mit Messwerten zeilenweise einlesen. 

import csv  # Modul zum Arbeiten mit CSV-Dateien

def einlesen_datei(pfad):
    daten = []
    with open(pfad, newline='', encoding='utf-8') as datei:
        reader = csv.DictReader(datei)  # jede Zeile wird als Wörterbuch eingelesen
        for zeile in reader:
            daten.append(zeile)
    return daten

messwerte = einlesen_datei("messwerte.csv")
print("Anzahl der Datensätze:", len(messwerte))

2. Fehlende Werte löschen

Wenn Temperaturwerte fehlen (z. B. "N/A" oder leer), entfernen wir die ganze Zeile. 

def entferne_fehlende(daten, spalte):
    neue_daten = []
    geloescht = 0  # Zähler für gelöschte Zeilen
    for eintrag in daten:
        wert = eintrag[spalte]
        if wert != "N/A" and wert.strip() != "":
            neue_daten.append(eintrag)
        else:
            geloescht += 1  # eine ungültige Zeile wurde übersprungen
    print(f"{geloescht} Zeilen wurden wegen fehlender Werte in '{spalte}' entfernt.")
    return neue_daten

messwerte = entferne_fehlende(messwerte, "Temperatur")

3. Unrealistische Werte ersetzen

Werte unter −30 °C oder über 50 °C gelten in diesem Kurs als unrealistisch (dieselben Grenzen gelten auf Seite 3.6). Wir ersetzen sie hier durch den Mittelwert aus dem vorherigen und dem nächsten Messwert. Liegt ein Ausreißer ganz am Anfang oder Ende der Messreihe, hat er nur einen Nachbarn und bleibt in dieser einfachen Variante unverändert. 

def ersetze_unrealistische(messwerte, spalte, min_wert, max_wert):
    for i in range(len(messwerte)):
        wert = float(messwerte[i][spalte])
        if wert < min_wert or wert > max_wert:
            if i > 0 and i < len(messwerte) - 1:
                vorher = float(messwerte[i - 1][spalte])
                nachher = float(messwerte[i + 1][spalte])
                ersatz = (vorher + nachher) / 2
                messwerte[i][spalte] = ersatz  # Wert durch Mittelwert der Nachbarn ersetzen

ersetze_unrealistische(messwerte, "Temperatur", -30, 50)
print("Unrealistische Werte ersetzt.")

4. Statistik berechnen

Für jeden Tag berechnen wir: Durchschnitt, Minimum und Maximum der Temperatur. 

def temperatur_statistik(daten):
    tage = {}
    for eintrag in daten:
        tag = eintrag["Zeitpunkt"].split(" ")[0]  # Datum extrahieren
        temperatur = float(eintrag["Temperatur"])
        if tag not in tage:
            tage[tag] = []
        tage[tag].append(temperatur)

    for tag in tage:
        werte = tage[tag]
        durchschnitt = sum(werte) / len(werte)
        print(f"{tag}: Mittel = {durchschnitt:.1f}°C, Min = {min(werte):.1f}°C, Max = {max(werte):.1f}°C")

temperatur_statistik(messwerte)
Praxisbezug: Datenbereinigung im Beruf

In der Praxis sind Rohdaten fast nie sauber: Sensoren fallen aus und liefern „N/A“, Formulare werden falsch ausgefüllt, beim Export verrutschen Spalten. Data Analysts schätzen, dass sie einen großen Teil ihrer Arbeitszeit mit dem Bereinigen verbringen, bevor überhaupt ausgewertet wird. Bei Wetterdiensten wie dem Deutschen Wetterdienst werden Messwerte automatisch auf Plausibilität geprüft – mit Grenzwerten wie auf dieser Seite. Wichtig ist, jede Bereinigung zu dokumentieren: Wer Ausreißer ersetzt, verändert die Daten und muss das offenlegen.

5. Reguläre Ausdrücke (Wiederholung)

Reguläre Ausdrücke (kurz Regex) kennst du bereits aus Klassenstufe 10 (Sprachen): Es handelt sich um Suchmuster, mit denen du Text nach bestimmten Regeln durchsuchen, überprüfen oder ersetzen kannst – zum Beispiel um zu prüfen, ob eine Eingabe einem bestimmten Format entspricht. In Python steht dafür das Modul re zur Verfügung; in vielen Texteditoren (z. B. Visual Studio Code) kannst du reguläre Ausdrücke auch direkt in der Suchfunktion nutzen.

Auf dieser Seite werden folgende Sonderzeichen verwendet:

Zeichen Bedeutung
^ Anfang des Textes
$ Ende des Textes
\d eine Ziffer (0–9)
\w ein Wortzeichen (Buchstabe, Ziffer oder Unterstrich)
+ das vorangehende Zeichen ein- oder mehrmals
{n} das vorangehende Zeichen genau n-mal
[...] eines der Zeichen innerhalb der eckigen Klammern
\. ein tatsächlicher Punkt (ohne den Backslash würde ein Punkt „irgendein Zeichen“ bedeuten)
Hinweis: ^ und $

^ und $ legen fest, dass das Muster am Anfang bzw. Ende des gesamten Textes stehen muss. Bei re.fullmatch() muss ohnehin der komplette Text passen – ^ und $ sind hier also nicht zwingend nötig, machen aber deutlich, dass keine zusätzlichen Zeichen davor oder danach erlaubt sein sollen. Bei re.search() ohne ^/$ reicht es dagegen, wenn das Muster irgendwo im Text vorkommt. 

import re

muster = r"^\d{5}$"  # genau 5 Ziffern
text = "01067"

if re.fullmatch(muster, text):
    print("Gültige Postleitzahl")
else:
    print("Ungültige Postleitzahl")

Werte aus Text herausziehen und vereinheitlichen

Reguläre Ausdrücke prüfen nicht nur, sie holen auch Teile aus einem Text heraus (re.search(...).group(), re.findall()) oder ersetzen sie (re.sub()). So lassen sich uneinheitlich erfasste Daten bereinigen: 

import re

adresse = "Schillerplatz 3, 01309 Dresden"
treffer = re.search(r"\d{5}", adresse)          # erste Folge aus genau 5 Ziffern
print(treffer.group())                          # 01309

text = "Messung 1: 21,5 °C – Messung 2: 22,1 °C"
werte = re.findall(r"\d+,\d", text)             # alle Dezimalzahlen mit Komma
print(werte)                                    # ['21,5', '22,1']
zahlen = [float(w.replace(",", ".")) for w in werte]
print(zahlen)                                   # [21.5, 22.1]

telefon = "0351 / 123-45 67"
print(re.sub(r"\D", "", telefon))               # 03511234567

\D steht für „keine Ziffer“; re.sub(r"\D", "", telefon) entfernt also alle Leerzeichen, Schrägstriche und Bindestriche, sodass jede Telefonnummer im selben Format gespeichert wird.

Beispiel 1 einfach Ein Muster Schritt für Schritt aufbauen – Messwerte aus Freitext

Ausgangssituation: In einer Tabelle wurden Temperaturen von Hand eingetragen, jede*r anders: "21,5 °C", " 22.1C", "23°C", "N/A", "-3,0 °C", "ca. 19". Daraus sollen Zahlen werden; wo keine Zahl steht, soll None stehen.

  1. Erster Versuch \d+ – „eine oder mehrere Ziffern“. Bei "21,5 °C" findet re.search nur 21: Die Nachkommastelle fehlt.
  2. Dezimaltrenner ergänzen: \d+[.,]\d+ – Ziffern, dann Punkt oder Komma, dann Ziffern. Jetzt passt 21,5 und 22.1, aber "23°C" liefert keinen Treffer mehr, weil dort kein Trenner steht.
  3. Nachkommateil optional machen: \d+([.,]\d+)? – Die runden Klammern fassen den Nachkommateil zu einer Gruppe zusammen, das ? dahinter heißt „null- oder einmal“. Jetzt passen 21,5, 22.1 und 23.
  4. Vorzeichen ergänzen: -?\d+([.,]\d+)? – Ohne -? würde aus "-3,0 °C" der Wert 3,0: ein stiller Fehler mit vertauschtem Vorzeichen.
  5. Treffer umwandeln – Komma durch Punkt ersetzen, dann float().
import re

rohwerte = ["21,5 °C", " 22.1C", "23°C", "N/A", "-3,0 °C", "ca. 19"]
muster = r"-?\d+([.,]\d+)?"

bereinigt = []
for roh in rohwerte:
    treffer = re.search(muster, roh)
    if treffer:
        bereinigt.append(float(treffer.group().replace(",", ".")))
    else:
        bereinigt.append(None)
print(bereinigt)

Ergebnis: [21.5, 22.1, 23.0, None, -3.0, 19.0]

Kontrolle: Jeder Rohwert muss genau einen Eintrag in der Ergebnisliste haben (6 Rohwerte, 6 Einträge), und "N/A" darf nicht zu einer Zahl werden. treffer.group() liefert immer den ganzen Treffer, auch wenn das Muster Klammern enthält.

Beispiel 2 komplex Uneinheitliche Datumsangaben vereinheitlichen

Ausgangssituation: Bei der Anmeldung zum Sportfest wurde das Datum frei eingetippt: "3.5.2025", " 03.05.25", "2025-05-03", "5/3/2025", "5.13.2025". Alle Angaben sollen in das Format JJJJ-MM-TT (ISO 8601) gebracht werden, das sich richtig sortieren lässt. Was sich nicht sicher deuten lässt, wird None und später von Hand geprüft.

import re

def datum_iso(text):
    text = text.strip()                                    # Leerzeichen am Rand entfernen
    t = re.fullmatch(r"(\d{1,2})\.(\d{1,2})\.(\d{4}|\d{2})", text)
    if t:
        tag, monat, jahr = int(t.group(1)), int(t.group(2)), t.group(3)
        if not (1 <= tag <= 31 and 1 <= monat <= 12):     # Regex prüft keine Bereiche
            return None
        if len(jahr) == 2:
            jahr = "20" + jahr
        return f"{jahr}-{monat:02d}-{tag:02d}"
    if re.fullmatch(r"\d{4}-\d{2}-\d{2}", text):          # schon im Zielformat
        return text
    return None

for d in ["3.5.2025", " 03.05.25", "2025-05-03", "5/3/2025", "5.13.2025"]:
    print(repr(d), "->", datum_iso(d))
  1. Leerzeichen entfernen – strip() zuerst, sonst scheitert fullmatch an " 03.05.25".
  2. Muster mit Gruppen – (\d{1,2}) erlaubt ein- oder zweistellige Tage und Monate, \. ist der echte Punkt, (\d{4}|\d{2}) ein vier- oder zweistelliges Jahr. Die drei Klammern liefern t.group(1) bis t.group(3).
  3. „3.5.2025“: Gruppen 3, 5, 2025 → 2025-05-03. :02d füllt mit führender Null auf.
  4. „ 03.05.25“: zweistelliges Jahr → „20“ davor → 2025-05-03. Falle: Bei Geburtsdaten wäre „98“ dann 2098 – für solche Daten darf man das Jahrhundert nicht raten.
  5. „2025-05-03“: passt nicht zum ersten Muster, aber zum ISO-Muster und bleibt unverändert.
  6. „5/3/2025“: Schrägstriche passen zu keinem Muster → None. Das ist Absicht: Ob 5. März oder 3. Mai gemeint ist (amerikanische Schreibweise), lässt sich nicht entscheiden.
  7. „5.13.2025“: passt formal zum Muster, aber Monat 13 gibt es nicht. Reguläre Ausdrücke prüfen nur die Form, nicht die Bedeutung – deshalb die zusätzliche Bereichsprüfung → None.

Ergebnis:

'3.5.2025' -> 2025-05-03
' 03.05.25' -> 2025-05-03
'2025-05-03' -> 2025-05-03
'5/3/2025' -> None
'5.13.2025' -> None

Kontrolle: Die ersten drei Eingaben meinen denselben Tag und ergeben denselben Text – genau das ist das Ziel der Vereinheitlichung. Die Bereichsprüfung ist bewusst grob: Ein Datum wie 31.02. würde noch durchgelassen; dafür wäre das Modul datetime nötig.

Das Wichtigste

Datenbereinigung: fehlerhafte, unvollständige oder widersprüchliche Daten erkennen und entfernen, korrigieren oder durch sinnvolle Ersatzwerte ersetzen, damit die Analyse zuverlässige Ergebnisse liefert.

Regulärer Ausdruck: Muster aus normalen Zeichen und Sonderzeichen (z. B. \d für eine Ziffer, + für „ein- oder mehrmals“), mit dem man prüft, ob ein Text diesem Muster entspricht.
