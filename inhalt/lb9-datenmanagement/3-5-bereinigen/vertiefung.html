Aufgabe 3.5.5: Fehler finden – vier Muster, die zu viel oder das Falsche tun AFB III

In einem Bereinigungsskript stehen diese vier Zeilen. Jede enthält einen Fehler.

import re
print(bool(re.search(r"\d{2}:\d{2}", "125:309")))       # soll eine Uhrzeit HH:MM erkennen
print(bool(re.fullmatch(r"\d+.\d+", "12x5")))           # soll eine Dezimalzahl erkennen
print(re.sub(r"\d", "", "0351 / 123-45 67"))            # soll nur die Ziffern übrig lassen
print(int(re.search(r"\d{5}", "01067 Dresden").group())) # soll die PLZ speichern
  1. Bestimme ohne Computer die Ausgabe jeder Zeile.
  2. Erkläre jeweils, warum das Ergebnis nicht dem Ziel entspricht.
  3. Korrigiere jede Zeile und gib für jede Korrektur einen Testfall an, der vorher falsch und jetzt richtig ist.
