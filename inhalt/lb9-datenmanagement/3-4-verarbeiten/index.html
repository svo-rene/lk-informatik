Nachdem wir gelernt haben, wie man CSV-Dateien in Python einliest, beschäftigen wir uns jetzt mit der Verarbeitung dieser Daten. Typische Aufgaben sind:

  • Bestimmte Werte gezielt ausgeben
  • Berechnungen durchführen (z. B. schnellste Zeit finden)
  • Daten filtern (z. B. nur Teilnehmende aus einer bestimmten Stadt)

Als Beispiel nutzen wir die Ergebnisse einer Sportveranstaltung.

Angenommene CSV-Datei sportveranstaltung.csv:

Durchgerechnete Beispiele

Die folgenden vier Beispiele arbeiten mit der Datei schueler.csv aus Seite 3.3 (Spalten Name;Alter;Note, 10 Datensätze). Sie zeigen die vier Grundmuster, die du in den Übungsaufgaben auf die Sportdaten überträgst. Alle Beispiele beginnen mit demselben Einlesen: 

import csv

Beispiel 1 einfach

Ausgangssituation: Aus schueler.csv soll die Durchschnittsnote aller 10 Schüler*innen berechnet werden. Nach dem Einlesen sind aber alle Werte Texte.

Beispiel 1: Texte in Zahlen umwandeln – int() und float()

print(schueler[0])                       # {'Name': 'Anna', 'Alter': '17', 'Note': '1.3'}
print(schueler[0]['Alter'] + '1')        # 171   – Text + Text wird aneinandergehängt!
print(int(schueler[0]['Alter']) + 1)     # 18    – erst umwandeln, dann rechnen
print(float(schueler[0]['Note']) * 2)    # 2.6

summe = 0
for s in schueler:
    summe += float(s['Note'])
print(round(summe / len(schueler), 2))   # 1.95  – Durchschnittsnote aller 10

int('1.3') würde mit einem ValueError abbrechen, weil '1.3' keine ganze Zahl ist – für Dezimalzahlen brauchst du float(). Steht in der Datei ein Dezimalkomma ('1,3'), musst du es vorher ersetzen: float(text.replace(',', '.')).

Vollständiges Programm für die Durchschnittsnote:

import csv

schueler = []
with open('schueler.csv', newline='', encoding='utf-8-sig') as csvfile:
    reader = csv.DictReader(csvfile, delimiter=';')
    for row in reader:
        schueler.append(row)

summe = 0
for s in schueler:
    summe += float(s['Note'])
print(round(summe / len(schueler), 2))
  1. Einlesen: 10 Dictionaries, z. B. {'Name': 'Anna', 'Alter': '17', 'Note': '1.3'}. Warum DictReader? So greift man über den Spaltennamen 'Note' zu statt über eine Positionsnummer.
  2. Summe mit 0 beginnen: Warum 0? 0 verändert die Summe nicht; jeder Wert wird in der Schleife dazugezählt.
  3. Jeden Notentext mit float() umwandeln und addieren: 1.3 + 2.0 + 1.7 + 3.0 + 1.0 + 2.3 + 1.5 + 2.7 + 1.9 + 2.1 = 19.5. Warum float? Ohne Umwandlung würde summe += '1.3' einen TypeError auslösen (Zahl + Text).
  4. Durch die Anzahl teilen und runden: 19.5 / 10 = 1.95. Warum len(schueler)? So stimmt das Programm auch, wenn die Datei mehr oder weniger Zeilen hat.

Ergebnis: Ausgabe 1.95.

Eingabe (Inhalt von schueler.csv)erwartete Ausgabe
die 10 Datensätze aus dem Material1.95
nur Anna;17;1.3 und Ben;16;2.01.65
eine Note als 1,3 (Komma)ValueError – vorher replace(',', '.') einbauen

Kontrolle: Der Durchschnitt muss zwischen der besten (1.0) und der schlechtesten Note (3.0) liegen – 1.95 passt.

Beispiel 2: Den besten Wert finden

beste = schueler[0]                      # Startwert: der erste Datensatz
for s in schueler:
    if float(s['Note']) < float(beste['Note']):
        beste = s
print(beste['Name'], beste['Note'])      # Eva 1.0

Weil bei Schulnoten die kleinste Zahl die beste ist, steht hier <. Für den größten Wert – etwa die längste Laufzeit – drehst du den Vergleich um. Kürzer geht es mit min(schueler, key=lambda s: float(s['Note'])); die Schleife zeigt aber, was dabei passiert. Nach demselben Prinzip sortiert sorted(schueler, key=lambda s: float(s['Note'])) die ganze Liste von der besten zur schlechtesten Note (mit reverse=True umgekehrt).

Beispiel 3: Filtern

for s in schueler:
    if float(s['Note']) < 2.0:
        print(s['Name'], s['Note'])
# Ausgabe:
# Anna 1.3
# Clara 1.7
# Eva 1.0
# Greta 1.5
# Jonas 1.9

Häufiger Fehler: if s['Note'] < 2.0 ohne float() – dann vergleicht Python einen Text mit einer Zahl und bricht mit einem TypeError ab.

Beispiel 4: Gruppieren und Zählen

anzahl_je_alter = {}
namen_je_alter = {}
for s in schueler:
    alter = s['Alter']
    anzahl_je_alter[alter] = anzahl_je_alter.get(alter, 0) + 1   # zählen
    if alter not in namen_je_alter:                              # gruppieren
        namen_je_alter[alter] = []
    namen_je_alter[alter].append(s['Name'])

print(anzahl_je_alter)   # {'17': 5, '16': 5}
print(namen_je_alter)    # {'17': ['Anna', 'Clara', 'Eva', 'Greta', 'Jonas'],
                         #  '16': ['Ben', 'David', 'Finn', 'Hannah', 'Lena']}

Beim ersten Vorkommen einer Gruppe gibt es den Schlüssel noch nicht. .get(alter, 0) liefert dann 0 statt eines KeyError – dieselbe Technik wie auf Seite 2.3.

Beispiel 5 komplex Vereinswertung – alle vier Grundmuster in einem Programm

Ausgangssituation: Die Beispiele 1–4 zeigen die Grundmuster einzeln. Der Veranstalter des Laufs möchte aus sportveranstaltung.csv (10 Teilnehmende) eine Vereinswertung: Vereine werden nach der durchschnittlichen Laufzeit sortiert, zu jedem Verein wird die schnellste Person genannt. Sonderregel: Gewertet werden nur Vereine mit mindestens zwei Teilnehmenden.

import csv

vereine = {}
with open('sportveranstaltung.csv', newline='', encoding='utf-8') as csvfile:
    reader = csv.DictReader(csvfile, delimiter=';')
    for row in reader:
        verein = row['Verein']
        zeit = int(row['Zeit'])                       # Muster 1: umwandeln
        if verein not in vereine:                     # Muster 4: gruppieren
            vereine[verein] = []
        vereine[verein].append((zeit, row['Name']))

wertung = []
nicht_gewertet = []
for verein, laeufer in vereine.items():
    if len(laeufer) < 2:                             # Muster 3: filtern (Sonderregel)
        nicht_gewertet.append(verein)
        continue
    zeiten = [z for z, n in laeufer]
    schnitt = sum(zeiten) / len(zeiten)
    bester = min(laeufer)                             # Muster 2: Extremwert
    wertung.append((schnitt, verein, len(laeufer), bester))

wertung.sort()
platz = 1
for schnitt, verein, anzahl, bester in wertung:
    print(f"{platz}. {verein}: {anzahl} Teilnehmende, Schnitt {schnitt:.1f} min, "
          f"Schnellste Person: {bester[1]} ({bester[0]} min)")
    platz += 1
print("Nicht gewertet:", ", ".join(nicht_gewertet))
  1. Einlesen, umwandeln und gruppieren – Für jeden Verein entsteht eine Liste von Paaren (Zeit, Name). Die Zeit steht vorne, damit Python Paare später nach der Zeit vergleicht. Ergebnis nach der Schleife: Lauftreff Dresden: (42, Anna Müller), (39, David Lehmann), (38, Finn Neumann), (43, Jonas Richter); SV Chemnitz: (45, Ben Schneider), (47, Greta Hoffmann); LG Leipzig: (40, Clara Schulz), (44, Eva Kunze), (41, Hannah Fischer); SV Zwickau: (46, Lena Scholz).
  2. Sonderfall filtern – SV Zwickau hat nur eine Teilnehmerin und kommt in die Liste nicht_gewertet. continue springt sofort zum nächsten Verein.
  3. Durchschnitt je Verein – Dresden: (42 + 39 + 38 + 43) / 4 = 162 / 4 = 40,5; Chemnitz: 92 / 2 = 46,0; Leipzig: 125 / 3 = 41,67.
  4. Schnellste Person – min(laeufer) vergleicht die Paare zuerst nach der Zeit, also z. B. in Dresden (38, 'Finn Neumann').
  5. Sortieren – wertung.sort() sortiert die Tupel nach ihrem ersten Element, dem Durchschnitt: 40,5 < 41,67 < 46,0.
  6. Ausgeben – :.1f rundet für die Anzeige auf eine Nachkommastelle (41,666… wird 41.7).

Ergebnis:

1. Lauftreff Dresden: 4 Teilnehmende, Schnitt 40.5 min, Schnellste Person: Finn Neumann (38 min)
2. LG Leipzig: 3 Teilnehmende, Schnitt 41.7 min, Schnellste Person: Clara Schulz (40 min)
3. SV Chemnitz: 2 Teilnehmende, Schnitt 46.0 min, Schnellste Person: Ben Schneider (45 min)
Nicht gewertet: SV Zwickau
TestfallEingabeerwartete Ausgabe
Durchschnitt mit NachkommaLG Leipzig: 40, 44, 41Schnitt 41.7 min
SonderregelSV Zwickau mit 1 TeilnehmerinNicht gewertet: SV Zwickau

Kontrolle: 4 + 3 + 2 gewertete plus 1 nicht gewertete Person ergeben die 10 Zeilen der Datei. Die Falle: Ohne int() bricht sum(zeiten) mit einem TypeError ab, und min würde Texte alphabetisch statt Zahlen vergleichen.

Praxisbezug: Auswertungen im Onlinehandel und bei Sportveranstaltungen

Genau diese vier Muster stecken hinter fast jeder Auswertung im Berufsalltag: Ein Data Analyst im Onlinehandel wandelt Preise aus einem Export um, sucht den umsatzstärksten Artikel, filtert Bestellungen einer Region und zählt Bestellungen je Kategorie. Zeitnahmefirmen bei Stadtläufen wie dem Dresden-Marathon erstellen so Ergebnislisten je Altersklasse. Werden dabei Namen veröffentlicht, gilt die DSGVO: Die Teilnehmenden müssen bei der Anmeldung eingewilligt haben.

Das Wichtigste

Die vier Grundmuster der Datenverarbeitung:

  1. Umwandeln: Eingelesene Werte sind Texte. Vor dem Rechnen oder Vergleichen wandelst du sie mit int() (ganze Zahl) oder float() (Dezimalzahl mit Punkt) um.
  2. Extremwert suchen: eine Merkvariable mit dem ersten Wert anlegen und in der Schleife jedes Mal ersetzen, wenn ein größerer (bzw. kleinerer) Wert kommt.
  3. Filtern: in der Schleife mit if prüfen und nur passende Datensätze ausgeben oder sammeln.
  4. Gruppieren und Zählen: ein Dictionary als Zähler; Schlüssel ist die Gruppe, Wert die Anzahl (oder eine Liste der Mitglieder).

Wichtige Methoden zum Arbeiten mit Text:

  • startswith('Text'): Prüft, ob ein Textanfang übereinstimmt.
  • endswith('Text'): Prüft, ob ein Textende übereinstimmt.
  • 'Teiltext' in Text: Prüft, ob Teiltext enthalten ist.
  • isdigit(): Prüft, ob alle Zeichen eines Textes Ziffern sind ('42'.isdigit() ist True, '7.5'.isdigit() ist False).
  • lower(): Wandelt Text in Kleinbuchstaben um.
  • upper(): Wandelt Text in Großbuchstaben um.
  • strip(): Entfernt Leerzeichen am Anfang und Ende.
  • split(): Zerlegt einen Text in Teile (z. B. Vorname, Nachname).
