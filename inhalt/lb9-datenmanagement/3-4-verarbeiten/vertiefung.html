Aufgabe 3.4.17: Ergebnis prüfen – die Stadtauswertung AFB III

Jonas soll für den Lauf die Durchschnittszeit je Stadt und die schnellste Person bestimmen. Sein Programm läuft ohne Fehlermeldung:

import csv

summen = {}
anzahl = {}
beste_zeit = '100'
beste_person = ''
with open('sportveranstaltung.csv', newline='', encoding='utf-8') as csvfile:
    reader = csv.DictReader(csvfile, delimiter=';')
    for row in reader:
        stadt = row['Stadt']
        summen[stadt] = summen.get(stadt, 0) + int(row['Zeit'])
        anzahl[stadt] = 1
        if row['Zeit'] < beste_zeit:
            beste_zeit = row['Zeit']
            beste_person = row['Name']

for stadt in summen:
    print(stadt, summen[stadt] / anzahl[stadt])
print('Schnellste Person:', beste_person, beste_zeit)
  1. Bestimme ohne Computer die vollständige Ausgabe des Programms für sportveranstaltung.csv.
  2. Vergleiche mit den Ergebnissen, die du von Hand erwartest, und erkläre die beiden Fehler.
  3. Korrigiere das Programm. Gib die richtige Ausgabe an, wobei die Durchschnitte auf eine Nachkommastelle gerundet werden sollen.
  4. Beurteile, warum gerade solche Fehler ohne Fehlermeldung gefährlich sind, und leite eine Regel für das Testen ab.
