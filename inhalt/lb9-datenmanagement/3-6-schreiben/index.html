Das Speichern von Daten im CSV-Format ist eine zentrale Methode, um strukturierte Informationen systemübergreifend weiterzugeben, zu archivieren oder automatisiert auszuwerten.

Daten mit csv.writer() als csv-Datei speichern

Das folgende Beispiel zeigt, wie mehrere strukturierte Datensätze mithilfe des Moduls csv in eine neue CSV-Datei geschrieben werden. Die Daten werden als Liste von Zeilen definiert und anschließend vollständig exportiert. 

import csv  
daten = [  
    ["Name", "Alter", "Note"],   # Kopfzeile (Spaltenüberschriften)
    ["Anna", "17", "1.3"],       # Erste Datenzeile
    ["Ben", "16", "2.0"]         # Zweite Datenzeile
]

with open("ausgabe.csv", "w", newline="", encoding="utf-8") as datei:
    writer = csv.writer(datei, delimiter=";") # Erzeuge ein CSV-Schreibobjekt mit Semikolon als Trennzeichen
    writer.writerows(daten) # Schreibe alle Datenzeilen auf einmal in die Datei
Hinweis: Warum newline="" und utf-8?

Das csv-Modul schreibt jedes Zeilenende selbst als \r\n. Ohne newline="" würde Python unter Windows daraus zusätzlich \r\r\n machen – beim Öffnen erscheint dann nach jedem Datensatz eine Leerzeile.
utf-8 sichert die Darstellung von Umlauten und Sonderzeichen.

Daten mit csv.DictWriter() als csv-Datei schreiben

In diesem Beispiel werden strukturierte Datensätze in Form von Dictionaries in eine CSV-Datei geschrieben. Durch die Verwendung von Spaltennamen können die Daten gezielt und übersichtlich gespeichert werden. 

import csv

daten = [
    {"Name": "Anna", "Alter": "17", "Note": "1.3"},
    {"Name": "Ben", "Alter": "16", "Note": "2.0"}
]

with open("ausgabe_dict.csv", "w", newline="", encoding="utf-8") as datei:
    feldnamen = ["Name", "Alter", "Note"]  # Definiere die Reihenfolge der Spalten

    writer = csv.DictWriter(datei, fieldnames=feldnamen, delimiter=";")# Erzeuge ein CSV-Schreibobjekt mit Spaltennamen
    writer.writeheader()# Schreibe zuerst die Kopfzeile
    writer.writerows(daten)# Schreibe alle Dictionaries in die Datei
Hinweis: Dateien schreiben, bestehende Dateien ändern

Der Modus "r" steht für read – Datei wird nur gelesen.
Der Modus "w" steht für write – Datei wird neu geschrieben (bestehende Inhalte werden gelöscht).
Der Modus "a" steht für append – neue Inhalte werden am Ende der Datei angehängt.

Einzelne Zeilen gezielt schreiben

Neben dem Schreiben ganzer Tabellen kann es sinnvoll sein, einzelne Ergebnisse oder aggregierte Daten schrittweise in eine CSV-Datei zu schreiben – etwa zur Dokumentation von Berechnungen oder zur Protokollierung.

Beispiel: Einzelwerte in CSV speichern

import csv

# Beispielwerte einer Temperaturauswertung
anzahl_messungen = 120
durchschnitt = 21.7
maximum = 34.5
minimum = 15.2

with open("auswertung_temperatur.csv", mode="w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file, delimiter=";")

    writer.writerow(["Anzahl Messungen", anzahl_messungen])
    writer.writerow(["Durchschnittstemperatur (°C)", durchschnitt])

    writer.writerow([])  # Leerzeile zur Trennung
    writer.writerow(["Maximale Temperatur (°C)", maximum])
    writer.writerow(["Minimale Temperatur (°C)", minimum])

Beispiel: Dictionary in CSV speichern

import csv

statistik = {16: 3, 17: 5, 18: 2}

with open("schueler_nach_alter.csv", "w", newline="", encoding="utf-8") as datei:
    writer = csv.writer(datei, delimiter=";")
    writer.writerow(["Alter", "Anzahl"])

    for alter, anzahl in statistik.items():
        writer.writerow([alter, anzahl])
Beispiel 1 einfach Gefilterte Daten in eine neue Datei schreiben

Ausgangssituation: Aus schueler.csv (Spalten Name;Alter;Note) sollen alle Schüler*innen mit einer Note besser als 2,0 in die Datei gute_noten.csv geschrieben werden – nur mit Name und Note.

import csv

ergebnis = []
with open('schueler.csv', newline='', encoding='utf-8') as datei:
    for zeile in csv.DictReader(datei, delimiter=';'):
        if float(zeile['Note']) < 2.0:
            ergebnis.append({'Name': zeile['Name'], 'Note': zeile['Note']})

with open('gute_noten.csv', 'w', newline='', encoding='utf-8') as datei:
    writer = csv.DictWriter(datei, fieldnames=['Name', 'Note'], delimiter=';')
    writer.writeheader()
    writer.writerows(ergebnis)

print(len(ergebnis), "Datensätze geschrieben")
  1. Lesen und filtern – Die Note wird nur für den Vergleich in eine Zahl umgewandelt. Gespeichert wird der Originaltext, damit in der neuen Datei genau dasselbe steht wie in der alten.
  2. Nur benötigte Spalten übernehmen – Jedes neue Dictionary enthält nur Name und Note (Datenminimierung: Das Alter braucht der Empfänger nicht).
  3. Datei mit 'w' öffnen – Eine vorhandene Datei gleichen Namens wird überschrieben; das Programm kann also beliebig oft laufen, ohne dass sich Zeilen doppeln.
  4. Kopfzeile, dann Daten – writeheader() schreibt die Feldnamen, writerows() alle Dictionaries.

Ergebnis: Auf der Konsole steht 5 Datensätze geschrieben. Die Datei gute_noten.csv enthält:

Name;Note
Anna;1.3
Clara;1.7
Eva;1.0
Greta;1.5
Jonas;1.9

Kontrolle: Die Datei mit csv.DictReader wieder einlesen: 5 Datensätze, der erste ist {'Name': 'Anna', 'Note': '1.3'}. Ben (2.0) fehlt zu Recht, weil 2.0 < 2.0 falsch ist.

Beispiel 2 komplex Eine kleine Pipeline: einlesen, zusammenfassen, für Excel schreiben

Ausgangssituation: Aus wetterdaten.csv (16 Messungen aus Dresden, Leipzig und Chemnitz) soll eine Zusammenfassung je Ort entstehen: Anzahl der Messungen, mittlere und höchste Temperatur. Die Datei soll sich in einem deutschen Excel per Doppelklick richtig öffnen – mit Umlauten und Dezimalkomma.

import csv

orte = {}
with open('wetterdaten.csv', newline='', encoding='utf-8') as datei:
    for zeile in csv.DictReader(datei, delimiter=';'):
        orte.setdefault(zeile['Ort'], []).append(int(zeile['Temperatur']))

with open('wetter_zusammenfassung.csv', 'w', newline='', encoding='utf-8-sig') as datei:
    writer = csv.writer(datei, delimiter=';')
    writer.writerow(['Ort', 'Messungen', 'Mittel', 'Maximum'])
    for ort, temps in orte.items():
        mittel = sum(temps) / len(temps)
        writer.writerow([ort, len(temps), f"{mittel:.1f}".replace('.', ','), max(temps)])
  1. Einlesen und gruppieren – setdefault legt für jeden neuen Ort eine leere Liste an und hängt die Temperatur an. Ergebnis: Dresden [18, 20, 22, 21, 23, 24, 22, 25], Leipzig [16, 19, 20, 21], Chemnitz [15, 17, 18, 19].
  2. Zusammenfassen – Dresden: 175 / 8 = 21,875; Leipzig: 76 / 4 = 19,0; Chemnitz: 69 / 4 = 17,25.
  3. Runden – die Falle – f"{17.25:.1f}" ergibt 17.2, nicht 17.3. Liegt ein Wert genau auf der Mitte, rundet Python zur geraden Ziffer („Banker’s Rounding“). 21,875 liegt dagegen nicht auf der Mitte und wird zu 21.9.
  4. Dezimalkomma für Excel – Python schreibt Zahlen mit Punkt. Ein deutsches Excel würde 21.9 als Datum oder Text deuten. Deshalb wird der formatierte Text mit replace('.', ',') umgewandelt. Das Semikolon als Trennzeichen ist nötig, weil das Komma jetzt in den Zahlen vorkommt.
  5. Kodierung utf-8-sig – Sie schreibt das BOM an den Dateianfang. Daran erkennt Excel, dass die Datei UTF-8 ist, und zeigt Umlaute richtig an. Beim Einlesen in Python braucht man dann ebenfalls utf-8-sig (Seite 3.3).
  6. Modus 'w' – Mit 'a' würde bei jedem Programmlauf erneut eine Kopfzeile samt Daten angehängt.

Ergebnis: Inhalt von wetter_zusammenfassung.csv:

Ort;Messungen;Mittel;Maximum
Dresden;8;21,9;25
Leipzig;4;19,0;21
Chemnitz;4;17,2;19
Testfallerwartete Ausgabe
Summe der Messungen8 + 4 + 4 = 16 = Zeilen der Eingabedatei
Mittelwert genau auf der Mitte (Chemnitz)17,2
ganzzahliger Mittelwert (Leipzig)19,0 (mit Nachkommastelle)

Kontrolle: Die Zahl der Messungen muss in Summe die Zeilenzahl der Eingabe ergeben. Wer kaufmännisch runden muss (Rechnungen), nutzt statt float das Modul decimal.

Grundaufgaben: Ergebnisse exportieren

Praxisbezug: Berichte automatisch erzeugen

In vielen Firmen entstehen Berichte nicht mehr per Hand: Ein Python-Skript liest nachts die Rohdaten, bereinigt sie und schreibt die Ergebnisse als CSV, die morgens automatisch in Excel oder einem Dashboard erscheinen. So arbeiten etwa Data Engineers bei Stadtwerken, die Zählerstände auswerten, oder Data Analysts im Onlinehandel, die tägliche Verkaufszahlen je Produkt ausgeben. Beim Export personenbezogener Daten gilt die DSGVO: In eine Auswertung gehören nur die Spalten, die der Empfänger wirklich braucht.

Das Wichtigste

writerow() schreibt genau eine einzelne Zeile in die CSV-Datei.
writerows() schreibt mehrere Zeilen auf einmal.
Nutze writerow() bei Schleifen oder Einzelergebnissen, writerows() bei kompletten Datensätzen.
