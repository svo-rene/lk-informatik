Aufgabe 1.8.10: Fehler finden – drei Änderungen, drei Pannen AFB III

Alle drei Befehle laufen ohne Fehlermeldung, richten aber Schaden an. Gib jeweils an, welche bzw. wie viele Zeilen tatsächlich verändert werden, erkläre den Fehler und korrigiere den Befehl.

  1. Gemeint: Anna Fischer (s_id 3) heißt nach ihrer Heirat „Schulz“. 
    UPDATE Schueler SET name = 'Schulz';
  2. Gemeint: Lisa Müller (s_id 1) bekommt nach einer Nachprüfung in Deutsch (k_id 2) die Note 1.0. 
    UPDATE Kursnote SET note = 1.0 WHERE s_id = 1 OR k_id = 2;
  3. Gemeint: Tim Weber (s_id 4) bekommt in Deutsch (k_id 2) die Note 1.7. 
    INSERT INTO Kursnote VALUES (2, 1.7, 4);

Beurteile abschließend, mit welcher Arbeitsweise sich alle drei Pannen vorab hätten verhindern lassen.
