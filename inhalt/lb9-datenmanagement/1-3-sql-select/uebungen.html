Aufgabe 1.3.4: Ergebnis vorhersagen AFB II

Bevor du eine Abfrage ausführst, solltest du ungefähr wissen, was herauskommen muss. Sage für den Ausschnitt mit den 5 Zeilen oben das Ergebnis dieser Abfrage voraus: Spaltenüberschriften, Werte und Reihenfolge.

SELECT Nachname AS Name,
       Notendurchschnitt AS Schnitt,
       2026 - CAST(substr(Geburtsdatum, 1, 4) AS INTEGER) AS Lebensjahre
FROM Studenten
ORDER BY Lebensjahre ASC, Schnitt DESC;

Arbeite in der Reihenfolge FROM → SELECT → ORDER BY und notiere nach dem SELECT eine Zwischentabelle.
