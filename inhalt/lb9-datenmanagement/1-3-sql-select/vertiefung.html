Aufgabe 1.3.6: Ist die Liste richtig sortiert? AFB III

Für ein Namensverzeichnis schreibt Jonas

SELECT Nachname, Vorname
FROM Studenten
ORDER BY Nachname;

Im Ergebnis findet er diesen Abschnitt:

NachnameVorname
KleinMia
KrauseFelix
KrugerAlina
KrämerSofia
KöhlerJan
KönigMarie

Jonas meint: „Die Datenbank sortiert falsch. Krämer gehört vor Krause, und Köhler gehört vor Krause.“

  1. Erkläre, nach welcher Regel SQLite hier sortiert und warum diese Reihenfolge entsteht.
  2. Suche in der vollständigen Liste eine weitere Stelle, an der ein Name mit Umlaut „zu spät“ einsortiert wird.
  3. Beurteile, ob die Liste für ein gedrucktes Namensverzeichnis taugt, und schlage eine pragmatische Lösung vor.
Aufgabe 1.3.7: Fehler finden – die Abfrage läuft, aber… AFB III

Gesucht ist eine Liste mit Vorname und Notendurchschnitt aller Studierenden, beste Note zuerst. Lea schreibt:

SELECT Vorname Notendurchschnitt
FROM Studenten
ORDER BY Notendurchschnitt DESC;

SQLite meldet keinen Fehler. Sage für den Ausschnitt mit den 5 Zeilen oben das tatsächliche Ergebnis voraus, erkläre beide Fehler und gib eine korrigierte Abfrage an.

Ein Alias darf in SQL auch ohne das Wort AS geschrieben werden.
