Aufgabe 3.10.5: Fehler finden – ungültiges JSON AFB III

Ein Mitschüler hat die Konfigurationsdatei für seinen Discord-Bot von Hand geschrieben. json.load meldet bei jeder der folgenden Varianten einen JSONDecodeError:

  1. {'prefix': '!', 'aktiv': true}
  2. {"prefix": "!", "aktiv": True}
  3. {"prefix": "!", "kanaele": ["allgemein", "hausaufgaben",]}
  4. {"prefix": "!", "aktiv": true // Bot einschalten }

Außerdem schreibt er zum Einlesen daten = json.load('{"prefix": "!"}') und wundert sich über einen AttributeError.

Finde in jedem Fall den Fehler, korrigiere ihn und erkläre, welcher Unterschied zwischen Python und JSON bzw. zwischen load und loads dahintersteckt. Leite eine Regel ab, wie man solche Fehler vermeidet.

Aufgabe 3.10.6: Ein JSON-Format für den Vertretungsplan entwerfen AFB III

Die Schüler-App soll den Vertretungsplan als JSON vom Schulserver laden. Für einen Tag gibt es mehrere Änderungen; jede betrifft eine Klasse bzw. einen Kurs, eine Stunde (oder mehrere), ein Fach und eine Art (Vertretung, Ausfall, Raumänderung). Eine Vertretung hat eine Lehrkraft und einen Raum, ein Ausfall nicht.

  1. Entwirf ein JSON-Dokument für den 12.03.2027 mit mindestens vier Änderungen unterschiedlicher Art.
  2. Gib die Python-Zugriffe an, mit denen die App (a) alle Ausfälle der Klasse 10b und (b) den Raum der ersten Änderung ermittelt.
  3. Beurteile, ob CSV für diesen Zweck ebenso gut geeignet wäre, und begründe, welche Angaben aus Datenschutzgründen nicht in die öffentlich abrufbare Datei gehören.
