JSON (JavaScript Object Notation) ist ein leichtgewichtiges Datenformat, das sich hervorragend zur Strukturierung und zum Austausch von Daten eignet. Es wurde ursprünglich für JavaScript entwickelt, ist aber inzwischen sprachunabhängig und wird von fast allen modernen Programmiersprachen unterstützt.

Praxisbezug: JSON im ganz normalen Alltag

JSON begegnet dir öfter, als du denkst, auch wenn du es nie direkt siehst: Öffnest du morgens die Wetter-App, holt sie sich die aktuelle Temperatur im Hintergrund als JSON von einem Server. Fragst du in der Fahrplan-App des ÖPNV nach der nächsten Verbindung, wird die Antwort mit Abfahrtszeiten und Verspätungen ebenfalls häufig als JSON übertragen. Auch die Deutsche Bahn stellt ihre Fahrplandaten (Bahnhofssuche, Abfahrts- und Ankunftstafeln, Zugläufe) über eine offene REST-Schnittstelle bereit, die JSON und XML als Format anbietet.

Berufsfelder: Mit JSON arbeiten zum einen klassische IT-Berufe wie Web- und App-Entwickler*innen oder Data Engineers, die Schnittstellen anbinden und Daten weiterverarbeiten. Zum anderen kommen aber auch Berufe außerhalb der Informatik regelmäßig mit JSON-Exporten und -Importen in Kontakt, etwa in der Marktforschung beim Export von Umfragedaten, im Datenjournalismus bei der Auswertung offener Datensätze (Open Data) oder in der Verkehrsplanung bei der Nutzung von Echtzeit-Fahrplandaten.

Was ist JSON?

JSON ist ein textbasiertes Datenformat, das zur Übertragung von Daten zwischen Systemen und Anwendungen verwendet wird. Es ist einfach lesbar und gleichzeitig für Maschinen leicht zu parsen und zu generieren. JSON ist zu einem Standard für Web-APIs geworden und ersetzt zunehmend ältere Formate wie XML.

Hinweis: Was ist eine API?

Eine API (Application Programming Interface) ist eine Schnittstelle, die es zwei Anwendungen ermöglicht, miteinander zu kommunizieren. APIs definieren die Regeln und Formate, die eine Anwendung verwenden kann, um Daten oder Dienste von einer anderen anzufordern. Ein bekanntes Beispiel ist eine Wetter-API, die aktuelle Wetterdaten in einem strukturierten Format wie JSON bereitstellt.

Wie ist JSON aufgebaut?

JSON besteht aus Schlüssel-Wert-Paaren und unterstützt folgende Datentypen:

  • Objekte: Geschachtelte Paare von Schlüssel und Wert, um komplexe Datenstrukturen darzustellen.
  • Arrays: Geordnete Listen von Werten, die verschiedene Datentypen enthalten können.
  • Primitive Datentypen: String, Zahl, Boolean (true/false) und null.

Was ist ein JSON-Objekt?

Ein JSON-Objekt ist eine Sammlung von Schlüssel-Wert-Paaren, die durch geschweifte Klammern {} umschlossen sind. Es ist das grundlegende Strukturmerkmal in JSON und ermöglicht die Darstellung komplexer Datenstrukturen.

JSON-Objekte haben folgende Eigenschaften:

  • Schlüssel: Immer ein String, der als Bezeichner für den Wert dient (z. B. "name").
  • Werte: Können Strings, Zahlen, Boolean-Werte, null, Arrays oder andere JSON-Objekte sein.
  • Trennzeichen: Schlüssel und Wert werden durch einen Doppelpunkt (:) getrennt. Paare werden durch ein Komma (,) getrennt.

Hier ist ein Beispiel für ein JSON-Objekt:

{
    "name": "Max Mustermann",
    "age": 30,
    "skills": ["JavaScript", "Python", "JSON"],
    "isEmployed": true
}

Ein weiteres Beispiel mit verschachtelten Objekten:

{
    "person": {
        "name": "Max Mustermann",
        "age": 30
    },
    "job": {
        "title": "Softwareentwickler",
        "skills": ["JavaScript", "Python", "JSON"]
    }
}

Verschachtelte Objekte erlauben es, komplexe Strukturen wie Personen mit zugehörigen Jobs und Fähigkeiten darzustellen.

Warum wird JSON in der Praxis genutzt?

JSON ist in der Praxis aus mehreren Gründen beliebt:

  • Einfachheit: JSON ist leicht zu lesen und zu schreiben, sowohl für Menschen als auch für Maschinen.
  • Interoperabilität: JSON ist sprachunabhängig und wird von nahezu allen modernen Programmiersprachen und Frameworks unterstützt.
  • Effizienz: Es hat eine geringere Datenübertragungsgröße im Vergleich zu XML, da es keine zusätzlichen Tags benötigt.
  • Web-Kompatibilität: JSON ist das bevorzugte Format für die Kommunikation zwischen Web-Clients und Servern in modernen APIs.

Typische Anwendungsbereiche

  • Datenaustausch in Web-APIs.
  • Speichern von Konfigurationen und Einstellungen.
  • Transport von Daten in clientseitigen Webanwendungen.
  • Cloud-Dienste und serverlose Architekturen.

JSON in Python verarbeiten

Mit dem Modul json kannst du einen JSON-Text in Python-Datenstrukturen umwandeln (json.loads()) und umgekehrt (json.dumps()). Ein verschachteltes JSON-Objekt wird dabei zu verschachtelten Dictionaries und Listen, die du wie gewohnt mit eckigen Klammern ansprichst. 

import json

text = '{"name": "Max Mustermann", "age": 30, "skills": ["JavaScript", "Python", "JSON"]}'

daten = json.loads(text)  # wandelt den JSON-Text in ein Dictionary um
print(daten["name"])       # Max Mustermann
print(daten["skills"][1])  # Python

JSON-Dateien lesen und schreiben: json.load() und json.dump()

Liegt das JSON nicht als Text im Programm, sondern in einer Datei, verwendest du die Varianten ohne „s“: json.load(datei) liest eine geöffnete Datei ein, json.dump(daten, datei) schreibt Python-Daten als JSON in eine Datei. Merkhilfe: Das „s“ in loads/dumps steht für string.

Die Kursdatei wetter_dresden.json enthält eine Antwort der Wetter-API Open-Meteo für Dresden (so, wie du sie auf Seite 3.11 selbst abrufen wirst): 

import json

with open('wetter_dresden.json', encoding='utf-8') as datei:
    wetter = json.load(datei)             # Datei -> Dictionary

aktuell = wetter['current_weather']        # inneres Objekt
print(aktuell['temperature'], wetter['current_weather_units']['temperature'])   # 14.8 °C

# Komplexer: stündliche Werte aus zwei parallelen Arrays auswerten
stunden = wetter['hourly']['time']
temps = wetter['hourly']['temperature_2m']
for zeit, temp in zip(stunden, temps):
    print(zeit[11:], temp)                 # 08:00 11.9 ... 11:00 16.1
print('Maximum:', max(temps))              # Maximum: 16.1

# Ergebnis als neue JSON-Datei speichern
auswertung = {'ort': 'Dresden', 'max_temperatur': max(temps)}
with open('auswertung.json', 'w', encoding='utf-8') as datei:
    json.dump(auswertung, datei, ensure_ascii=False, indent=2)

indent=2 sorgt für eine eingerückte, gut lesbare Datei; ensure_ascii=False schreibt Umlaute direkt statt als \u00fc.

JSON und XML im Vergleich

Vor JSON war XML (Extensible Markup Language) das übliche Austauschformat. XML beschreibt Daten mit selbst gewählten Tags in spitzen Klammern – ähnlich wie HTML. Dieselbe Person sieht in beiden Formaten so aus:

JSONXML
 
{
  "name": "Max Mustermann",
  "age": 30,
  "skills": ["Python", "SQL"]
}
 
<person>
  <name>Max Mustermann</name>
  <age>30</age>
  <skills>
    <skill>Python</skill>
    <skill>SQL</skill>
  </skills>
</person>

XML braucht zu jedem Wert ein öffnendes und ein schließendes Tag und ist deshalb länger. Es kennt dafür Attribute, Kommentare und strenge Prüfregeln (Schemas) und wird bis heute bei Office-Dokumenten (.docx), im Bankwesen und in Behördenschnittstellen verwendet. Bei Web-APIs hat sich JSON durchgesetzt, weil es kürzer ist und direkt zu den Datenstrukturen von JavaScript und Python passt.

Beispiel 1 einfach Vom JSON-Text zum Dictionary und zurück

Ausgangssituation: Eine Kurswahl-App schickt den Datensatz einer Schülerin als JSON-Text. Er soll gelesen, um einen Kurs ergänzt und wieder als JSON ausgegeben werden.

import json

text = '{"name": "Lina", "klasse": "12", "kurse": ["Informatik", "Mathe"], "volljaehrig": true, "handy": null}'
daten = json.loads(text)
print(type(daten))
print(daten["kurse"][0], len(daten["kurse"]))
print(daten["volljaehrig"], daten["handy"])
daten["kurse"].append("Physik")
print(json.dumps(daten, ensure_ascii=False))
  1. json.loads(text) – wandelt den Text in Python-Daten um. Das äußere JSON-Objekt wird ein dict, daher <class 'dict'>.
  2. Zugriff auf das Array – "kurse" ist eine list: Element 0 ist „Informatik“, die Länge 2.
  3. Datentypen übersetzen – JSON true wird Python True, JSON null wird None. Deshalb gibt print True None aus.
  4. Ändern – append auf der inneren Liste, wie bei jedem verschachtelten Dictionary (Seite 3.2).
  5. json.dumps(daten) – macht daraus wieder JSON-Text: doppelte Anführungszeichen, true, null. Die Reihenfolge der Schlüssel bleibt erhalten.

Ergebnis:

<class 'dict'>
Informatik 2
True None
{"name": "Lina", "klasse": "12", "kurse": ["Informatik", "Mathe", "Physik"], "volljaehrig": true, "handy": null}

Kontrolle: json.loads(json.dumps(daten)) == daten ergibt True – Hin- und Rückweg verlieren nichts. Ein print(daten) sähe dagegen anders aus (einfache Anführungszeichen, True, None): Das ist Python-Schreibweise, kein gültiges JSON.

Beispiel 2 komplex Verschachteltes JSON in eine flache CSV-Tabelle umwandeln

Ausgangssituation: Die Bibliothekssoftware exportiert Ausleihen als verschachteltes JSON. Für die Auswertung in DB Browser (Seite 3.7) wird eine CSV-Tabelle mit einer Zeile je ausgeliehenem Buch gebraucht. Achtung: Ein Vorgang enthält keine Bücher, bei einem fehlt die Klasse.

import json
import csv

text = '''
{"bibliothek": "Gymnasium Elbtal",
 "ausleihen": [
   {"schueler": {"name": "Lina", "klasse": "10b"},
    "buecher": [{"titel": "Tschick", "tage": 14}, {"titel": "Momo", "tage": 21}]},
   {"schueler": {"name": "Malik", "klasse": "9a"},
    "buecher": []},
   {"schueler": {"name": "Ole"},
    "buecher": [{"titel": "Krabat", "tage": 7}]}
 ]}
'''
daten = json.loads(text)

zeilen = []
for a in daten["ausleihen"]:
    name = a["schueler"]["name"]
    klasse = a["schueler"].get("klasse", "unbekannt")
    for b in a["buecher"]:
        zeilen.append([name, klasse, b["titel"], b["tage"]])

with open("ausleihen.csv", "w", newline="", encoding="utf-8") as datei:
    writer = csv.writer(datei, delimiter=";")
    writer.writerow(["Name", "Klasse", "Titel", "Tage"])
    writer.writerows(zeilen)

for z in zeilen:
    print(z)
print(len(zeilen), "Zeilen aus", len(daten["ausleihen"]), "Ausleihvorgängen")
  1. Struktur lesen – Objekt → "ausleihen" (Array) → je Vorgang ein Objekt mit dem Objekt "schueler" und dem Array "buecher". Zwei Arrays ineinander bedeuten zwei Schleifen.
  2. Äußere Schleife – je Ausleihvorgang Name und Klasse holen. Bei Ole fehlt "klasse"; ["klasse"] gäbe einen KeyError, .get("klasse", "unbekannt") setzt einen Ersatzwert.
  3. Innere Schleife – je Buch eine flache Zeile: Name und Klasse werden in jede Zeile kopiert. Lina erscheint deshalb zweimal – beim „Flachklopfen“ entsteht Redundanz, wie bei einer nicht normalisierten Tabelle.
  4. Sonderfall Malik – Seine Bücherliste ist leer, die innere Schleife läuft nicht, er taucht in der CSV gar nicht auf. Ob das gewollt ist, muss man entscheiden: Für „Welche Bücher sind verliehen?“ ist es richtig, für „Wer war in der Bibliothek?“ ginge Information verloren.
  5. Schreiben – wie auf Seite 3.6 mit Kopfzeile und Semikolon.

Ergebnis: Konsolenausgabe

['Lina', '10b', 'Tschick', 14]
['Lina', '10b', 'Momo', 21]
['Ole', 'unbekannt', 'Krabat', 7]
3 Zeilen aus 3 Ausleihvorgängen

und Inhalt von ausleihen.csv:

Name;Klasse;Titel;Tage
Lina;10b;Tschick;14
Lina;10b;Momo;21
Ole;unbekannt;Krabat;7

Kontrolle: Zahl der CSV-Datenzeilen = Summe der Bücher in allen Vorgängen: 2 + 0 + 1 = 3. Die Zahl der Vorgänge (3) stimmt nur zufällig überein – deshalb wird beides ausgegeben.

Das Wichtigste

JSON (JavaScript Object Notation): textbasiertes Format für strukturierte Daten.

Objekt: { } mit Schlüssel-Wert-Paaren. Schlüssel stehen immer in doppelten Anführungszeichen.

Array: [ ], eine geordnete Liste von Werten.

Werte: Zeichenketten, Zahlen, true/false und null sowie wieder Objekte und Arrays. So lassen sich Daten beliebig verschachteln.

JSON in Python: Ein JSON-Objekt wird zu einem dict, ein Array zu einer list.
