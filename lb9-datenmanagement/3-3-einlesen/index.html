3.3 Daten mit Python einlesen

Einführung 2Übungen 2Vertiefung 2

Im Unterricht beschäftigen wir uns damit, wie man Daten automatisiert mit Python einlesen kann. Daten stammen in der Praxis oft aus verschiedenen Quellen, zum Beispiel:

  • Öffentliche Datenbanken und Open-Data-Portale
  • Exportdateien aus Programmen wie Excel oder Datenbanken
  • Messungen und Sensoren (z. B. Wetterdaten)
  • Online-APIs

Für den Unterricht konzentrieren wir uns auf CSV-Dateien (Comma-Separated Values). CSV-Dateien sind einfach zu erstellen, vorzubereiten und zu analysieren. Das ist besonders wichtig, da

  • vorgefertigte Übungsdateien genutzt werden können
  • CSV auch im Abitur geprüft werden kann, ohne dass Internetzugriff notwendig ist
  • CSV-Dateien auch in der Realität ein häufig genutztes Format sind.
Praxisbezug: CSV als Austauschformat im Beruf

Ob Kontoauszug aus dem Onlinebanking, Notenliste aus der Schulverwaltung oder Bestellexport aus einem Onlineshop – fast jedes Programm kann Daten als CSV exportieren. Data Analysts und Fachinformatiker*innen für Daten- und Prozessanalyse schreiben deshalb täglich kleine Python-Skripte, die solche Exporte automatisch einlesen, statt sie von Hand in Excel zu kopieren. Typische Stolpersteine im Berufsalltag sind genau die Parameter auf dieser Seite: falsches Trennzeichen, falsche Kodierung oder ein unsichtbares BOM-Zeichen am Dateianfang.

CSV-Dateien als Listen einlesen

Eine CSV-Datei kann zeilenweise eingelesen und jede Zeile in eine Liste umgewandelt werden: 

import csv

with open('daten.csv', newline='', encoding='utf-8') as csvfile:
    reader = csv.reader(csvfile, delimiter=';')
    for row in reader:
        print(row)

Hier passiert Folgendes:

  • open() öffnet die Datei zum Lesen.
  • csv.reader() wandelt jede Zeile in eine Liste um.
  • for row in reader geht Zeile für Zeile durch die Datei.
Beispiel 1 einfach

Beispiel

Angenommen, die Datei schueler.csv enthält:

Name;Alter;Note
Anna;17;1.3
Ben;16;2.0
…

Dann ergibt sich in Python beim Einlesen als Liste (hier die ersten drei Zeilen):

['Name', 'Alter', 'Note']
['Anna', '17', '1.3']
['Ben', '16', '2.0']

Jede Zeile wird zu einer Liste von Texten (Strings).

Vollständiges Programm (die Datei schueler.csv liegt im selben Ordner wie das Programm):

import csv

with open('schueler.csv', newline='', encoding='utf-8') as csvfile:
    reader = csv.reader(csvfile, delimiter=';')
    zeilen = list(reader)

print(zeilen[0])          # Kopfzeile
print(zeilen[1])          # erster Datensatz
print(len(zeilen) - 1)    # Anzahl der Datensätze ohne Kopfzeile
  1. Datei öffnen: open(…, newline='', encoding='utf-8'). Warum diese Parameter? Das csv-Modul wertet Zeilenenden selbst aus, und UTF-8 sorgt dafür, dass Umlaute richtig ankommen.
  2. Reader anlegen: csv.reader(csvfile, delimiter=';'). Warum das Semikolon? Die Datei trennt die Spalten mit ;; mit dem Standard-Komma bliebe jede Zeile ein einziges Feld.
  3. Alle Zeilen in eine Liste übernehmen: list(reader). Warum? Danach ist die Datei geschlossen, und man kann mit Index (zeilen[1]) und len() auf die Daten zugreifen.
  4. Ausgeben: Die Kopfzeile steht in zeilen[0], der erste Datensatz in zeilen[1]. Warum - 1? Die Kopfzeile ist kein Datensatz.

Ergebnis für die Datei mit 11 Zeilen (Kopfzeile + 10 Datensätze):

['Name', 'Alter', 'Note']
['Anna', '17', '1.3']
10

Testfälle und Kontrolle:

Eingabeerwartete Ausgabe
schueler.csv wie im MaterialKopfzeile, ['Anna', '17', '1.3'], 10
Datei nur mit der KopfzeileKopfzeile, dann IndexError bei zeilen[1] – eine leere Datei muss man vorher abfangen
dieselbe Datei, aber delimiter vergessen['Name;Alter;Note'] – eine Liste mit nur einem Element verrät das falsche Trennzeichen

Beachte: '17' und '1.3' stehen in Anführungszeichen – es sind Texte, keine Zahlen. Die Umwandlung folgt auf Seite 3.4.

CSV-Dateien als Dictionaries einlesen

Wenn die CSV-Datei eine Kopfzeile mit Spaltennamen hat, können wir die Daten direkt als Wörterbücher laden: 

import csv

with open('daten.csv', newline='', encoding='utf-8') as csvfile:
    reader = csv.DictReader(csvfile, delimiter=';')
    for row in reader:
        print(row)

Hier passiert Folgendes:

  • csv.DictReader() erstellt für jede Zeile ein Dictionary, wobei die Spaltennamen als Schlüssel verwendet werden.
  • Jede Ausgabe ist ein Wörterbuch, für schueler.csv z. B. {'Name': 'Anna', 'Alter': '17', 'Note': '1.3'}.

Beispiel

Angenommen, die Datei produkte.csv enthält:

Produkt;Preis
Taschenrechner;19.99
USB-Stick;8.49
…

Dann ergibt sich in Python beim Einlesen als Dictionary (hier die ersten beiden Datensätze):

{'Produkt': 'Taschenrechner', 'Preis': '19.99'}
{'Produkt': 'USB-Stick', 'Preis': '8.49'}

Jede Zeile wird zu einem Wörterbuch (dict), wobei die Spaltennamen als Schlüssel verwendet werden.

Wichtige Parameter beim Einlesen von CSV-Dateien

Damit das Einlesen problemlos funktioniert, sollten folgende Parameter genau beachtet werden:

  • newline='':
    Schaltet die automatische Umwandlung von Zeilenenden durch open() ab und überlässt sie dem csv-Modul. Das ist nötig, weil das csv-Modul Zeilenenden selbst auswertet: Nur so werden Felder, die in Anführungszeichen einen Zeilenumbruch enthalten, richtig gelesen. Beim Schreiben verhindert newline='' unter Windows zusätzliche Leerzeilen zwischen den Datensätzen (siehe Seite 3.6).
  • encoding='utf-8':
    Sorgt für korrekte Darstellung von Umlauten und Sonderzeichen. Speichern Excel oder LibreOffice eine Datei als „CSV UTF-8“, steht am Dateianfang oft ein unsichtbares Zeichen, das Byte Order Mark (BOM). Mit 'utf-8' landet es im ersten Spaltennamen ('\ufeffName' statt 'Name'), und row['Name'] meldet einen KeyError. Dann hilft encoding='utf-8-sig': Es entfernt das BOM und funktioniert auch bei Dateien ohne BOM. Stammt eine Datei von einem älteren Windows-Programm und die Umlaute sind kaputt, hilft oft encoding='cp1252'.
  • delimiter:
    Gibt an, welches Zeichen die Werte trennt. In Deutschland häufig das Semikolon („;“), manchmal auch das Komma („,“).
Hinweis: Das richtige Trennzeichen

Beim Einlesen von CSV-Dateien ist das richtige Trennzeichen (delimiter) sehr wichtig! In Deutschland wird oft das Semikolon („;“) statt des Kommas („,“) verwendet, weil wir das Komma als Dezimaltrennzeichen benutzen. Die Dateien in diesem Kurs verwenden meist das Semikolon und den Punkt als Dezimaltrennzeichen (1.3). Schau dir eine unbekannte Datei deshalb immer zuerst in einem Texteditor an. Ist das Trennzeichen falsch eingestellt, landet die ganze Zeile in einem einzigen Listenelement, z. B. ['Name,Punkte'].

Dateinamen und Pfadangaben

Beim Öffnen einer Datei muss der Dateiname exakt angegeben werden. Liegt die Datei im gleichen Ordner wie dein Python-Programm, reicht der Dateiname alleine: 

with open('schueler.csv', newline='', encoding='utf-8') as csvfile:

Liegt die Datei in einem Unterordner (z. B. „downloads“), musst du den Pfad ergänzen: 

with open('downloads/schueler.csv', newline='', encoding='utf-8') as csvfile:

Achtung: Bei Windows sind Backslashes (\) üblich. In Python sollte man Pfade entweder mit Schrägstrich (/) schreiben oder doppelte Backslashes verwenden: 

with open('downloads\\schueler.csv', newline='', encoding='utf-8') as csvfile:

Oder besser: immer den Schrägstrich / verwenden. Python versteht das auf allen Systemen!

Komplexeres Beispiel: Einlesen und gleich umwandeln

Meist will man die Daten nicht nur anzeigen, sondern weiterverarbeiten. Dann wandelt man beim Einlesen gleich die Zahlenspalten um und sammelt alle Datensätze in einer Liste: 

import csv

schueler = []
with open('schueler.csv', newline='', encoding='utf-8-sig') as csvfile:
    reader = csv.DictReader(csvfile, delimiter=';')
    for row in reader:
        row['Alter'] = int(row['Alter'])      # Text '17'  -> Zahl 17
        row['Note'] = float(row['Note'])      # Text '1.3' -> Zahl 1.3
        schueler.append(row)

print(len(schueler), "Datensätze eingelesen")
print(schueler[0])

Ausgabe mit der Kursdatei schueler.csv: 10 Datensätze eingelesen und {'Name': 'Anna', 'Alter': 17, 'Note': 1.3} – jetzt ohne Anführungszeichen um die Zahlen, man kann also mit ihnen rechnen (Seite 3.4).

Beispiel 2 komplex Eine Einleseroutine, die das falsche Trennzeichen bemerkt

Ausgangssituation: Die einfachen Beispiele oben zeigen das Einlesen im Normalfall. Die Datei klassenarbeit.csv soll mit derselben Funktion eingelesen werden wie die übrigen Kursdateien – also zunächst mit Semikolon. Sie ist aber mit Komma getrennt. Die Funktion soll das selbst bemerken, statt stillschweigend Unsinn zu liefern, und die Punkte gleich als Zahlen bereitstellen.

import csv

def einlesen(dateiname, trennzeichen):
    with open(dateiname, newline='', encoding='utf-8-sig') as csvfile:
        reader = csv.reader(csvfile, delimiter=trennzeichen)
        kopf = next(reader)                      # Kopfzeile lesen
        if len(kopf) == 1:                       # nur eine Spalte? Trennzeichen falsch!
            print("Warnung: nur eine Spalte erkannt:", kopf)
            return None
        daten = []
        for row in reader:
            daten.append({'Name': row[0], 'Punkte': int(row[1])})
        return daten

ergebnis = einlesen('klassenarbeit.csv', ';')
print(ergebnis)
ergebnis = einlesen('klassenarbeit.csv', ',')
print(len(ergebnis), "Datensätze")
print(ergebnis[0])
summe = 0
for d in ergebnis:
    summe += d['Punkte']
print("Summe:", summe, "Durchschnitt:", summe / len(ergebnis))
  1. Datei mit utf-8-sig öffnen – So stört ein eventuell vorhandenes BOM den ersten Spaltennamen nicht. Bei Dateien ohne BOM ändert sich nichts.
  2. Kopfzeile mit next(reader) lesen – Sie wird nicht als Datensatz gebraucht, verrät aber, wie viele Spalten der Reader erkennt.
  3. Erster Aufruf mit ';' – Die Kopfzeile Name,Punkte enthält kein Semikolon. Der Reader liefert deshalb eine Liste mit einem Element: ['Name,Punkte']. Die Prüfung schlägt an, die Funktion gibt eine Warnung aus und liefert None. Ohne diese Prüfung käme es später bei row[1] zu einem IndexError, dessen Ursache schwer zu erkennen wäre.
  4. Zweiter Aufruf mit ',' – Jetzt hat die Kopfzeile zwei Spalten. Jede weitere Zeile wird zu einem Dictionary; int(row[1]) macht aus dem Text '85' die Zahl 85.
  5. Plausibilität prüfen – Anzahl der Datensätze, erster Datensatz und eine Summe zeigen schnell, ob alles vollständig und richtig umgewandelt wurde.

Ergebnis:

Warnung: nur eine Spalte erkannt: ['Name,Punkte']
None
10 Datensätze
{'Name': 'Anna', 'Punkte': 85}
Summe: 796 Durchschnitt: 79.6
TestfallEingabeerwartete Ausgabe
falsches Trennzeicheneinlesen('klassenarbeit.csv', ';')Warnung, Rückgabe None
richtiges Trennzeicheneinlesen('klassenarbeit.csv', ',')Liste mit 10 Dictionaries
Zahlen umgewandeltergebnis[0]['Punkte'] + 186 (nicht '851')

Kontrolle: Von Hand: 85 + 72 + 91 + 65 + 88 + 77 + 82 + 69 + 93 + 74 = 796, geteilt durch 10 ergibt 79,6.

Das Wichtigste

CSV-Datei: Textdatei, in der jede Zeile einen Datensatz enthält. Die Werte sind durch ein Trennzeichen getrennt, in Deutschland meist ;, international meist ,.

csv.reader: liefert jede Zeile als Liste.

csv.DictReader: liefert jede Zeile als Dictionary mit den Spaltennamen der Kopfzeile als Schlüsseln.

Eingelesene Werte: sind zunächst immer Texte (Strings), auch Zahlen.
